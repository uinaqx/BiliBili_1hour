# 一小时学习 C 语言：零基础入门

面向从未接触过编程的学生。课程围绕姓名、成绩和文件记录，从显示第一句话开始，逐步讲解变量、常量、类型、表达式、输入输出、分支、循环、数组、字符串、函数、递归、指针、结构体和文件操作。共有 12 章、69 个分镜、10 道原创课堂练习；目标时长 50～70 分钟，最终时长见交付目录。

## 学习材料

- `content/完整讲稿.md`：每个分镜的旁白、画面代码、提示和结果。
- `content/chapters_a.py` 至 `chapters_d.py`：可编辑内容源。
- `content/example_manifest.json`：66 个完整 C11 程序与测试输入、预期输出、文件副作用。
- 交付目录中的 `C示例/`：每个子目录都包含完整 `main.c`，需要已有文件的例题还带文件样本。输入检查失败例题按预期返回非零，这不是工程故障。
- `build/example-validation.json` 与 `build/property-validation.json`：实际编译、运行及边界验证记录。

## 视觉与声音

沿用 Rust 第二讲：1920×1080 深色画面，左侧代码 34px，下方独立运行结果 32px，四行结果使用 30px；右侧中文提示和原创二维图示，底部居中 40px 中文字幕。主标题使用正规章节名，每屏主要代码最多 12 个可见行。代码节选标注完整示例位置。

阿里云百炼北京区域，`qwen-audio-3.0-tts-plus`，系统男声 `longanlufeng`，自然、沉稳的中文教师口吻，无背景音乐。句号之间额外增加 0.1 秒，逗号不增加；每道题在题目朗读完成后保留完整 4 秒思考时间。

字幕对齐分为两步：先使用服务的字级时间戳定位片段，再用已知讲稿对实际音频做 Whisper 声音强制对齐和起音修正。字幕持续到下一句出现，避免朗读过程中意外消失。音频插入静音后，字幕时间同步偏移。最终编码把每次字幕变化都作为显示事件，并检查实际烧录状态；各章开头、中间、末尾以波形相关性核对拼接同步。自动检查不能替代逐字人工听辨。

视频按 30fps 时间刻度组织，H.264/AAC 输出，包含章节标记。静止教学画面采用可变帧率编码，播放器显示的平均帧率可能低于 30，这不改变字幕事件时间。

## 练习环境

制作环境是 Windows、Node.js 24、Python 3.11、FFmpeg、Microsoft YaHei 和 Cascadia Code 字体。实际编译器为 MinGW GCC 6.3.0，示例采用 C11。也可用较新的 GCC 或 Clang 学习，其他系统需调整可执行文件名称和字体。

最短练习流程：安装能编译 C11 的 GCC，把示例保存成 `main.c`，在该文件目录执行：

```powershell
gcc -std=c11 -Wall -Wextra main.c -o example.exe
.\example.exe
```

需要输入的例题运行后输入资料指定的小整数或短英文姓名，再回车。文件例题请在独立练习目录运行；`w` 会清空同名旧文件，`a` 在末尾追加，`r` 读取已有文件。验证脚本在每个独立测试目录准备输入文件，不修改其他课程或个人资料。

```powershell
npm ci --ignore-scripts
python -m pip install -r requirements.txt
python scripts/build_course.py
python scripts/verify_examples.py
python scripts/property_checks.py
# 工程包已有配音时，直接从 prepare_audio 开始，无需再次调用服务。
python scripts/prepare_audio.py

npx tsc --noEmit
npm run studio
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/final_frames.py
python scripts/package.py
```

首次使用声音对齐时需要下载 Whisper base 模型。原始配音在 `public/audio_original/`，加入停顿后的 WAV 与时间轴在 `public/audio/`；保留原始音频才能可靠地重新处理。画面和分章编码都有内容缓存，失败可继续。不要在仍生成时间轴时开始全片渲染。

修改旁白需要生成自己的新配音。脚本从进程环境变量或标准输入取得凭据，不读取 `.env.example` 中的占位符：

```powershell
$env:DASHSCOPE_API_KEY = '<自己的百炼 API Key>'
$env:SFM_WORKSPACE_ID = '<同一业务空间的 Workspace ID>'
python scripts/voice.py --from-env --test
python scripts/voice.py --from-env --workers 3
```

调用前确认自己的模型权限、额度有效期和费用保护；免费额度并不保证存在。不要把真实 API Key 或 Workspace ID 写入源码、公开仓库或制作说明。工程不含原作者的密钥或业务空间 ID；已制作配音可以用于当前工程的离线重渲染。

## 核验依据

讲稿与例题为原创教学内容，语法与标准库语义依据 [WG14 C11 委员会草案 N1570](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)，重点核对表达式、数组与指针、函数调用、结构体、`scanf` 返回值和宽度、字符串结束字符及文件打开模式。没有复制标准中的长段正文。

本课程不运行除零、越界、悬垂指针、错误格式与地址等没有可靠结果的例子来“预测输出”；这些情况通过解释和图示说明。正常示例实际运行，失败输入与文件失败路径也实际验证。
