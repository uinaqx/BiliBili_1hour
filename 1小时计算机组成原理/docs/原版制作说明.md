# 一小时学习计算机组成原理

面向初学者与大学生，12 章、73 个分镜、11 道课堂题。以“把内存中的十三和七相加并保存二十”为主线，连接数据表示、逻辑电路、运算器、存储系统、指令、CPU、流水线、输入输出和虚拟存储。

成片自然语速，实测 **68 分 12.1 秒**，落在约定的 50～70 分钟内。服务语速为 1.0，解码与合成期间没有加速、减速或拉伸语音来凑时长。沿用此前句号后额外增加 0.1 秒的停顿，逗号不增加；每道题另有 4 秒独立思考时间。

## 内容与画面

| 章节 | 内容 |
|---|---|
| 导学 | 一次加法与整机分工 |
| 数据与信息表示 | 位、字节、进制、补码、溢出、小数与浮点近似 |
| 逻辑电路 | 逻辑门、全加器、选择器、寄存器与时钟 |
| 运算器与数据通路 | 加减、移位、乘法分解与结果保存 |
| 主存储器 | 编址、字节序、容量与地址宽度、SRAM/DRAM、读写 |
| 存储层次与高速缓存 | 局部性、平均访问时间、映射、替换与写策略 |
| 指令系统与寻址 | 教学指令、操作数来源、转移、指令设计取舍 |
| CPU 与指令周期 | 取指、译码、执行、访存、写回、控制与中断 |
| 流水线与性能 | CPU 时间、理想时序、数据与控制冒险、局部优化 |
| 总线与输入输出 | 传输率、轮询、中断、DMA、存储器映射 I/O |
| 虚拟存储与外存 | 分页、TLB、缺页与访问检查、外存分工 |
| 综合应用与回顾 | 整机数据流、读题方法与概念边界 |

视觉继承数据结构课程：深蓝背景、橙色当前步骤、蓝色结构、绿色结论、底部居中中文字幕。左侧原代码区改为位格、字段图、真值表、数据通路、分支关系图、流水线时序等；左下区域用于算式和结论。右侧保留关键概念与步骤提示。

本课使用简化的、每条 4 字节的教学指令，展示软件语义和硬件数据流，不把它当成某种真实 ISA 的机器码。所有例题都写明所用位宽、编址单位或性能假设。

## 工程结构

- `content/chapters_a.py` 至 `chapters_d.py`：完整讲稿、每页四段旁白、关键概念和习题。
- `content/visual_data.py`：73 页图示的四步数据、计算结论和状态。
- `src/visuals.tsx`：可编辑 SVG 图形组件。
- `src/video.tsx`：整体版式、动画、思考倒计时、预览字幕和声音。
- `public/course.json`、`public/timeline.json`：课程清单与实测时间轴。
- `public/audio_original/`：原始配音缓存；`public/audio/`：用于合成的音频和逐句时间。
- `scripts/verify_models.py`：补码、逻辑、容量、缓存、指令模拟、性能和分页验算。
- `scripts/check.py`：最终成片、章节、字幕存在性、自然语速 PCM 和合成声音同步校验。

四步图示的切换点保持原版时间。当前字幕为 V2：对现有配音做独立逐字 CTC 对齐，连续数字和存疑边界补充同音字路径复核；取消字幕起点的提前量。上一条保持到下一句起音后再切换，末句覆盖到朗读结束。

## 字幕修正版 V2

最新交付为 `一小时学习计算机组成原理_字幕修正版V2.mp4`，主文件与独立字幕已同步。语音直接复制旧版 AAC，音频载荷及每个音频包的时间戳、时长和大小都保持一致。

- `scripts/subtitle_audit_v2.py`：检查实际成片中 73 段配音的首、中、尾声音位置，排除累计偏移。
- `scripts/subtitle_ctc.py`：使用中文 Wav2Vec2 CTC，对已冻结的声音和讲稿做单调逐字对齐；`--phonetic-review` 复核连续数字与低置信度位置。
- `scripts/subtitle_sync_v2.py`：只重建字幕时间和字幕显示帧，复制原音轨，不修改教学图示步骤。
- `scripts/subtitle_wavecheck.py`：检查所有字幕起点附近的实际声音。
- `scripts/subtitle_validate_v2.py`：将成片每个显示状态中的实际字幕与对应文字图像比较，检查是否显示了错误的下一条字幕。随后严格解码整片。

工程已包含对齐结果及冻结时间轴；保留声音与讲稿时无需重新推理。修改字幕算法需在独立 Python 环境安装 `requirements-subtitles.txt`，将 [中文 Wav2Vec2 模型](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-chinese-zh-cn/tree/main) 的 `pytorch_model.bin`、`config.json`、`preprocessor_config.json`、`vocab.json`、`special_tokens_map.json` 放到 `build/subtitle-model/ctc-zh/`。模型不打包。

```powershell
# 已有本工程的对齐缓存时，跳过以下两行
python scripts/subtitle_ctc.py
python scripts/subtitle_ctc.py --phonetic-review
python scripts/subtitle_sync_v2.py prepare
# 改过教学图示时，先用 node scripts/stills.mjs 更新静帧
python scripts/subtitle_sync_v2.py render
python scripts/subtitle_wavecheck.py
python scripts/subtitle_validate_v2.py
python scripts/subtitle_sync_v2.py publish
```

`render` 需要同级交付目录中的旧 `一小时学习计算机组成原理_字幕校准版.mp4`，从中复制音轨。若在新目录制作，先在脚本 `SOURCE` 指定本人已有的同一音轨成片。工程缓存用于可重复检查，自动对齐不等于逐字人工听辨。

## 上一版字幕校准流程（历史）

本次修订只修改字幕时间，不调用配音服务，不调整声音速度、停顿、章节或画面步骤。成片 AAC 音轨直接复制；音频载荷以及所有音频包的 PTS、DTS、时长和大小都与旧版校验一致。

已经包含校准后的 `public/timeline.json`、音频 JSON、SRT 和识别结果。只修改画面时，直接从 `node scripts/stills.mjs` 开始；不要重新执行 `prepare_audio.py` 覆盖已经校准的时间。

重新做字幕校准时，可在独立 Python 环境安装 `requirements-subtitles.txt`，并把官方 [fa-zh](https://huggingface.co/funasr/fa-zh) 和 [SeACo Paraformer](https://modelscope.cn/models/iic/speech_seaco_paraformer_large_asr_nat-zh-cn-16k-common-vocab8404-pytorch) 模型分别放在 `build/subtitle-model/fa-zh` 与 `build/subtitle-model/paraformer-timestamp`。模型权重不放进工程压缩包。随后运行：

```powershell
python scripts/subtitle_calibrate.py backup
python scripts/subtitle_fa.py
python scripts/subtitle_asr.py
python scripts/subtitle_asr.py --remap
python scripts/subtitle_review.py
# 核查 build/subtitle-review.json 与识别差异后再继续
python scripts/subtitle_calibrate.py prepare
python scripts/subtitle_calibrate.py render
python scripts/check.py
```

`backup` 会冻结当前交付视频、时间轴和音频元数据，已有备份不会覆盖。`render` 使用干净的 Remotion 图示静帧，只编码视频，复制备份视频中的 AAC 音轨，并验证音频载荷和包时间戳一致。识别及校准在本机执行，不需要 API Key 或 Workspace ID。

## 安装和制作

需要 Node.js 22+、Python 3.11、FFmpeg/FFprobe。字体使用 Microsoft YaHei；其他系统需安装具有中文字符的字体并替换源码中的字体配置。

```powershell
npm ci --ignore-scripts
python -m pip install -r requirements.txt
npm run studio
```

工程包包含声音缓存，可直接重新渲染；不修改旁白时不需要重新调用在线服务。

```powershell
python scripts/build_course.py
python scripts/verify_models.py
# 修改了旁白才需要下行；先在进程环境设置自己的凭据
python scripts/voice.py --from-env
python scripts/prepare_audio.py
python scripts/timeline.py
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/final_frames.py
python scripts/package.py
```

首次初始声音对齐会下载 Whisper base 模型。最终字幕另用上面的字幕校准流程；已有时间数据时可跳过配音和对齐。静帧与章节支持缓存和失败后继续；改画面后先运行 stills，再编码。`--scene 05-04` 可只生成指定分镜静帧，`--chapter 05` 可只编码指定章节。

默认交付目录为工程同级的 `交付/计算机组成原理一小时`。课程超出时长范围时，timeline 会报错，需要修改内容或有教学意义的停顿安排，不能自动调整语速。

## 编码和核验

1920×1080，16:9，使用 30fps 时间刻度。Remotion 绘制图示变化帧，FFmpeg 保持静止段并烧录字幕，输出 H.264 可变帧率视频与 AAC 48kHz 单声道音频，附 MP4 章节标记。播放器显示的平均帧率可能低于 30；画面变化和字幕都按精确时间戳呈现。

验证包括独立数值模型、图示文本边界、每次编码状态的字幕存在性、每章声音与最终 AAC 的波形相关性及偏移，以及全片严格解码。移除已记录的额外静音后，还把每段合成用音频与原配音直接解码的 PCM 逐字节比对，验证没有调速。字幕自动对齐与显示检查不能代替逐字人工听辨。
