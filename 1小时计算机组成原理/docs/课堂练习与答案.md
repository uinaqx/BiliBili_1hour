# 课堂练习与答案

每题在成片中提供四秒独立思考。先写出状态或算式，再核对结果。

## 数据与信息表示 · Data Representation

题目：现在做一道小题。画面上的八位数据是，一一一一一一一一。第一个问题，按无符号整数解释，它是多少？第二个问题，按八位补码解释，它又是多少？

接着，把这一串位再加上一，仍然只保留低八位。低八位会变成什么？向第九位有没有进位？请把这几个结果分别写下来。

最后再想一想，如果把这次加法理解成补码中的负一加一，有没有有符号溢出？不要因为前面出现了进位，就直接套用结论。

你可以先写位模式，再写两种解释，最后判断各自的范围。现在留四秒钟，独立算一遍，我们随后一起核对。

答案与解释：先核对第一个结果。八位全一，按无符号整数读，是一百二十八加六十四，一直加到一，总和二百五十五。按补码读，最高位改成负权重，结果就是负一。

这一串位加一，低八位全变成零，并向第九位进位。所以低八位的位模式是八个零，进位存在。这是对电路产生的位结果进行描述。

如果按补码解释，刚才做的是负一加一，真实结果是零，零在可表示范围内，因此没有有符号溢出。进位和有符号溢出的结论可以不同。

这道题最值得保留的方法，是把位模式、数值解释和范围检查分开。下次遇到同一串位出现两个答案，先问它采用什么规则，再判断哪个答案适合题意。

要点：无符号：255；补码：−1；低 8 位为 0，有进位；补码 −1＋1 没有有符号溢出

## 逻辑电路 · Digital Logic

题目：现在把选择器和寄存器接起来。左路输入是十三，右路输入是七；选择信号为一时走右路。寄存器当前保存五，写入允许已经打开。

第一个问题，在时钟边沿还没到来时，选择器输出是多少？第二个问题，这时寄存器已经保存的输出是多少？请不要把两者写成同一个答案。

第三个问题，等到规定的时钟边沿到来，且输入已经稳定，寄存器会更新成多少？我们只讨论这个简单的同步模型。

先决定选择器走哪路，再决定寄存器什么时候更新。现在留四秒钟，分别写出边沿前和边沿后的状态。

答案与解释：选择信号为一，所以选择器走右路，输出七。这个值已经到达寄存器输入端，但输入端出现七，不代表已经保存的状态马上就变成七。

在规定边沿到来之前，寄存器仍然输出原来保存的五。它保留的是上一次更新时记录下来的值，这正是保存状态的意义。

当有效时钟边沿到来，写入允许也打开，且输入满足稳定要求，寄存器更新为七。边沿前后，选择器可能没变，寄存器的状态却发生了变化。

所以，这三个答案依次是七、五、七。读数据通路图时，碰到带时钟的保存单元，要特别问一句：这是正在输入的值，还是已经保存的值？

要点：选择器输出：7；边沿前寄存器：5；有效边沿后寄存器：7

## 运算器与数据通路 · ALU and Datapath

题目：画面上是八位补码负八，它的位模式是一一一一一零零零。现在分别做一次逻辑右移和一次算术右移，两个操作都向右移动一位。

请先写出右移后的八位，不要直接凭负八除以二来回答。逻辑右移在最高位补零，算术右移则复制原来的最高位。

再把两个结果都按八位补码解释，它们分别是多少？同样的原始位模式，只因为补位规则不同，就可能得到完全不同的数值。

我们留四秒钟。先移动，再补位，最后按指定规则读数，三个步骤分开完成。

答案与解释：先看逻辑右移。原来的八位向右移动，最高位补零，得到零一一一一一零零。它按补码读是正的一百二十四。

算术右移则复制原符号位，在最高位补一，得到一一一一一一零零。按八位补码读，它是负四。

所以，这次两个答案分别是一百二十四和负四。算术右移保留了负号，而逻辑右移把最高位变成零，不能再期待它保持原来的负数含义。

不要只记这两个数字。真正可迁移的方法，是明确位宽和补位规则，画出位的变化，再解释结果。运算的名称相近，具体规则却必须读完整。

要点：逻辑右移：01111100 = 124；算术右移：11111100 = −4；先操作位，再解释数值

## 主存储器 · Main Memory

题目：现在换一块芯片。它有四千零九十六个可寻址单元，每个单元十六位，题目按单元编址。请问，选择一个单元需要多少位地址？

第二个问题，一次选中单元，对应的数据宽度是多少位？第三个问题，这块芯片一共能保存多少字节，也就是多少 KiB？

注意，题目没有说按字节编址。先算有多少个可以选的位置，再算每个位置装多少位，最后再把位换成字节。

我们留四秒钟。把地址位数、数据位数和总容量，写成三个分开的答案。

答案与解释：四千零九十六等于二的十二次方，所以选择这些单元需要十二位地址。每个单元十六位，因此数据宽度是十六位。

总容量是四千零九十六乘十六，等于六万五千五百三十六位。每八位换成一字节，得到八千一百九十二字节，也就是八 KiB。

你可能发现，它和前面八 K 乘八位的芯片，总容量相同，但单元数和每单元宽度不同。因此，同样的总容量，不代表相同的地址组织方式。

以后看到存储容量题，先写出单元数量，再写每单元位数。题目若还涉及多片扩展，就继续区分增加字数，还是增加每个字的宽度，不能混着相加。

要点：地址宽度：12 位；数据宽度：16 位；4096×16 bit = 8 KiB

## 存储层次与高速缓存 · Memory Hierarchy and Cache

题目：现在只看一个很小的直接映射缓存，一共有两行。块号除以二的余数，就是它必须去的行号。开始时两行都无效。

接下来依次读取主存块零、块二、块零。这三个数字是块号，不是字节地址。每次缺失都会把所需块装入指定行。

请问，三次访问分别命中还是缺失？总共缺失几次？你也可以把每次访问后，零号缓存行里保存哪个块，写在旁边。

不要因为一号行还是空的，就把数据随意放过去。先按映射规则找位置，再检查标记。现在留四秒钟。

答案与解释：第一次读取块零，零号行原来无效，所以缺失，把块零放进去。第二次读取块二，它除以二余零，也必须去零号行。

虽然零号行有效，但里面保存的是块零，标记不匹配，因此又缺失，块二把块零替换出去。剩下的一号空行，不能违反直接映射规则拿来使用。

第三次再读块零，零号行现在保存块二，依然不匹配，所以第三次还是缺失。总共三次缺失，每一步都要按当时的缓存状态判断。

这就是冲突造成来回替换的一个例子。缓存总容量之外，地址怎样映射、访问顺序怎样，也会影响命中情况。不要只看有多少空位，就判断一定能命中。

要点：依次：缺失、缺失、缺失；零号行：块 0 → 块 2 → 块 0；一号空行不能随意借用

## 指令系统与寻址 · Instructions and Addressing

题目：现在做一道寻址题。一个寄存器保存一百，指令给定位移十二。采用基址加位移的访存方式，而且内存地址一百一十二处保存五十。

请问，这次有效地址是多少？如果执行读入，目标寄存器最终得到多少？然后再想，如果十二采用的是立即数方式，直接使用的数值是多少？

三个问题分别对应算位置、读内容、直接用常数。不要把同一个十二，未经区分地带到所有答案里。

我们留四秒钟。建议先画一个加法箭头，再画一个读取内存的箭头，把两个步骤分开。

答案与解释：基址一百加位移十二，有效地址是一百一十二。这一步只是在确定位置，还没有说明取回的数据是多少。

去地址一百一十二处读取，那里保存五十，所以目标寄存器得到五十。前提是题目约定的访问宽度和数据都已经给定，不涉及异常。

如果十二采用立即数方式，直接使用的数值就是十二，不需要为了这个常数再去地址十二处读一次。

所以三个答案依次是一百一十二、五十、十二。读寻址题时，区分地址计算和内容读取；读立即数时，则不要凭空多加一次内存访问。

要点：有效地址：112；读回内容：50；立即数方式直接使用 12

## CPU 与指令周期 · CPU and Instruction Cycle

题目：回到教学程序。执行加法前，寄存器一是十三，寄存器二是七，内存地址一百零八处原来是零。现在只执行那条寄存器加法，结果写到寄存器三。

请问，加法完成后，寄存器三是多少？内存地址一百零八处又是多少？这时还没有执行后面的存出指令。

再想一个问题：在这个每条四字节的顺序执行模型里，位于地址八的加法指令之后，下一条指令地址是多少？

我们留四秒钟。请把寄存器变化、主存变化和下一条地址，分成三栏填写。

答案与解释：加法得到二十，并写入目标寄存器三，所以寄存器三变成二十。这个答案说明运算和寄存器写回已经完成。

内存地址一百零八处仍然是零，因为题目明确说，还没有执行存出。机器不会因为某个寄存器变了，就自动把它复制到你心里想的一个主存地址。

在这个定长四字节、顺序执行的模型里，地址八后面的下一条在十二。因此，这三栏依次是二十、零、十二。

做执行跟踪题，每次只更新指令真正改变的状态。没有发生的存储写入，不要提前画上；没有说明的转移，也不要自行假设。这样，复杂程序也能一条一条推下去。

要点：R3 = 20；M[108] 仍为 0；顺序下一条地址为 12

## 流水线与性能 · Pipelining and Performance

题目：两台机器执行同一个任务，都需要十亿条指令。甲的主频是二 GHz，平均 CPI 是二；乙的主频是四 GHz，平均 CPI 是四。

只按这些给定条件计算 CPU 时间，哪台更快？先不要被四 GHz 吸引，分别算出总周期数，再除以每秒周期数。

题目没有加入额外的输入输出等待，也不比较功耗和价格。我们只回答这一次给定程序的 CPU 执行时间。

现在留四秒钟。请写出两台机器各用了多少秒，再给出比较结论。

答案与解释：甲总共需要十亿乘二，也就是二十亿个周期。每秒能走二十亿周期，因此甲需要一秒。

乙需要十亿乘四，也就是四十亿个周期。它每秒能走四十亿周期，因此乙也需要一秒。

所以，在题目给定的口径下，两台用时相同。乙虽然频率更高，但平均每条指令占用的周期也更多，两者恰好抵消。

这并不是说主频没用，而是说主频只是公式中的一项。先把指令数量、平均周期数和频率放到同一个式子里，再比较秒数，才能避免只盯着宣传数字。

要点：甲：10⁹×2÷(2×10⁹) = 1 s；乙：10⁹×4÷(4×10⁹) = 1 s；本例 CPU 时间相同

## 总线与输入输出 · Buses and Input/Output

题目：一条教学总线的数据宽度是三十二位，频率一百 MHz，每周期完成一次传输。现在要发送二百五十六字节，忽略所有等待和控制开销。

第一个问题，每次传多少字节？第二个问题，一共需要占用多少个传输周期？最后再把周期数换算成时间。

题目已经明确每周期一次，不要自行改成一个周期传两次。这里计算的是总线占用的完整传输周期数，不讨论第一拍和最后一拍之间的边沿间距。

现在留四秒钟。先把位换成字节，再用总量除每次传输量，最后乘周期长度。

答案与解释：三十二位等于四字节，所以每次传四字节。二百五十六字节除以四，需要六十四次传输，也就是六十四个周期。

一百 MHz 表示每秒一亿个周期，因此每周期十纳秒。六十四乘十，得到六百四十纳秒。

也可以先算峰值数据率：每次四字节，乘每秒一亿次，是每秒四亿字节。用数据总量除数据率，会得到同样的结果。

实际设备还会有等待和控制开销，所以这里是理想条件下的占用时间。做题把单位跟着每一步写出来，往往能立即发现把位和字节混用的错误。

要点：每次：32÷8 = 4 B；次数：256÷4 = 64 周期；每周期 10 ns，共 640 ns

## 虚拟存储与外存 · Virtual Memory and Storage

题目：采用四 KiB 的分页模型。一个虚拟地址是零叉二五六七，虚拟页二已经在内存中，映射到物理页框九，并且允许本次访问。

请问，这个地址的页内偏移是多少？转换后的物理地址是多少？如果只是 TLB 没有现成记录，是否一定要去外存读取页面？

请利用页面已经在内存这个条件。不要把查不到一条快速转换记录，误当成页面的数据根本不存在。

我们留四秒钟。先拆开页号与偏移，再替换页框号，最后判断缺失发生在哪一层。

答案与解释：四 KiB 等于二的十二次方，所以低十二位是页内偏移，也就是十六进制的后三位，零叉五六七。虚拟页号则是二。

把虚拟页二换成物理页框九，偏移保持五六七，得到物理地址零叉九五六七。访问的是同一页内的同一个相对位置。

仅仅 TLB 未命中，不必然从外存读取页面。本题已经说明页面驻留、权限允许，可以通过页表等转换机制找到映射，再继续访问。

因此，三个结论是偏移五六七，物理地址九五六七，以及不一定需要调页。区分转换缓存缺失、缺页和数据缓存缺失，是这一章最重要的边界。

要点：页内偏移：0x567；物理地址：0x9567；TLB 未命中不必然访问外存

## 综合应用与回顾 · Putting It Together

题目：最后一起检查三句话。第一，寄存器加法把结果写入目标寄存器后，主存中的目标位置也会自动跟着改变。

第二，只要 TLB 没有命中，就说明页面不在内存中，必须去磁盘读取。第三，使用 DMA 搬运数据以后，CPU 完全不需要参与这次输入输出。

请判断哪些表述需要修正，并用一句话说明原因。不要只写对或者错，要指出它把哪两个不同阶段，或哪两层机制混在了一起。

我们留四秒钟。你可以分别从存出指令、地址转换和传送配置三个角度，找出遗漏的步骤。

答案与解释：三句话都需要修正。寄存器加法只改变规定的寄存器状态，要更新主存中的相应数据，还需要执行存储操作，并遵守存储系统的规则。

TLB 未命中，只代表没有现成的快速转换记录。页面可能已经在内存中，能通过页表继续找到；即使需要缺页处理，也不总是去磁盘读取。

DMA 减少 CPU 逐项搬运数据的工作，但 CPU 仍需进行必要的配置、完成处理和管理。一个机制承担部分工作，不代表其他部件从此完全退出。

这节课到这里结束。请选一道你刚才做错的小题，重新画出状态变化，并讲给自己听。能解释数据怎样走、状态何时变、时间怎样算，就已经建立起继续学习计算机组成原理的一条主线。

要点：写寄存器与写主存分开；转换记录缺失与页面缺失分开；DMA 搬运与 CPU 管理分开
