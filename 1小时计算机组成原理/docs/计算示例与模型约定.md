# 计算示例与模型约定

先写模型，再带单位计算。下列数字是本课的教学算例，不是某款处理器或设备的实测参数。

| 主题 | 条件 | 结果与注意事项 |
|---|---|---|
| 位与字节 | 1 B = 8 bit | 8 位共有 256 种组合，无符号范围 0～255 |
| 进制 | 1101₂、0x10 | 分别为十进制 13、16 |
| 补码 | 固定 8 位 | 11111011 表示 −5；范围 −128～127 |
| 进位与溢出 | 127＋1，8 位补码 | 低位 10000000 表示 −128，发生有符号溢出 |
| 另一次加法 | 11111111＋1，低 8 位 | 结果 0，有第 9 位进位；按补码 −1＋1 没有有符号溢出 |
| 二进制小数 | 0.101₂ | 1/2＋1/8 = 0.625；某些十进制小数无法有限精确表示 |
| 全加器 | 输入 A、B、Cin 均为 1 | 总和 3 = 11₂，和位 1，输出进位 1 |
| 选择与保存 | 选择右路 7，寄存器原为 5 | 边沿前保存值仍为 5；允许写入且有效边沿到来后为 7 |
| 减法 | 固定 8 位，13−7 | 转为 13＋(−7)，低 8 位为 00000110，即 6 |
| 右移 | 原模式 11111000 | 逻辑右移为 01111100，即 124；算术右移为 11111100，即 −4 |
| 负奇数右移 | −3 的 8 位补码 | 算术右移为 −2，不能无条件替代向零截断的整数除法 |
| 乘法 | 13×3 | 13＋(13 左移 1 位) = 13＋26 = 39 |
| 编址 | 按字节编址，整数 4 B | 从地址 100 起占用 100～103，下一个起点 104 |
| 字节序 | 整体 0x12345678 | 低地址起，小端为 78、56、34、12；大端为 12、34、56、78 |
| 存储容量 | 8192 单元×8 bit | 13 位逻辑单元地址、8 位数据、总容量 8 KiB |
| 容量练习 | 按单元编址，4096×16 bit | 12 位地址、16 位数据、总容量仍为 8 KiB |
| Cache 平均时间 | 查询 2 ns，缺失率 10%，额外代价 40 ns | 2＋0.1×40 = 6 ns；额外代价没有包含前面的查询时间 |
| Cache 地址字段 | 32 位字节地址，数据区 4 KiB，块 64 B，直接映射 | 64 行，块内偏移 6 位，行号 6 位，标记 20 位；容量不计元数据 |
| 冲突练习 | 两行直接映射，行号为块号 mod 2，初始无效 | 块 0、2、0 都映到行 0，三次都缺失；行 1 不能随意借用 |
| 两路 LRU | 同组依次访问甲、乙、甲、丙 | 丙到来时换出乙，组内内容为甲、丙 |
| 寻址 | 基址 100、位移 12，M[112] = 50 | 有效地址 112；读回 50；另一个立即数方式直接使用 12 |
| 指令跟踪 | 每条教学指令 4 B；地址 8 的 ADD | 顺序下一条 12；ADD 写 R3 后，尚未执行 STORE 时主存目标不变 |
| CPU 时间 | IC = 10⁹，CPI = 2，f = 2 GHz | 时间 IC×CPI/f = 1 s；4 GHz、CPI = 4 的对照机器也是 1 s |
| 理想流水线 | 4 条指令、5 级、每级 1 周期、无停顿 | 4＋5−1 = 8 周期；同阶段周期的顺序模型为 20 周期，整体加速 2.5 倍 |
| 局部优化 | 原来 1 s，其中 80% 加速 4 倍 | 新时间 0.2＋0.8/4 = 0.4 s，整体加速 2.5 倍 |
| 总线峰值 | 64 bit、200 MHz、每周期一次、忽略开销 | 8 B×200×10⁶/s = 1.6 GB/s，GB 采用十进制 |
| 传输练习 | 32 bit、100 MHz、每周期一次、256 B | 占用 64 个完整传输周期，每周期 10 ns，共 640 ns |
| 分页 | 4 KiB 页，0x1234 的页号 1 映射到页框 9 | 偏移 0x234 不变，物理地址 0x9234 |
| 分页练习 | 虚拟 0x2567，页 2 映射页框 9，已驻留且允许访问 | 偏移 0x567，物理地址 0x9567；TLB 缺失不必然调页 |

## 四条教学指令

只跟踪下列四条指令。主存按字节编址，`M32[address]` 表示从该地址开始的 32 位整值；表格不是字节级内存转储。本课的指令语法和固定长度用于演示，不对应真实机器编码。

| 指令地址 | 指令 | 完成后的关键状态 |
|---|---|---|
| 0 | LOAD R1,[100] | R1 = 13，顺序 PC = 4 |
| 4 | LOAD R2,[104] | R2 = 7，顺序 PC = 8 |
| 8 | ADD R3,R1,R2 | R3 = 20，M32[108] 仍为 0，顺序 PC = 12 |
| 12 | STORE R3,[108] | M32[108] = 20，顺序 PC = 16 |

有 Cache 时，具体写入可见性和向下一层同步的时机取决于写策略；上述指令语义与缓存的内部传送步骤应分开理解。

## 核验方法

`scripts/verify_models.py` 使用逐位全加器模型，对全部 65536 对八位操作数与整数加法对照，另检查有符号范围与溢出。其他算例检查容量与单位、字节序、直接映射访问轨迹、LRU、字节编址指令模拟、流水线排程、CPU 时间及分页偏移不变性。

概念题中的 SRAM/DRAM、转发与停顿、中断、DMA、TLB 与缺页边界还经过讲稿人工核对；这些概念不能由一个数值断言代替。
