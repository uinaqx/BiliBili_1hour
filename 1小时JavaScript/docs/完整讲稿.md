## 数据类型与运算符

### js-02-01 数字、文字与真假

```javascript
const price = 12;
const product = "茶";
const paid = true;
console.log(typeof price);
console.log(typeof product);
console.log(typeof paid);
```

一个购买记录通常需要几种数据。价格十二是数字，商品名称茶是一段文字，是否已经付款用true或false表示。这里true表示真，false表示假。JavaScript把这些数据分成不同类型，方便选择合适的操作。看赋值右边，有没有引号、是不是数字、是否使用真假关键字，就能先判断这几个例子的种类。

typeof可以查看值的类型。价格得到number，商品名称得到string，付款状态得到boolean。同一个数字写成十二和引号里的十二，参与运算的方式会有区别。先把这种区别记住：类型跟当前值有关。我们练习时尽量让一个变量始终承担清楚的用途，例如金额一直保存数字，名称一直保存文字，这样读代码和排查问题都会顺畅。

本页总结：

- number 表示常见数字
- string 表示文字
- boolean 只有 true 和 false
- typeof 查看当前值的类型

运行结果或操作预期：

```text
number
string
boolean
```

### js-02-04 计算金额与余数

```javascript
console.log(12 + 8);
console.log(20 - 5);
console.log(3 * 4);
console.log(10 / 4);
console.log(10 % 4);
console.log((12 + 8) * 2);
```

基本算术和我们熟悉的写法接近：加号做加法，减号做减法，星号表示乘法，斜线表示除法。十除以四得到二点五，数字运算可以产生小数。下一行的百分号求余数，十里面能放进两个四，还剩二，所以结果是二。判断编号是否为偶数时，也常常检查它除以二的余数是不是零。

最后一行先算括号内的十二加八，得到二十，再乘二，结果是四十。乘除通常先于加减，表达式里加入括号，可以把想要的计算顺序写清楚。金额的小数运算还会涉及浮点精度，日常小额练习可以先用整数表示分，再汇总和显示。今天的例子主要用整数，便于把注意力放在程序步骤和计算关系上。

本页总结：

- +、-、*、/ 完成基本算术
- / 可以得到小数结果
- % 求相除后剩余的部分
- 括号明确先计算的部分

运行结果或操作预期：

```text

15
12
2.5
2
40
```

### js-02-05 比较与逻辑组合

```javascript
const spent = 25;
const budget = 30;
console.log(spent <= budget);
console.log(12 === "12");
console.log(12 !== 8);
console.log(spent > 0 && spent <= budget);
```

比较运算会得到真假。花了二十五，预算三十，二十五小于等于三十，所以第一处结果为true。三个等号是严格相等，十二这个数字和引号里的十二类型不同，比较结果为false。叹号加两个等号表示严格不相等，十二和八确实不同，所以得到true。入门时优先使用这组严格比较，条件的含义会更清楚。

最后一行把两个条件放在一起。左边要求开销大于零，右边要求开销小于等于预算，两个条件都成立，整个表达式就是真。两个与符号表示并且；两个竖线表示或者，有一个条件成立就能得到真。单个叹号可以把真假反过来。先分别说清每个小条件，再用并且或者连接，复杂的判断也能拆成容易检查的步骤。

本页总结：

- <= 检查左边是否小于或等于右边
- === 同时比较类型和值
- !== 检查严格不相等
- && 两边条件都为真，结果才为真

运行结果或操作预期：

```text
true
false
true
true
```

## 条件判断与循环

### js-03-01 根据预算选择分支

```javascript
const spent = 25;
const budget = 30;
if (spent <= budget) {
  console.log("预算内");
} else {
  console.log("超出预算");
}
```

我们已经会比较开销和预算，现在让程序根据结果采取行动。if后面括号里的条件是二十五小于等于三十，这个条件成立，就执行紧接着那组大括号里的语句，显示预算内。读这种结构时先圈出条件，再看条件为真时进入哪一组语句。大括号把同一条路线上的操作放在一起，缩进让这层关系更容易看清。

else后面这组语句负责条件为假的情况。把spent改成三十五，再运行，程序就会显示超出预算。两条路线中，每次会根据条件选择对应的一条。写完以后用预算附近的三个数测试：二十九、三十和三十一。这样能核对小于和小于等于的区别，也能确认边界值三十确实进入了你想要的分支。

本页总结：

- if 括号内放判断条件
- 条件成立执行第一组大括号
- else 处理条件不成立的情况
- 本例 25 <= 30，显示预算内

运行结果或操作预期：

```text
预算内
```

### js-03-02 多个条件依次判断

```javascript
const score = 82;
if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("通过");
} else {
  console.log("继续练习");
}
```

如果需要区分更多情况，可以增加else if。这次分数是八十二，第一处检查是否至少九十分，条件为假，于是往下检查是否至少六十分，这次成立，就显示通过。把判断过程说成一句话，就是先看优秀，再看通过，最后处理其余情况。顺着代码从上到下走，遇到第一个符合的分支，就执行它对应的内容。

条件的先后顺序会影响分类结果。如果把至少六十分放在最前面，九十五分也会先进入通过这一支。因此这类分数题先写九十分，再写六十分，范围关系就清楚了。两种简单结果也可以用条件问号和冒号写成表达式，例如及格时取通过，否则取继续练习。初学时先把if路线写清楚，再考虑紧凑的表达形式。

本页总结：

- 从上到下检查条件
- 先匹配的分支得到执行
- else if 补充下一种条件
- 范围较窄的高分条件放在前面

运行结果或操作预期：

```text
通过
```

### js-03-03 for 循环重复三次

```javascript
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
```

当一个动作要重复几次，可以使用for循环。括号里面分成三部分，第一部分让i从一开始，第二部分要求i小于等于三，第三部分在每轮结束后把i加一。第一次检查时i是一，符合条件，于是显示一。显示完以后更新i为二，再回到条件位置检查。我们把大括号里的操作叫作循环体，它是每轮真正要做的事情。

接下来显示二，再更新成三，显示三以后更新成四。四小于等于三为假，循环就在这里结束，所以结果是一、二、三。跟踪循环时，按初始化、检查、执行、更新这个顺序走。i加加是把i增加一的简写，预算累加也可以用加等号表达。先把每一轮的状态列出来，再看简写，就能理解程序到底重复了多少次。

本页总结：

- 开始时 i = 1
- 每轮执行前检查 i <= 3
- 循环体显示当前 i
- i++ 后继续下一轮检查

运行结果或操作预期：

```text
1
2
3
```

### js-03-04 while 循环与停止条件

```javascript
let remaining = 3;
while (remaining > 0) {
  console.log(remaining);
  remaining--;
}
console.log("完成");
```

while适合表达只要某个条件成立，就继续处理。这次remaining从三开始，只要它大于零，就显示当前值，再把它减一。先显示三，再变成二，下一轮显示二，再变成一，第三轮显示一，再变成零。你可以把remaining看成还剩几次处理机会，每轮用掉一次，剩余数量就减少一次。

零大于零的条件为假，程序离开循环，继续显示完成。检查这类循环时，找到两件事：开始时的值是什么，每轮怎样朝着停止条件前进。如果例子里的减一漏掉，remaining会一直维持三，条件就一直成立。遇到这种情况，先停止运行，再补上更新。循环体里也能用break提前结束，具体使用时让退出的原因写得清楚。

本页总结：

- while 每次先检查条件
- remaining 每轮减少 1
- 变为 0 时结束循环
- 循环结束后继续执行后面的语句

运行结果或操作预期：

```text
3
2
1
完成
```

### js-03-05 逐项读取一组数据

```javascript
const expenses = [12, 8, 5];
let total = 0;
for (const amount of expenses) {
  total += amount;
}
```
