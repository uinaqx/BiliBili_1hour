# 制作与字幕说明

成片：一小时学完JavaScript_零基础_含字幕.mp4。
实测时长：58分01.533秒，1920×1080，H.264/AAC，章节按原始声音时间生成。

面向零基础学生，10章、60页、120段旁白、1151条字幕。深色代码区、左下运行结果、右侧具体总结；开头是10个课程知识点。代码选中持续保持，练习先思考4秒，再显示结果与解释。

配音：百炼3.1 Plus、许南川、原生1.05倍速；后期tempo=1.0。句号间额外0.1秒、逗号保持原有停顿。未用改变语速的方式凑时长。

字幕：基于最终音频的词级声学校准，精确计入插入停顿和各页起点。完整词保持在同一字幕中，时间重叠时合并，不强行截短上一句。字幕开始与结束均成为30fps网格中的显示事件，并直接绘入对应画面。独立SRT与成片采用同一来源；实际视频在下一可显示帧切换。

配套：60组独立例子和一个完整网页项目；网页项目包含index.html、app.js、budget.js。样例全部实际运行，浏览器交互检查覆盖添加、删除、刷新恢复、空输入、非法数字、负数、0元、文字显示、损坏存储与重置。

可编辑工程附讲稿、代码、源旁白、最终页面WAV、对齐数据、画面和渲染脚本，可复用已有声音离线重制。账号加载器、API Key、Workspace ID、模型权重、浏览器和依赖缓存已排除。

字幕边界的实际编码画面按全量显示状态检查；每章抽取开头和末尾音频核对位置。该检查覆盖计时变换、画面状态和编码完整性，逐句发音中的细微语义边界仍以试听为准。
