## js-01-06 练习：跟踪两次赋值

来做第一道练习。spent开始保存十，接着执行spent加五，再显示它。显示以后，又把二交给spent，再显示一次。请预测控制台会出现哪两个数字，并在心里按照代码的顺序追踪。你也可以在纸上写一个spent，把每次读到和写入的值分别记下来。先做判断，四秒以后我们一起对照。

```javascript
let spent = 10;
spent = spent + 5;
console.log(spent);
spent = 2;
console.log(spent);
```

第一处更新读取十，再加五，得到十五，所以第一次显示十五。接着直接赋值为二，第二次显示二。每条赋值都依据当时已经执行到的位置，读取当时的值。这样跟踪程序时，先按顺序走，每经过一次赋值，就更新纸上的记录，再处理下一行。下一章会把数字、文字和真假分开，看看不同种类的数据怎样参加运算。

```text
15
2
```

## js-02-06 练习：拼接还是加法

现在请预测三次显示的结果。amount保存文字十，第一次直接加二，第二次先经过Number转换再加二，第三次拿转换结果和数字十做严格比较。请把每一步的数据类型也说出来。例如你预测一个结果是十二，还要想清楚它此时是数字，还是引号里的文字。给自己四秒钟，把三行结果依次写下来。

```javascript
const amount = "10";
console.log(amount + 2);
console.log(Number(amount) + 2);
console.log(Number(amount) === 10);
```

第一行发生拼接，得到一零二这段文字。第二行先把文字十转换成数字十，再加二得到十二。第三行转换后得到数字十，和右边数字十类型和值都一致，所以是真。这个例子帮助我们建立一个习惯：看到输入或加号，先问现在拿到的值是什么类型，再决定是否转换。下一章用这些比较结果控制程序走不同的路线。

```text
102
12
true
```

## js-03-06 练习：循环中的判断

现在把判断放到循环里面。每次取出一笔开销以后，先检查它是否至少为八，符合才加进total。数组仍然是十二、八、五，请预测最终总额是多少。跟踪时为每一轮列三项：当前金额、判断结果、累计结果。给你四秒，先把三轮各自的变化写清，再和最后的输出对照。

```javascript
let total = 0;
for (const amount of [12, 8, 5]) {
  if (amount >= 8) {
    total += amount;
  }
}
console.log(total);
```

十二达到八，第一轮把累计变成十二。八也达到八，第二轮把累计变成二十。五没有达到八，第三轮直接来到下一轮的位置，累计保持二十。因此最后显示二十。这个例子把程序拆成取数据、判断、更新三个小步骤。以后处理更长的数据表，也可以沿用这个阅读顺序，先理解一轮，再看它怎样重复到全部数据。

```text
20
```

## js-04-06 练习：返回值怎样继续参与计算

这道题先调用add，把十二和八交进去，再把结果保存到total，最后显示total乘二。请按实际执行路线判断最后显示什么。先走到调用处，再进入函数体，带着返回值回到原处。你可以用一个方框先占住调用的位置，等函数算完以后，再把返回值写进这个方框，继续完成外面的表达式。

```javascript
function add(a, b) {
  return a + b;
}
const total = add(12, 8);
console.log(total * 2);
```

add内部先把十二和八相加，返回二十。因此const total右边这次调用的结果是二十，total接住它。最后再把二十乘二，显示四十。函数先完成自己的计算，外层接着处理它返回的值。这个顺序掌握以后，看到几层函数调用，就能从最里面的具体计算开始，一层一层向外整理，逐步得到整个表达式的结果。

```text
40
```

## js-05-06 练习：筛选以后再转换

这次把两个处理步骤连在一起。先从三、八、十二里面筛选至少为八的值，再把留下的每项加一。请预测result最后保存什么。阅读一串连续的方法时，在每一步后面写出临时结果，然后把它当作下一步的输入。你有四秒思考，先写filter的结果，再写map的结果，最后检查显示用的逗号分隔。

```javascript
const values = [3, 8, 12];
const result = values
  .filter((value) => value >= 8)
  .map((value) => value + 1);
console.log(result.join(","));
```

第一步筛选后留下八和十二，第二步分别加一，变成九和十三，因此显示九逗号十三。三在筛选阶段已经被跳过，后面的加一针对的是筛选后的数组。方法链只是把连续的输入输出关系接在一起。需要调试时，也可以拆成两个变量，分别显示中间结果，找到从哪一步开始和预期不同。

```text
9,13
```

## js-06-06 练习：共享还是独立

请画出这一页有几张对象卡片。a最先建立一条记录，b直接接收a，c通过展开接收a的顶层属性。随后把b的amount改成三十，最后读取a和c各自的金额。你有四秒，把共享的箭头画到一起，把新建的容器分开画。然后沿着修改发生的位置，判断哪些读取会受到影响。

```javascript
const a = {amount: 12};
const b = a;
const c = {...a};
b.amount = 30;
console.log(a.amount);
console.log(c.amount);
```

a和b汇合到同一张卡片，所以通过b改成三十以后，a也读到三十。c对应另一张卡片，它是在修改之前复制出来的，amount还保存十二。结果依次是三十和十二。这个例子把声明方式、赋值方式和数据结构放在一起考查。下次看到类似题目，先数对象，再画引用，最后执行修改，步骤就会清楚。

```text
30
12
```

## js-07-06 练习：读取后再更新

请预测页面最后显示什么。程序先找到段落，再把当前文字保存给before，接着把before和逗号小林连接起来，交回段落的textContent。你可以把元素想成页面上的一个显示位置，把before想成从这个位置抄出来的一份文字。给你四秒，沿着读取、拼接、写回的顺序推到最后。

```javascript
<!doctype html>
<meta charset="UTF-8">
<p id="message">你好</p>
<script>
  const p = document.querySelector("#message");
  const before = p.textContent;
  p.textContent = before + "，小林";
  console.log(p.textContent);
</script>
```

读取时段落里是你好，所以before保存你好。连接逗号小林以后，得到你好，小林，页面和控制台都显示这段新文字。读取出来的字符串值和页面后来的文字更新各有自己的位置。做这种题时，明确什么时候读取，什么时候赋值，就能判断每个名字保存的具体内容。下一章加入按钮和输入框，让这些更新由用户的操作来触发。

```text
你好，小林
```

## js-08-06 练习：两次点击如何累加

为了更容易检查点击逻辑，我们先把它简化成两次函数调用。total在外层从零开始，add每次接收一段金额文字，转成数字，加进total，再返回当前累计。先调用文字十二，再调用文字八，请预测两次输出。给自己四秒，看清第二次调用开始以前，外层total已经保存了什么。

```javascript
let total = 0;
function add(raw) {
  total += Number(raw);
  return total;
}
console.log(add("12"));
console.log(add("8"));
```

第一次把零加十二，返回十二。第二次读取的是已经更新后的十二，再加八得到二十，所以两次输出依次是十二和二十。函数之外的状态会延续到后面的调用。把这条更新放进点击回调，就能得到刚才网页上的累计效果。也可以增加检查函数，在金额合适时才调用add，把数据规则和交互步骤组合起来。

```text
12
20
```

## js-09-06 练习：当前执行与异步回调

这一页只有三行，请预测字母的显示顺序。第一行直接显示A，第二行把显示B放到Promise的then回调里，第三行直接显示C。先在纸上把同步语句和登记的回调分开，再按执行时机排队。你有四秒，想清楚这次回调什么时候获得机会，然后再对照下方的结果。

```javascript
console.log("A");
Promise.resolve().then(() => console.log("B"));
console.log("C");
```

正确顺序是A、C、B。A和C属于当前正在执行的脚本，按顺序先完成。then注册的回调随后执行，才显示B。做入门异步顺序题时，先走完当前同步路线，再处理已经就绪的Promise回调。涉及更多任务种类时，再根据对应队列规则继续分析。这里把最常见的第一步建立起来，读网页请求和按钮里的异步函数就有了基础。

```text
A
C
B
```

## js-10-06 练习与课程回顾

最后一道题，把对象数组、筛选、汇总和条件表达式连起来。三笔金额是十二、八、五，先留下至少八元的记录，再计算这些记录的总额，最后判断是否在三十元预算内。请用四秒时间，在每一步旁边写出中间结果。阅读长一点的程序，仍然可以从这些已经熟悉的小操作开始，一步一步推到最后。

```javascript
const items = [{amount: 12}, {amount: 8}, {amount: 5}];
const selected = items.filter((item) => item.amount >= 8);
const total = selected.reduce((sum, item) => sum + item.amount, 0);
const message = total <= 30 ? "预算内" : "超出预算";
console.log(total, message);
```

筛选以后留下十二和八，总额二十，因此显示二十和预算内。今天我们从一行输出走到可以交互的小网页，学过变量、类型、运算、分支、循环、函数、数组、对象、字符串、事件、异步和模块。课后先运行全部例子，再把完整项目加上分类和按名称搜索。每次改一处，预测结果，再运行核对，你就能把这一小时里的语法变成真正会使用的工具。

```text
20 预算内
```
