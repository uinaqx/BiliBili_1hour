# 汇编语言课程参考资料与运行条件

## 使用范围

本课程面向零基础大学生，使用8086实模式、NASM Intel语法。源文件显式声明`CPU 8086`、`BITS 16`、`ORG 100h`。视频中的`AX`、段地址、标志位、近调用与DOS接口均围绕这一组约定讲解。

## 原始资料

- [Intel《The 8086 Family User's Manual》，1979年10月版扫描](https://bitsavers.org/components/intel/8086/9800722-03_The_8086_Family_Users_Manual_Oct79.pdf)：寄存器、寻址、标志、算术逻辑、条件转移、栈与字符串指令。
- [NASM官方语法说明](https://www.nasm.us/doc/nasm03.html)：操作数顺序、标签、立即数、内存操作数、DB/DW及常量写法。
- [NASM BITS与CPU指令](https://www.nasm.us/doc/nasm08.html)：16位模式与8086指令集限制。
- [NASM二进制格式与ORG](https://www.nasm.us/doc/nasm09.html)：平坦二进制、起始偏移和COM文件组织。
- [Microsoft MS-DOS 2.0源代码中的系统调用说明](https://github.com/microsoft/MS-DOS/blob/main/v2.0/source/SYSCALL.txt)：字符、字符串、输入和退出等DOS服务约定。
- [Microsoft Press《MS-DOS Encyclopedia》系统调用资料重印](https://www.pcjs.org/documents/books/mspl13/msdos/encyclopedia/section5/)：INT 21h服务参数与调用规则。
- [Unicorn官方示例与说明](https://www.unicorn-engine.org/docs/tutorial.html)：映射内存、运行机器码、读取寄存器与挂钩执行事件。

## 当前工程的执行条件

实际验证使用NASM 3.02、Unicorn 2.1.4与Capstone包5.0.9。每份正常示例先汇编为机器码，再逐条执行；源行、机器码列表、寄存器、标志、内存写入和输出记录均保留在工程中。

测试初态为`CS=DS=ES=SS=1000h`、`IP=0100h`、`SP=FFFEh`，其余通用寄存器为0，初始EFLAGS为0002h。个别程序会显式重设SP。数据夹具的偏移和字节在`scripts/examples.py`中给出。视频右下卡片展示当前指令完成后的实际状态；底部结果区展示完整运行后的检查值。物理地址例题都处于1MB边界以内。

DOS `INT 21h`通过本工程的教学适配器运行，提供01h读入与回显、02h字符输出、09h以`$`结束的字符串输出、4Ch退出。输出记录用于核对这些服务的调用参数。运行范围为指令功能与这些明确的接口；真实DOS装载过程、BIOS、外设及电气时序由相应系统环境负责。

## 预期失败与版本观察

`examples/expected-failures`分别保存操作数宽度冲突、普通MOV内存到内存、非法16位寻址、8086以后的指令、除数为0、商超出目标范围以及错误选用有符号/无符号分支的例子。验证报告将汇编诊断、执行异常与结果错误分别记录。

NASM 3.02对省略大小的`mov [0200h],1`采用字节操作。该观察保存在`examples/version-observations/omitted_mov_size.asm`。课程使用明确的BYTE或WORD来教学访问范围。

NASM工具来自[官方发布站点](https://www.nasm.us/)，本地下载记录保留文件SHA-256与ZIP完整性结果。记录中的摘要用于标识本次文件；工具本身需使用者另行安装。

## 语音与可复现资料

成片使用百炼`qwen-audio-3.1-tts-plus`、许南川`xunanchuan_v3.1`、原生rate 1.05。后期tempo保持1.0；只给中文句号增加0.1秒，逗号维持原音频停顿。原始MP3、最终逐页WAV和本地声学时间资料随工程保留，可离线重渲染。

API Key与Workspace ID由使用者自行设置。账号、模型权限、费用和额度检查见`docs/百炼语音配置说明.md`。
