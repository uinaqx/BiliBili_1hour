## 4. 零基础语法速查（20 分钟版）

> 详细解释看对应题号的文件。这里只做「一页纸」复习。

### 4.1 程序结构与注释

```rust
// 单行注释
/* 多行注释 */

fn main() {          // 程序入口，必须有且只有一个
    println!("hi");  // 打印并换行；println! 是宏（注意 !）
}
```

对应题号：01、02。

### 4.2 变量

```rust
let x = 5;          // 不可变变量（默认！想改必须加 mut）
let mut y = 6;      // 可变变量
y = 7;              // OK
const MAX: u32 = 100; // 常量：必须写类型，不能改，全局可用
let x = "hello";    // 遮蔽：同名新变量，类型也可以不同
```

对应题号：03~08。要点：**Rust 变量默认不可变**，这是和 C/Java 最不一样的地方之一。

### 4.3 基本类型

| 类型 | 写法 | 说明 |
| --- | --- | --- |
| 整数 | `i32`/`u32`/`i64`/`usize` 等 | 默认 `i32`，`usize` 常作下标/长度 |
| 浮点 | `f32`/`f64` | 默认 `f64` |
| 布尔 | `bool`：`true` / `false` | |
| 字符 | `char`：`'a'`、`'中'` | 单引号，占 4 字节，Unicode |
| 字符串字面量 | `&str`：`"hello"` | 双引号，不可变 |
| 元组 | `(1, "a", true)` | 可不同类型；用 `.0` 访问或解构 |
| 数组 | `[1, 2, 3]`，类型 `[i32; 3]` | 长度固定；切片 `&a[0..2]` |
| 单元类型 | `()` | 空/无返回值，类似 void |

对应题号：18~23。

### 4.4 函数

```rust
fn add(a: i32, b: i32) -> i32 {  // 参数必须写类型，返回值用 ->
    a + b                        // 最后一行表达式即返回值（不要写分号！）
}
```

- 语句（statement）：执行操作，无返回值，如 `let x = 1;`
- 表达式（expression）：有返回值，如 `1 + 2`、函数调用、`if` 表达式
- 最后一行加分号 → 变成语句，返回 `()`，和声明返回 `i32` 冲突 → 报 E0308

对应题号：09~13。

### 4.5 所有权、移动、借用（Rust 灵魂）

```rust
let s1 = String::from("hi");
let s2 = s1;              // 移动（move）：s1 失效，不能再用
// println!("{}", s1);    // ❌ 编译错误 E0382

let s3 = s2.clone();      // 深拷贝：两个都能用

fn take(s: String) {}     // 传参默认是移动
fn borrow(s: &String) {}  // & 借用：只借不拿走

let mut v = vec![1, 2];
let r = &v;               // 不可变借用（可以有多个）
let m = &mut v;           // 可变借用（同一时刻只能有一个）
```

三条核心规则：

1. 每个值有且只有一个所有者；
2. 所有者离开作用域，值自动释放（drop）；
3. 借用（`&`/`&mut`）不转移所有权；同一时刻：要么多个 `&`，要么一个 `&mut`，不能混。

对应题号：26~31（最重要的一组题）。

### 4.6 结构体与方法

```rust
struct Point { x: i32, y: i32 }

impl Point {
    fn new(x: i32, y: i32) -> Self { Self { x, y } } // 关联函数
    fn sum(&self) -> i32 { self.x + self.y }          // 方法，&self 类似 this
}
```

对应题号：32~34。

### 4.7 枚举、Option、match

```rust
enum Message { Quit, Move { x: i32, y: i32 }, Write(String) }

let m = Message::Write(String::from("hi"));
match m {
    Message::Quit => println!("quit"),
    Message::Move { x, y } => println!("{x},{y}"),
    Message::Write(s) => println!("{s}"),
}

let some: Option<i32> = Some(3);
if let Some(v) = some { println!("{v}"); }
```

- `Option<T>` = `Some(T)` 或 `None`，Rust 用它代替 null；
- `match` 必须穷举所有情况，可以用 `_ => ...` 兜底；
- `if let` / `while let` 是只关心一种模式时的简写。

对应题号：35~37、45~47。

### 4.8 字符串

```rust
let s: String = String::from("hi"); // 可增长，堆上
let r: &str = "hi";                 // 字符串切片（借用），不可变
let s2 = s + "!";                   // 注意 s 被移动了
let part = &s2[0..1];               // 切片按字节
```

对应题号：38~41。要点：`String` 拥有数据，`&str` 是借来的视图；函数参数优先用 `&str`。

### 4.9 集合：Vec 与 HashMap

```rust
let mut v: Vec<i32> = Vec::new();
v.push(1);
let first = &v[0];          // 越界会 panic
let maybe = v.get(0);       // 返回 Option<&i32>，安全

use std::collections::HashMap;
let mut map = HashMap::new();
map.insert("a", 1);
map.entry("b").or_insert(2); // 没有才插入
```

对应题号：24~25、42~44。

### 4.10 泛型与 trait

```rust
fn largest<T: PartialOrd>(list: &[T]) -> &T { /* ... */ } // 泛型 + 约束

trait Summary { fn summarize(&self) -> String; }          // 特征（接口）
impl Summary for Article { fn summarize(&self) -> String { ... } }

fn notify(item: &impl Summary) {} // impl Trait 作参数
```

对应题号：48~55。要点：泛型 = 类型参数；trait = 一组行为的约定（类似接口）。

### 4.11 生命周期

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str { /* ... */ }
```

`'a` 是“这个引用至少活多久”的标注，用来防止返回悬垂引用。多数情况下编译器会自动推导，
只有在“返回引用且来自多个输入引用”等复杂场景才需要手写。

对应题号：56~58。

## 7. 学习建议

1. **先自己做，再看答案**：看答案看懂很快，自己写会卡很久，但“卡住—报错—改对”才是真正的学习。
2. **按编号顺序**：26~31（所有权/借用）是分水岭，务必吃透；后面的生命周期、引用都建立在这一章上。
3. **多用 `rustc` 看报错**：Rust 编译器的错误提示是业界最详细的之一，先自己读报错，再查本题的【常见错误】。
4. **不要背代码，背规则**：例如“同一时刻只能有一个可变借用”“变量默认不可变”，规则会了，代码自然写得出来。
5. **每章结束做一次小复习**：只看题目名，回忆知识点；回忆不出来的，重读对应答案文件的【知识铺垫】。
6. 学完后回到 `exercises/` 用 `rustlings watch` 独立通关一遍，再去做课件上的其他练习。
