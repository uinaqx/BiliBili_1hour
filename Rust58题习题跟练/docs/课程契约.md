## 讲解校核

原注释作为材料，讲解不能未经核验直接照读。整数除法向零截断，不笼统说向下取整；数组并非因类型就一定存于栈；常量有作用域；借用的有效使用区间不等同于整个大括号；生命周期标注表达引用关系，不延长对象寿命。

参考 Rust 官方教材的借用与生命周期章节及 Rust Reference 运算符章节。仅针对本课实际涉及的知识补充，不扩展成宏、异步或复杂工程课程。
