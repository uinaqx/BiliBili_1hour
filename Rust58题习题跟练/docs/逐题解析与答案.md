## 第 06 题 · variables4

视频起点：00:09:23

第六题先把 x 设为三，打印后又想改成五。题目要求保留中间的重新赋值，所以不能简单删掉它来让程序通过。Rust 中用 let 创建的绑定默认不能再次赋值。请从声明处修改权限，让同一个变量能够经历三到五的变化。

在 let 和变量名之间加 mut，表示这个绑定允许后续修改。这里不是把数字三变成了某种特殊数字，而是允许名字 x 对应的当前值发生变化。第一次打印仍然读取三，因为重新赋值还没有执行。按执行顺序看，不要从后面的五反过来覆盖已经发生的输出。
执行这次赋值后，x 当前保存的值才变成五。第二次打印读取新值，于是两次输出不同。mut 和遮蔽是不同机制，下一题会专门比较；这一题的目标是保留同一个可变绑定，并且后续赋的新值还需要符合它的类型，不能顺便改成字符串。

实际输出先是 Number 三，再是 Number 五。请把两条打印与中间赋值的先后顺序对应起来。默认不可变能够让读代码的人少担心变量被别处改掉，只有确实需要变化时才加 mut。不要遇到任何报错都习惯性补 mut，它解决的是可变性问题，不能解决类型不匹配或名字不存在。
