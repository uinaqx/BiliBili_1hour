# 使用自己的百炼账号

工程已包含最终配音，可离线复用。只有改写旁白并需要生成新语音时才配置自己的账号。

1. 在[百炼控制台](https://bailian.console.aliyun.com/)登录、完成账号要求，开通百炼服务，地域选北京。普通模型 API 调用不要求创建智能体应用。
2. 在 API Key 管理中创建密钥，确认 API Key 属于哪个业务空间。参考[官方密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key/)。
3. 从该业务空间获取 Workspace ID，不能用账号 UID、应用 ID 或其他空间 ID 代替。参考[官方空间说明](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)。
4. 在该地域和空间确认 `qwen-audio-3.0-tts-plus` 的可用状态、模型权限、当前价格以及你自己的免费额度与有效期。符合条件的模型可在控制台检查“免费额度用完即停”设置，具体以当前账号界面为准。[官方额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota)。开通服务不表示所有调用永久免费。
5. 将自己的值通过秘密管理器或本机环境变量设置到 `DASHSCOPE_API_KEY`、`SFM_WORKSPACE_ID`，先运行短语音测试。不要将值写入源代码、命令记录、截图或公开仓库。

接口适配器见 `scripts/audio.py`，北京地域、模型及声音配置在该文件中。真实 `.env`、原始服务响应、私有账号加载器不会进入交付包。服务返回 `AccessDenied.Unpurchased` 时，先检查开通、额度及权限，再从缓存继续，不重新调用已成功的片段。
