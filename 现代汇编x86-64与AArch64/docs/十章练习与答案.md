# 十章练习与答案

每章在视频中留有四秒独立思考。

## 现代汇编与两套64位架构

题目：现在拿到两个加法函数，一个从RDI和RSI取数，另一个从X零和X一取数。你会先看哪两类信息，才能判断参数怎样传进来？先把处理器架构和函数交接规则分别写出来，接下来留四秒思考。

答案：先确认处理器架构，再确认调用约定。RDI和RSI对应本课的x八六杠六十四System V例子，X零和X一对应AArch六十四的基础整数参数例子。若换成Windows x六十四，还要改看RCX与RDX。先给代码标明环境，再分析每条指令。

- 架构帮助识别寄存器和指令。
- ABI规定参数和返回值的位置。
- Windows x64另有参数规则。
- 指令功能与平台接口分层理解。

## 寄存器、位宽与数据表示

题目：假设RAX和X零的高三十二位原来都含有数据。现在分别把七写进EAX和W零。请写出两个完整六十四位寄存器的最终值，并说明高三十二位怎样变化。接下来留四秒思考。

答案：两者最终都为七，高三十二位都清零。这是本课两套架构中三十二位目标寄存器写入的重要规则。对照前面的AL例子，写最低八位会保留其他位置；判断结果时，要按本条指令的目标宽度选择规则。

- RAX最终为0000000000000007h。
- X0最终为0000000000000007h。
- 两者高32位均清零。
- 较窄写入另按相应寄存器规则分析。

## 内存访问与地址计算

题目：一个无符号三十二位数组从二零零零零零H开始，下标从零计数。现在读取下标为二的元素，地址是多少？请把元素大小与下标相乘，再和起点相加，接下来留四秒思考。

答案：下标二乘每项四字节，偏移是八字节，因此地址为二零零零零八H。把下标和字节偏移分别标清。若元素类型换成八字节，步长也要跟着改变，再重新计算。

- 元素大小为4字节。
- 下标2对应8字节偏移。
- 目标地址为200008h。
- 按目标类型确定访问宽度。

## 算术运算、位操作与条件码

题目：两套架构都比较一和二，相减时需要借位。x八六的CF是多少，A六十四的C又是多少？请把借位和各自标志的含义对应起来，接下来留四秒思考。

答案：x八六的CF为一，表示发生借位；A六十四的C为零，表示本次减法需要借位。它们都能支持判断一小于二，只是标志编码采用不同约定。实际写分支时使用各自对应的无符号条件。

- x86-64：CF=1。
- AArch64：C=0。
- 两者比较结果均为1<2。
- 跨架构先还原数值关系，再读条件。

## 比较、选择与循环

题目：两套计数循环都在每轮末尾递减计数，并按非零条件回跳。计数从一减到零时，下一步走向哪里？请指出刚刚更新条件标志的指令，接下来留四秒思考。

答案：计数归零以后，非零条件结束，执行按顺序离开循环。x八六例子由DEC更新标志，A六十四例子由SUBS更新标志。把最近一次条件写入与分支配对，就能解释最后一轮为什么结束。

- 计数从1变0。
- 零条件成立，非零回跳结束。
- x86-64读取DEC之后的标志。
- A64读取SUBS之后的NZCV。

## 数组、字符串与数据布局

题目：请比较长度为三和长度为零的数组求和。三项处理完后指针一共前进多少字节？零长度时结果是多少，第一次读取发生了吗？按入口检查和元素步长分别判断，接下来留四秒思考。

答案：三项每项四字节，指针总共前进十二字节。零长度时入口检查直接结束，累计结果保持零，程序会跳过第一次元素读取。数组题把长度条件、每轮访问和结束位置连起来检查，就能覆盖这个边界。

- 3项共前进12字节。
- 长度0返回累计初值0。
- 入口检查先于首次元素读取。
- 访问宽度与指针步长均按类型确定。

## 函数参数、调用与返回

题目：x八六杠六十四的CALL，以及A六十四的BL，分别把接续位置保存到哪里？如果A六十四的函数还要继续调用另一个函数，应该先保护什么？接下来留四秒思考。

答案：x八六的CALL把返回地址压入栈，A六十四的BL把接续地址写入X三十。A六十四继续调用之前，要保护当前仍需使用的返回位置，本例把X三十与帧指针一起保存到栈中。之后成对恢复，再执行RET。

- x86-64 CALL：返回地址进入栈。
- A64 BL：返回地址进入X30。
- 嵌套调用要保护仍需保留的返回位置。
- 保存与恢复按本层栈记录配对。

## 寄存器保护、栈对齐与Windows

题目：现在要按Windows x六十四约定继续调用一个普通整数函数。入口RSP除以十六余八，需要三十二字节影子空间。在这份最简单的例子里，总共向下预留多少字节，才能同时满足对齐安排？接下来留四秒思考。

答案：本例预留四十字节，也就是三十二字节影子空间加八字节对齐调整。调用之后再对应恢复四十。实际函数若还有局部变量或额外参数，就把它们加入同一张栈布局表重新核算。

- 32字节影子空间。
- 8字节完成本例对齐。
- SUB RSP,40；返回后ADD RSP,40。
- 其他保存项与局部变量另计入布局。

## 机器码、调试与系统接口

题目：把一个Linux输出程序从x八六杠六十四迁到AArch六十四时，为什么既要改指令写法，又要核对系统调用号和参数位置？请按本课的三个层次回答，接下来留四秒思考。

答案：指令写法与行为由目标指令集规定，函数交接由ABI规定，系统调用号和系统调用参数则按目标操作系统接口准备。因此迁移时要分别核对计算指令、调用约定和系统服务，逐层完成对应。

- 指令集：寄存器与机器指令。
- ABI：函数参数、返回值与保护责任。
- OS接口：系统调用号与参数。
- 分层核对后再做实际运行验证。

## 双架构综合实践与回顾

题目：把综合程序的输入改成零、九、二。总和与最大值各是多少？再把结果填到本课两套架构约定的输出寄存器中，接下来留四秒思考。

答案：总和为十一，最大值为九。x八六的RAX为十一、RDX为九；A六十四的X零为十一、X一为九。计算方法相同，返回位置按各自明确的接口填写。检查时再确认三轮都推进了指针和计数，结果就完整了。

- 总和0+9+2=11。
- 无符号最大值为9。
- x64：RAX=11，RDX=9。
- A64：X0=11，X1=9。
