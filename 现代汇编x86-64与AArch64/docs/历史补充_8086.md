# 历史补充：8086 放在哪里学

8086 实模式使用 16 位寄存器和分段寻址。常见物理地址计算为“段值 × 16 + 偏移”，DOS 环境里的 `INT 21h` 则是当时系统服务的入口之一。这些内容适合结合早期 PC、实模式启动和历史系统课程学习。

本次新版把普通应用的主线放在两套 64 位架构：x86-64 和 AArch64。课堂里的地址计算围绕字节地址、基址、下标、元素宽度、固定偏移和 PC/RIP 相对引用展开。普通 64 位应用使用平坦地址模型，FS/GS 及地址转换等机制归入相应系统进阶内容。

AArch64 是本课选择的 Arm 64 位执行环境，指令集采用 A64。AArch32、Thumb 和特定微控制器平台可作为后续专题，继续沿用“架构、ABI、OS、数据流、控制流”的阅读顺序。
