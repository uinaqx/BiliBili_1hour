# 官方资料与验证依据

访问核验日期：2026-11-02。教学主线为 x86-64 与 AArch64 的基础整数程序，明确区分指令集、函数 ABI 和操作系统接口。

- [Intel 64 与 IA-32 软件开发手册](https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html)：寄存器、指令行为、标志位与整数除法。
- [NASM：64 位代码](https://www.nasm.us/doc/nasm13.html)：64 位模式、寄存器写入、相对寻址与平台交接示例。
- [NASM：语法](https://www.nasm.us/doc/nasm03.html)：Intel 风格操作数与地址表达式。
- [System V x86-64 psABI 官方项目](https://gitlab.com/x86-psABIs/x86-64-ABI)：Linux 等平台的参数、返回值、寄存器保护和栈对齐。
- [Microsoft：x64 调用约定](https://learn.microsoft.com/en-us/cpp/build/x64-calling-convention?view=msvc-170)：RCX/RDX/R8/R9、影子空间与函数调用。
- [Microsoft：x64 软件约定](https://learn.microsoft.com/en-us/cpp/build/x64-software-conventions?view=vs-2019)：寄存器与栈布局。
- [Arm：AAPCS64 官方规范](https://github.com/ARM-software/abi-aa/blob/main/aapcs64/aapcs64.rst)：整数参数与返回、保护责任、SP 对齐。
- [Arm：AArch64 寄存器](https://support.arm.com/documentation/100069/0606/Overview-of-AArch64-state/Registers-in-AArch64-state)：W/X 视图和专用寄存器角色。
- [Arm：过程调用标准介绍](https://support.arm.com/documentation/102374/0102/Procedure-Call-Standard)：基础调用流程。
- [Arm：UDIV 指令](https://support.arm.com/documentation/ddi0602/2022-03/Base-Instructions/UDIV--Unsigned-Divide-?lang=en)：零除数时的结果。
- [Linux x86-64 系统调用表](https://github.com/torvalds/linux/blob/master/arch/x86/entry/syscalls/syscall_64.tbl) 与 [Linux 通用调用号头文件](https://github.com/torvalds/linux/blob/master/include/uapi/asm-generic/unistd.h)：本课 write 调用号示例。
- [Unicorn 官方教程](https://www.unicorn-engine.org/docs/tutorial.html)：处理器模拟执行。
- [Keystone 官方源码](https://github.com/keystone-engine/keystone)：A64 机器码汇编工具。

NASM 用于 x86-64；Keystone 用于 A64；Capstone 反汇编用于核对每条实际编码；Unicorn 保存逐条运行状态。模拟器提供明确的代码、数据、栈和返回入口，OS 服务页采用接口示意，不作为真实 Linux 系统调用运行演示。
