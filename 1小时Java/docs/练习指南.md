# 零基础 Java 练习指南

## 先让第一段程序运行起来

1. 从 [Microsoft OpenJDK 官方页面](https://learn.microsoft.com/en-us/java/openjdk/download) 下载并安装适合系统的 JDK 21。Windows 安装器中选择设置 PATH 和 JAVA_HOME；安装后重新打开终端。
2. 输入 `java -version` 和 `javac -version`，应能看到 21 开头的版本。只看到 java、没有 javac，通常需要安装完整 JDK 或检查 PATH。
3. 打开 `Java示例/01-1` 文件夹，在这个文件夹打开终端。Windows 11 可在空白处右键选择“在终端中打开”。
4. 输入 `javac -encoding UTF-8 Main.java`。没有错误消息就继续输入 `java Main`。
5. 看到 `Hello, Java!` 后，修改双引号里的文字，保存，再编译、运行。

Main.java 的大小写要正确。第一条命令带 .java，第二条只写 Main。每个示例单独运行，不能把所有同名 Main 类合并到一个目录。

## 每次怎样练习

先读一小段，写下自己预测的结果，再运行。每次只改一个地方，例如成绩 80 改成 59、条件 `>=` 改成 `>`、循环结尾 3 改成 4。观察输出发生了什么，再解释原因。暂时不要同时改动多个地方。

有输入的例子，在程序等待时输入内容并回车。完整输入和预期结果在示例目录的 `预期行为.json`：04-1 输入 `80`；04-2 输入 `Ana Lee`；04-3 先输入 `80` 回车，再输入 `Ana Lee` 回车；04-q、04-a 输入 `80`。

## 看懂三种结果

- **正常运行**：先编译成功，再按预期显示。即使正常运行，也要检查计算结果是否符合需求。
- **编译错误**：程序尚未开始执行。01-q 故意缺少分号，08-4 故意在范围外使用局部变量；先修正再运行。
- **运行时异常**：编译通过，但执行到某一步无法完成。07-q 故意访问数组长度对应的位置；最后一项的位置应是长度减一，并应先判断数组不为空。

控制台错误通常包含文件名与行号。先找自己写的那一行，检查第一处原因，不要被后面连带出现的大段消息吓住。

## 课后的五个小任务

1. 修改两门或三门成绩，计算总分和平均分；分清整数除法与小数除法。
2. 用 59、60、61 检查及格判断；用 89、90 检查多分支边界。
3. 分别用数组下标循环和增强 for 累加成绩。`07-extra-enhanced-for` 提供后者的完整版本。
4. 画出 `Student a` 与 `Student b`：分别用一次 new 和两次 new，观察修改成绩的影响。
5. 用列表添加、删除姓名，再用映射表按姓名查询成绩。为查不到的姓名准备清晰提示。

初次完成时可以翻阅完整讲稿和课堂练习答案。第二次合上答案，尝试从空白文件独立写出同一功能。下一阶段再学习更完整的类设计、继承和接口、文件操作、调试与测试。
