# 一小时学习 Java：零基础入门

面向从未接触编程的学生，不要求 C、C++ 或其他语言基础。沿用 Rust 第二讲的深色代码画面：左侧代码、左侧下方大字运行结果、右侧中文要点与关系图，1920×1080，中文沉稳男声，**无字幕、无背景音乐**。目标时长一小时，允许 50～70 分钟；实际时长见交付目录和验收报告。

课程按依赖顺序讲解：课程导学、第一个 Java 程序、变量与数据类型、运算符与表达式、输入输出、分支结构、循环结构、数组与字符串、方法、类与对象、集合、异常处理、综合回顾。11 道原创课堂练习，每题讲完后留出完整四秒思考，再解释答案。

这是入门课，不在一小时内展开继承、接口、文件、线程和框架。先用具体数据解释每一步，再给新写法起名字；课堂节选的完整程序和输入样例见配套 `Java示例`。正常示例、预期编译错误、预期运行时异常分别验证，不把错误说明冒充正常输出。

## 学生从哪里开始

先读 [练习指南](练习指南.md)。安装 JDK 21 后检查 `java -version` 和 `javac -version`。进入某个示例自己的目录，执行：

```powershell
javac -encoding UTF-8 Main.java
java Main
```

示例都叫 Main.java，因此不要一次把不同目录里的 Main 类放到同一个编译目录。需要键盘输入的程序，请参考该目录的 `预期行为.json`。`01-q` 缺少分号、`08-4` 使用了范围外变量，预期不能编译；`07-q` 刻意访问数组越界，预期运行时抛出异常。

## 本地重新制作

需要 Node.js 22、Python 3.11 或更高版本、FFmpeg 和 JDK 21。音频对齐使用本地 Whisper base 模型，首次使用会下载模型；已有对齐缓存时可以复用。示例按 Java 21 编译，制作机器实际使用 Microsoft OpenJDK 21.0.12.1。

```powershell
npm ci
python -m pip install -r requirements.txt
python scripts/build_course.py
python scripts/verify_examples.py
python scripts/property_checks.py
python scripts/extra_examples.py
```

只复用现有旁白时继续执行：

```powershell
python scripts/prepare_audio.py
python scripts/timeline.py
npx tsc --noEmit
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/final_frames.py
python scripts/package.py
```

先检查 `build/qa` 和 90 秒内部试片，再完成全片；课堂题目倒计时与答案页也要看。分镜有缓存，失败后重试同一命令会继续。修改画面、课程或时间轴会更新缓存版本。`npm run studio` 可打开可编辑预览。最终交付写入工程同级的 `交付/Java一小时`。

若修改了旁白，在自己的进程环境中设置 `.env.example` 列出的两个变量，再运行 `python scripts/voice.py --from-env`。示例文件只列变量名，**不会自动读取 .env**。不要将实际值写入源文件；不要把整个工作目录直接上传公开仓库。`package.py` 会扫描交付文本中的常见密钥和空间标识格式，并校验压缩包完整性。

## 画面、配音与时间

代码字号 34px，一页最多 12 行主要代码；运行结果在代码下方，字号 32px，四行结果使用 30px。右侧显示当前要点和关系图。课堂节选会明确标注，完整 Main.java 另附。底部保留空白，不烧录字幕，不写入字幕流。

配音使用北京地域百炼 `qwen-audio-3.0-tts-plus`、`longanlufeng` 男声。语音文本自然解释操作，不逐字符念代码。在声学对齐后的句号间插入额外 0.1 秒静音，不额外改变逗号停顿。全课使用一致语速；目前语音实测无需变速。逐段保存配音，按样本生成时间轴，分章编码并内嵌章节。

最终视频使用 H.264/AAC。画面在 30fps 时间网格上设计，连续高亮过渡以 0.1 秒状态渲染，静态讲解画面使用可变帧率保持，方便长课压缩与重用；不是每秒重复编码 30 张相同图片。

## 阿里云百炼账号与免费额度申请教程

### 一、开通账号与百炼服务

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，注册或登录自己的账号，并按要求完成实名认证。
2. 阅读并同意服务协议，开通百炼，地域选择 **华北2（北京）**。
3. 本项目使用普通百炼模型 API，不需要购买 Token Plan、服务器或创建智能体应用。账号开通不代表语音调用一直免费。参见 [官方开通说明](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。

### 二、创建 API Key

在首页“常用功能 → API Key”创建密钥：地域北京，归属自己的主账号，业务空间选择默认空间或专用空间。若设置自定义模型权限，应包含将要调用的语音模型。需要的是百炼 API Key，不是阿里云 AccessKey，也不是旧版语音服务 Access Token。存入自己的密码管理器，勿公开或提交仓库。参见 [官方密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key/)。

### 三、获取 Workspace ID

进入“业务空间”，复制 **该 API Key 所属空间**的 Workspace ID。不能使用另一个空间，也不能以账号 UID 或 APP ID 代替。参见 [官方获取说明](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)。

### 四、确认语音模型

在模型目录查找完整名称 `qwen-audio-3.0-tts-plus`；本工程实际验证使用这个模型。`qwen-audio-3.0-tts-flash` 是可另行调查的语音模型，本工程不声明已验证它能直接替换。核对地域、调用说明、账号权限及价格。如果页面要求额外开通，按模型页面办理；子空间还需获得模型权限。不要误选名称相近的语音识别或实时对话模型。参见 [官方语音模型与声音说明](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)。

### 五、首次调用前检查免费额度和费用保护

1. 在控制台的“免费额度”查询**具体模型**的剩余额度和有效期。
2. 如果模型提供“免费额度用完即停”，建议开启。
3. 如果没有额度、已过期或没有对应开关，先确认当前价格及是否接受付费，再调用。

免费额度因账号、模型和活动规则而异，不保证每个账号都有。支持的模型在开启“用完即停”后额度耗尽会停止服务。以 [官方额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota) 和自己控制台为准。
