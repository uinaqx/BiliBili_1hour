# 本地案例：修复购物车总价

该例用固定脚本代替模型，以便反复观察相同的运行时机制。文件读取、补丁写入、子进程测试和检查点落盘均真实执行，不调用模型或外部服务。

| 阶段 | 文件内容中的返回表达式 | 输入 | 实际结果 |
| --- | --- | --- | --- |
| 初始文件 | `sum(values) + 1` | `[10, 20]` | 31，原文件有错 |
| 第一版补丁 | `sum(values[:-1])` | `[10, 20]` | 10，测试失败 |
| 第二版补丁 | `sum(values)` | `[10, 20]` | 30，同一测试通过 |

## 从头观察与暂停恢复

在工程根目录运行以下 Python 代码。工作目录应自行选择在自己的临时空间，避免覆盖已有演示结果。

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from demo.harness import Harness

with TemporaryDirectory(prefix="harness-lesson-") as folder:
    first = Harness(Path(folder))
    paused = first.run(pause_after=3)
    print(paused["status"])  # paused
    resumed = Harness(Path(folder)).run()
    print(resumed["status"])  # completed
    for event in resumed["events"]:
        print(event["callId"], event["tool"], event["result"])
```

`checkpoint.json` 保存游标、轮数、已知结果、消息、事件和调用账本。重复的调用 ID 且参数相同，会复用已记录结果；同一 ID 携带不同参数会拒绝。接收方幂等另用 `IdempotentService` 演示：这是本地模拟的持久结果表，不会创建真实外部订单。

20 项单元测试覆盖正常反馈、结构错误、路径越界、未授权写入、ID 冲突、已记录调用复用、恢复、过早终答、预算、取消、超时结果不明及接收方去重。正式视频展示的账本来自 `build/demo-execution.json`，实际命令结果不是在画面里编造的。

## 教学简化

- 只允许读取演示文件和提交两个预批准的补丁，不接受任意命令。
- 参数和路径校验不是操作系统级沙箱，也不能当成抵御所有并发/文件系统攻击的生产权限方案。
- 写文件、记录结果与提交检查点之间仍可能有中断缝隙；本例没有宣称外部副作用恰好一次。
- 测试中固定模型替身用于检验运行策略，不用于估计模型成功率。
- 模型最终消息还需通过应用验收：最新测试通过且当前代码确为最终版本。
