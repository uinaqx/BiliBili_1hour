## 向量与线性组合

题目：00:04:42；答案：00:05:09

蓝色向量是一和二，橙色向量是二和四。能不能只靠它们的数乘与相加，得到横坐标一、纵坐标零的目标？请先看两支箭头的关系，再看目标是否在同一条直线上。不要因为手里有两个向量，就直接断言能到达整个二维平面。现在独立思考四秒。

**答案：** 不能；两向量共线，任意组合满足 y=2x。

**解析：**

不能。橙色恰好是蓝色的两倍，它们的任意组合都能写成蓝色的某个倍数。因此横坐标与纵坐标一直满足，纵坐标等于横坐标的两倍。目标一和零不满足这个关系，所以到不了。图上看到目标离开了这条线，计算上看到坐标关系不成立，两种判断相互印证。这个小题已经碰到了后面的线性相关和秩。我们稍后再给出严格定义，现在先留下一个直观印象：重要的是提供了多少个不可替代的方向，而不是写了多少个名字。遇到一个新的抽象词，可以先寻找它在这幅图里对应什么。接下来把向量整齐排成矩阵，看看一个数字表格怎样控制整张坐标网格。

## 矩阵与线性变换

题目：00:11:50；答案：00:12:19

已知 A 是二乘三矩阵，B 是三乘二矩阵。A 乘 B 和 B 乘 A，哪些有意义，各是什么尺寸？再判断它们能不能因为使用了同样两张矩阵，就直接认定相等。先圈出中间两个尺寸，看能否配对；再留下外侧尺寸，作为结果的行数和列数。请独立思考。

**答案：** 都能相乘；AB为2×2，BA为3×3，尺寸不同，不能相等。

**解析：**

两种顺序都能相乘，但结果尺寸不同。A 乘 B 的中间两个三配对，结果二乘二；B 乘 A 的中间两个二配对，结果三乘三。这两张结果连尺寸都不同，因此不能相等。很多矩阵错误不需要算到最后，只检查尺寸，就已经能发现。这个习惯在以后看复杂公式时尤其有用。即使两张矩阵同阶、两个乘积尺寸相同，也只能说它们有资格比较，仍不能自动交换。请把尺寸检查和数值计算分开：先判断运算有没有意义，再按规则算。到这里，矩阵已经从一张数字表，变成了描述组合和变换的工具。下一章研究行列式，用一个数概括方阵对面积、体积和信息压缩的重要影响。

## 行列式与面积变化

题目：00:19:58；答案：00:20:25

矩阵的两列分别是二和零、一和三。它把单位正方形变成什么样，面积是原来的多少倍？如果只交换两列，行列式和面积各会怎样变化？这里有两个问题：一个问带符号的行列式，一个问没有正负号的面积。请先算二乘三减零，再考虑交换方向的影响。

**答案：** 行列式6，面积扩大6倍；交换两列后行列式-6，面积仍扩大6倍。

**解析：**

原来的行列式是六，因此面积放大六倍。交换两列以后，行列式变成负六，但绝对值仍是六，面积倍率没有改变。方向翻转，不等于面积变成了负数。图中顶点顺序翻了过来，而平行四边形占据的大小相同。把数值里的符号和几何大小分开，是理解行列式很关键的一步。到这里，行列式有了三种用途：描述面积倍率，借助性质简化计算，并判断方阵是否丢失方向。一般定义、余子式展开和消元不是互相冲突的算法，而是从同一个数出发选择不同计算路径。具体题目先观察结构，再决定怎么计算。接下来关心更实际的问题：变换以后，能不能找到一套操作，把输入完整恢复。

## 初等变换与逆矩阵

题目：00:25:07；答案：00:25:36

看矩阵 A，主对角线上是一，右上角也是一，左下角是零。有人认为，把每个非零元素取倒数、零保留不动，就得到逆矩阵。这个方法对不对？你可以不用猜，直接考虑候选矩阵和 A 相乘是否等于单位矩阵。逆矩阵的定义，比记忆某一种外形更可靠。请独立思考四秒。

**答案：** 不对。A的逆为[[1,-1],[0,1]]，而不是原矩阵本身。

**解析：**

不对。原矩阵让网格向右错切，撤销它应该向左错切，所以右上角要变成负一。把二者相乘，主对角线为一，右上角的一与负一抵消，才得到单位矩阵。若照逐元素取倒数的想法，候选仍是原矩阵，连做两次会继续错切，右上角变成二，显然没有恢复原状。求逆不一定每次都用同一种工具。二阶可以用公式，小规模可以用伴随矩阵，系统计算常用增广表消元。无论选哪种，最后的定义都一样。还要检查行列式是否为零，不能为了写出一个逆，就对零进行除法。下一章把独立方向的数量正式称为秩，用它统一解释压扁、不可逆和方程组自由程度。

## 线性相关与矩阵的秩

题目：00:31:19；答案：00:31:49

矩阵的三列依次是一和二、二和四、三和六。请判断秩是多少，再指出一个极大无关组。你可以观察列之间的倍数，也可以先把第二行减去第一行的两倍。注意矩阵只有两行，秩本来就不可能达到三；但上界是二，不意味着实际一定等于二。请独立思考四秒。

**答案：** 秩为1；任意一列单独构成一个极大无关组。

**解析：**

秩是一。第二列是第一列的两倍，第三列是第一列的三倍，所以只需要保留一个非零列方向。第一列单独就构成一个极大无关组。选择第二列或第三列也可以，因为它们同样非零，都能表示其余两列。极大无关组不唯一，但这些选法都只有一个向量，秩是同一个数。请回想，刚才同一个事实被我们用三种方式看到：图上三支箭头共线，列之间存在倍数关系，消元以后只有一个非零行。这些角度应当得到一致答案。以后一个结果和图形明显冲突时，不要急着背下一条公式，先检查对象、尺寸和运算过程。现在用秩来讨论，什么时候方程组有解，以及解为什么有时会形成一整条线。

## 线性方程组与解的结构

题目：00:36:29；答案：00:36:59

一个实数线性方程组有三个未知数。系数矩阵的秩是二，增广矩阵的秩也是二。它无解、唯一解，还是无穷多解？若改成右边全为零的对应齐次系统，基础解系里应该有几个向量？先把判断拆成两步：两个秩是否相同，以及这个秩是否达到未知数个数。

**答案：** 无穷多解；对应齐次系统的基础解系含1个向量。

**解析：**

两个秩相同，说明有解；但秩二小于未知数个数三，所以有一个自由变量，在实数范围内有无穷多解。对应齐次系统的基础解系包含三减二，也就是一个向量。一个向量不是一个解的意思，而是一个基础方向；这个方向的任意实数倍，都给出一份齐次解。以后求通解，可以照这个顺序做：写增广矩阵，消元，检查矛盾行，辨认主元与自由变量，再把参数形式整理成向量形式。齐次时找基础解系，非齐次时再加一个特解。每一步都能回到原方程代入核对。接下来我们不再只问能到哪里，而是寻找一种特别的方向：经过矩阵以后，方向所在的直线仍然不变。

## 特征值与相似对角化

题目：00:42:46；答案：00:43:17

矩阵还是主对角线为二、另外两个元素为一。向量是一和负一，请判断它是不是特征向量，如果是，对应特征值是多少。再思考，它和一、一组成的向量，能否一起作为对角化使用的新基。建议先真正做一次矩阵乘法，不要因为两个向量长度看起来一样，就给出相同的特征值。

**答案：** 是特征向量，特征值为1；它与(1,1)线性无关，可作为对角化的新基。

**解析：**

矩阵乘上它，仍得到一和负一，因此对应特征值是一。另一支一和一对应特征值三。两支不共线，所以线性无关，可以一起构成新基。放到 P 的列里面，就能把 A 化为对应顺序的对角矩阵。它们的长度相同并不是关键，决定倍率的是 A 作用在各自方向上的具体结果。这个例子还有一个额外的好处，两支特征向量正好垂直。把它们都缩成单位长度后，换坐标时可以保持长度和夹角。这不是任意可对角化矩阵都自动具有的性质，而和本例矩阵对称有关。下一章先把垂直、投影和正交化的计算补齐，再解释实对称矩阵为什么能使用这样整齐的坐标。

## 内积与正交变换

题目：00:47:58；答案：00:48:28

向量一和一，与一和负一，彼此垂直。如果直接把它们作为两列，得到的矩阵就是正交矩阵吗？请区别一组向量互相正交，和一张方阵是正交矩阵这两句话。你可以算每列与自己的内积，检查转置乘自身，得到的是 I 还是别的矩阵。请独立思考四秒。

**答案：** 不是；PᵀP=2I。两列分别除以√2后才得到正交矩阵。

**解析：**

不是。两列内积为零，但各自长度都是根号二，所以转置乘自身得到二倍 I。把每一列都除以根号二，列与自身内积才成为一，得到真正的正交矩阵。这里不是把垂直性否定了，而是正交矩阵这个名称，还包含了列向量单位长度的要求，两个条件都要满足。这一章我们从内积判断垂直，用投影拆出分量，再通过减投影与单位化建立整齐的新坐标。对于实对称矩阵，这套坐标还可以取在特征方向上。下面研究二次型时，同样的矩阵会决定一个曲面的形状，而旋转到这些特征方向，就能让混在一起的交叉项消失，公式和图形将再次对应起来。

## 二次型与坐标变换

题目：00:53:13；答案：00:53:44

二次型是 x 平方加四倍 x y，再加三倍 y 平方。请写出它对应的实对称矩阵。主对角线的两个数分别来自哪里？两个非对角位置应该填四，还是各填二？你可以反过来，把 x 的转置乘矩阵再乘 x 展开，看交叉项最后被加了几次。请独立思考四秒。

**答案：** 对称矩阵为[[1,2],[2,3]]，非对角线各填2。

**解析：**

两个非对角位置各填二。展开时，左上角贡献 x 平方，右下角贡献三倍 y 平方，而两个对称位置分别贡献二倍 x y，加起来才是四倍 x y。若两处都填四，就会得到八倍 x y，改变原题。把矩阵展开核对，是比单独背交叉项除以二更可靠的检查方式。这张对称矩阵的行列式是负一，因此两个实特征值一正一负，曲面有向上也有向下的方向，不是一只处处向上的碗。这里先看到形状，下一章正式定义正定。二次型问题的起点是把矩阵写对，之后的特征值、正交变换和正定判断，才会建立在正确对象上，不能跳过这一步。

## 正定判断与综合回顾

题目：00:57:30；答案：00:57:58

最后一题，实对称矩阵的主对角线都是一，另外两个元素都是二。它是否正定？你可以计算第二个顺序主子式，也可以试试一和负一这个向量。请注意，检查一个向量得到正值，不能证明所有方向都为正；但只要找到一个非零向量使结果不为正，就能否定正定。

**答案：** 不是正定；行列式-3，且向量(1,-1)代入得到-2。

**解析：**

它不是正定。第二个顺序主子式是一减四，等于负三，已经不符合要求。再把一和负一代入，得到一减四再加一，等于负二，也直接找到了一个非零反例。图上曲面沿这个方向下降，而另一个方向上升，是鞍形。对角线元素为正，只检查了坐标轴方向，没检查轴之间的组合方向。这也提醒我们，线性代数经常研究方向怎样组合，不能只看几个孤立数字。判断之前先核对对象：是否方阵，是否实对称，变量有几个，允许怎样变换。然后再选择行列式、秩、特征值或主子式。公式不是越多越好，而是要知道当前问题需要什么信息，以及某个条件究竟能推出多强的结论。
