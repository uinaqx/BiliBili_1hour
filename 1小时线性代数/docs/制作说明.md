# 制作说明

## 内容和图形

`content/author.py` 定义章节、页面、旁白段落、公式、图形参数和练习。`chapters_a.py` 至 `chapters_e.py` 各包含两章，`actions.py` 保存具体话语触发的操作。

每页有一至两个主要讲解状态；画面先给直观对象，再解释术语。多数二维图形使用真实坐标，三维解直线和曲面使用明确标注的投影示意。矩阵元素、乘积、余子式、秩和二次型高度均由数据计算。

`scripts/draw.py` 提供向量、网格、行列式面积、矩阵乘法、转置、排列、余子式、消元、秩、解集、特征方向、正交基、投影、二次型等高线和曲面的绘制函数。图形的最终状态持续保留。

## 声音和时间轴

本版由 126 个独立旁白段落组成，再拼成 68 页最终 WAV。音频采样率 24kHz，页面最终声音已含句间额外 0.1 秒。最终合成对章节响度归一，导出 48kHz 单声道 AAC。

本地声学对齐结果在 `build/alignment/`；页面 JSON 记录最终 WAV 的采样数、段落起点、声学起音点和插入停顿。`timeline.py` 将人工语句锚点映射到插入停顿后的最终音频坐标，并量化到 30fps 时间格。

不要先修改语速再沿用旧时间轴。旁白改变时重新配该段，执行 `prepare_audio.py`，再重建时间轴、渲染和验收。未改旁白则可以使用工程包里的最终 WAV 重导。

## 渲染和恢复

`render.py` 分章生成画面，动画区间逐帧输出，静止区间持帧。默认四个进程并行渲染，各章分别缓存视频与音频，再合成为带十个章节标记的 H.264/AAC MP4。

缓存依赖图形代码、渲染代码、字体和章节时间轴，时间轴含音频散列。重新运行相同命令可跳过已经验证指纹的章节；修改后的章节自动使用新的缓存目录。跨机器字体改变时应重渲并查看公式、中文和图形，不直接沿用旧图像缓存。

`preview.py` 生成 90 秒内部试片，涵盖不同类型的数学运动、题目与答案。`layout_review.py` 输出全部旁白状态的画面联系表；这是画面检查，不能用合成的测试时间轴冒充最终成片。

## 验证命令

```powershell
python scripts/verify_math.py
python scripts/check.py
python scripts/render.py --workers 4
python scripts/check.py --final
python scripts/check_audio_placement.py
python scripts/speech_spotcheck.py
```

`check.py --final` 对比成片解码画面，而非只检查课程 JSON。检查每个动画区间的所有计划时间点确实存在；抽取每段切换前后、运动中间和终态、题目倒计时；分别对图示区和公式提示区比较图像误差，防止大面积静态背景掩盖小图形错误。另执行全片解码。

`check_audio_placement.py` 在成片 AAC 中独立定位每段首尾的波形，检验音轨实际位置。`speech_spotcheck.py` 只抽听审三个 18 秒段落对应的本地转写，不声称逐分钟人工听过全片。

## 交付和隐私

`document.py` 从最终时间轴生成章节目录、覆盖表和答案；`package.py` 采用文件白名单打包，并扫描 API Key、Workspace ID 形态及 ZIP CRC。

工程包包含讲稿、原始知识点提纲、绘图与合成代码、最终声音和同步数据、数学与成片检查报告。排除在线服务的原始返回、私有调用工具、真实环境文件、聊天记录、用户源目录路径、模型权重、大量渲染缓存和第三方安装包。

本版没有字幕轨和烧录字幕，右侧公式与要点是教学内容的一部分。保留其持续显示即可，无需逐句做字幕同步。
