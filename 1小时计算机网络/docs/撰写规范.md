# 《一小时学完计算机网络》内容撰写规范

目标是 60±5 分钟的课程视频。全课 10 章、80 页、约 141 个讲解段落。最终时长由实测配音决定，所以篇幅必须按这里的字数写，不能随意加长。

## 文件归属

- 每位内容作者只写自己的一个文件：`content/chapters_b.py`、`chapters_c.py`、`chapters_d.py`。
- 不要改 `author.py`、`build_course.py`、`validate_chapter.py`、`scripts/` 下任何文件，也不要改别人的章节文件。
- 写完必须运行验证：`python scripts/validate_chapter.py chapters_b`（换成自己的模块名），要求输出 `CHAPTER_MODULE_OK`。

## 作者 API（`from author import *`）

```python
c = C('第二章标题')                      # 开始一章，标题 4-24 字
T(标签, 行文本)                          # 普通行：标签 ≤20 字，行文本 ≤70 字
P(旁白, focus, notes, show=None, phase='first', anchor=None)
S(c, '页面标题', [行...], [P(...), P(...)], ['标签'], kind='lesson', visual=G('图示名'))
```

- `P` 的 `focus` 是本段讲解时持续高亮哪些行（行号从 1 开始），`show` 是显示到第几行（默认高亮最大行号）。
- 每页最后一段的 `show` 必须等于本页行数（作者函数会断言）。
- `notes` 是右侧 1-3 条要点，每条 ≤30 字，不要写整句长文。
- `anchor`：图示页每段必须给，是这段旁白里**只出现一次**的短语，画面动画从这句真正被读出时开始（不要写「第一句」这类位置描述，写实词短语）。
- `visual=G('kind')` 只写图示类型，图示内部数据固定在 `scripts/examples.py`（见下方标准数值），不要自己编数字。
- `kind='question'` 为练习页（播放后停 4 秒思考），`kind='answer'` 为答案页；每章各一页，且答案页紧跟练习页。

## 硬性结构（验证脚本会检查）

- 每章 8 页：6 页 `lesson` + 1 页 `question` + 1 页 `answer`。第 1 章已经是 overview + 5 lesson + 练习 + 答案，由 Lead 负责，你不要写第 1 章。
- 每个 `lesson` 页**必须恰好 2 个段落**；`question`/`answer` 页恰好 1 个段落。
- 每个段落 100-155 字（目标 110-125 字），以句号结尾。一句话不要写太长。
- `lesson` 页旁白总量 225-300 字；`question` 页 95-140 字；`answer` 页 100-155 字。
- 每章旁白总量 1570-1780 字（目标约 1650 字）。写多写少都会报错，请按页调整。
- 每章 1-2 页图示（见各章页面清单）。图示页行数 ≤3，且两个段落都要 `phase` 和 `anchor`。
- 旁白里不要用问号、感叹号（停顿只处理句号）；不要用 `[ ] { } \ # * \` < > |` 等字符；不要用「」或引号包裹整句。
- 行文本里可以写 `TCP`、`192.168.1.0` 这类术语和数字，语音会把它们读出来。

## 文风（照 `content/chapters_a.py` 学）

- 先给具体小场景或小例子，再抽规则，最后给术语名称。术语第一次出现时用一句话解释。
- 口吻像耐心、循序渐进的老师。用「先看」「再看」「这里有个常考点」「做计算题时」这类过渡，不要播音腔。
- 每页两个段落分工：第一段讲「看到什么、怎么变化」，第二段讲「规则、易错点、和相邻概念的对比」。
- 概念页要有对比辨析（例如发送时延 vs 传播时延、流量控制 vs 拥塞控制）；计算页要有题设、步骤、结果、检查方法。
- 不堆砌定义，不逐条朗读行文本；旁白要比行文本更口语、更有解释。
- 每章练习页出 2 个判断/计算小题（旁白里陈述题目，不出问号），答案页给答案 + 依据 + 检查方法。

## 标准数值（必须与图示、验证脚本一致）

- 第 2 章：波特率 2000、16 种码元 → 4 bit/码元 → 8000 bps；带宽 3 kHz、SNR=30 dB → S/N=1000 → 香农约 29.9 kbps。
- 第 3 章：以太网帧 = 目的 MAC 6B + 源 MAC 6B + 类型 2B + 数据 46～1500B + FCS 4B；最小帧 64B、最大 1518B；示例拓扑冲突域 3、广播域 1。
- 第 4 章：192.168.1.0/24 划四个 /26；子网 2 = 网络 192.168.1.64、广播 192.168.1.127、可用 .65-.126；202.101.0.0/24 起四个连续 /24 聚合为 202.101.0.0/22；私有地址 10/8、172.16/12、192.168/16；环回 127/8；链路本地 169.254/16。
- 第 5 章：4000B 数据报（首部 20B、数据 3980B）、MTU 1500 → 3 片：1500B（数据 1480）、1500B（数据 1480）、1040B（数据 1020）；片偏移 0、185、370；MF 1、1、0。NAT：192.168.1.10:3000 ↔ 202.1.1.1:40000。协议号 ICMP=1、TCP=6、UDP=17；TTL 64 经 3 个路由器后 61。
- 第 6 章：路由表见练习；最长前缀匹配优先；RIP 最大跳数 15（16 视为不可达）、每 30 秒更新；OSPF 用链路状态与 Dijkstra；BGP 是 AS 间路径向量协议。
- 第 7 章：SYN seq=1000 → SYN+ACK seq=5000、ack=1001 → ACK ack=5001；挥手 FIN seq=2000 → ACK 2001 → FIN seq=6000 → ACK 6001；TIME_WAIT 等 2MSL。端口：0-1023 知名端口，HTTP 80、HTTPS 443、DNS 53、DHCP 67/68、FTP 21 控制 20 数据、SMTP 25、POP3 110、SSH 22。

- 第 10 章：RTT=20ms，DNS+TCP 握手+HTTP 请求响应 = 3 RTT ≈ 60ms；HTTPS = HTTP + TLS。
