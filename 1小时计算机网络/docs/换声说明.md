# 计算机网络课程换声版

本版按用户指定，将原课程配音换为阿里云百炼 `qwen-audio-3.1-tts-plus`、许南川 `xunanchuan_v3.1`，原生合成速率为 **1.05**。后期速度保持1.0，不再进行额外变速。

课程仍为原有10章、80页、139段讲解、10道练习。讲稿、题例、绘图组件、布局和持续高亮逻辑与原版逐项核对一致，来源哈希保存在 `换声版本来源.json`。许南川的实际朗读时长与原配音不同，按新音频重新生成了翻页、高亮切换、动画触发和章节时间。本版实测总时长为 **01:05:05.400**。

373处内部句号和139个段尾句号各额外增加0.1秒，合计51.2秒；逗号保持原样。保留原有语音样本和4秒思考安排。百炼把部分数字展开为中文读法，`content/voice-anchor-aliases.json`逐项记录4处明确的动画触发文字对应，未改写教学内容或动画状态。

较长的IPv4短语另做了短窗口声学对齐复核，见 `build/route-anchor-review.json`。原始词时间与声学对齐存在差异时采用最终音频的声学定位；该对比不能单独作为每个音素准确度的证明。正式验收范围及对应成片哈希见 `验收记录.md`。

原版工程及原版视频保留在原目录。本版使用独立制作工程和独立交付文件夹，工程包不含真实API Key、Workspace ID或私有账号加载器。
