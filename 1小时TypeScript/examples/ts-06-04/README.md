# 给泛型添加需要的能力

一个泛型函数需要读取length，就把这项能力写进约束。T extends后面说明传入类型需要带有数字length属性。函数体依据这份要求读取长度并返回。约束把实现真正需要的内容交代清楚，让函数既能接受不同类型，又有足够的信息完成当前操作。

字符串hello拥有长度属性，所以返回五。三项数字数组同样拥有长度属性，所以返回三。这里关注的是共同能力，而不是先把所有允许的具体类型列成清单。编写泛型时，先问实现究竟要对参数做什么，再给出相应约束，通常比一开始就安排复杂的类型表达式更容易得到清楚的接口。

## 本页总结

- extends 在这里约束类型参数
- 传入值需要具备数字 length
- 函数只使用声明过的能力
- 文字与数组都能满足这项要求

## 预期输出

5
3
