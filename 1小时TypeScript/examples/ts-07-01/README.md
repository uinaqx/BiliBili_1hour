# 把数据与方法组织成类

如果希望把余额和修改余额的操作放在一起，可以定义Wallet类。balance保存这个对象的余额。constructor是构造函数，创建对象时接收初始数字，并用this点balance把它保存到当前对象。this可以先理解成这一次正在处理的对象，让同一套方法能操作各个对象自己的数据。

add方法接收金额，加进当前余额。返回类型void表示这里主要使用方法产生的操作效果。通过new创建钱包，起始余额十。调用add增加五。最后读取余额，得到十五。类把字段和相关操作集中组织起来，调用者通过对象来使用它。先跟踪一个对象的创建和一次方法调用，再扩展到多个对象，就容易看清它们各自保存的状态。

## 本页总结

- class 定义一类对象的结构和操作
- constructor 准备每个对象的初始数据
- this 指向当前这一个对象
- void 表示调用者主要使用操作效果
