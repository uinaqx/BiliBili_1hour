# type 为数据形状起名字

type后面写Expense，就是给名称和金额组成的这份类型说明起名字。名字本身用于检查阶段，方便在代码里重复引用。label函数接收一条Expense记录，返回字符串。模板依次读取名称和金额，组合成适合显示的文字。把类型定义和处理函数放在一起，读代码的人很容易找到这项工具需要哪些输入。

调用时提供名称午餐和金额十二，对象满足Expense描述的形状，于是得到午餐冒号十二元。以后增加统计、筛选或保存函数，都可以继续把参数写成Expense。类型别名还可以为联合类型、数组和元组起名字。先给经常重复的数据结构一个稳定名称，再围绕它编写操作，整个程序的表达会越来越一致。

## 本页总结

- type 为一个类型表达式命名
- Expense 可重复用于参数与变量
- 函数内部按字段类型继续处理
- 模板字符串整理显示文字
