# 练习：一次调用完成几步计算

这道题把函数和循环放在一起。total接收数字数组，在内部准备累计变量sum。循环把各项加进去，再返回最后的总和。外面交入十二和八，还在函数调用后面接着乘二。请预测最终显示什么。先在调用处停一下，进入函数算出返回值，再把它带回外面的表达式。

sum从零开始，先加十二，再加八，得到二十。return把二十交回调用处。于是外层实际处理的是二十乘二，最后显示四十。类型检查确认交入的是数字数组，返回值也能继续参加数字运算。值的计算顺序仍然要沿程序一步一步走。用输入、函数内部变化和返回值这三个位置做记录，就能读懂这类组合题。

## 本页总结

- 参数是一组数字
- 函数内从 0 开始累计
- 返回总和 20
- 外层接着乘 2 得到 40

40
