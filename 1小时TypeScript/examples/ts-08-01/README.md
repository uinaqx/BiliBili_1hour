# 枚举为一组状态命名

除了把状态写成字符串字面量联合，还可以使用枚举，为一组值提供统一命名入口。这里Status包含Pending和Paid两个成员，各自指定对应文字。代码通过Status点成员名取得值，编辑器也能提示这组候选项。先明确每个成员的实际值，再观察它怎样交给变量和函数使用。

current被声明为Status，接收Status点Paid。运行时显示它对应的文字paid。普通枚举还会生成供运行时使用的对象，因此可以通过名字读取成员。字符串字面量联合侧重直接描述允许值，枚举则提供统一的成员入口；项目可以根据组织习惯选择。初学时先把示例中采用的这套方式保持一致，状态代码就比较容易查找。

## 本页总结

- enum 为一组成员提供命名入口
- 字符串枚举明确各成员的值
- 通过枚举名读取对应成员
- 普通枚举会生成运行时对象

## 预期输出

```text
paid
```
