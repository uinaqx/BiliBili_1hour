# 继承与 override

Report先提供一个title方法，返回开销记录。MonthlyReport通过extends继承它，再安排本月报表需要的行为。override标明这里重写基类已经有的方法，工具会据此核对对应关系。继承适合让几种对象共享一部分能力，再在各自的位置补充差异，阅读时先找到基类提供了什么。

派生方法通过super调用基类的title，先得到开销记录，再接上本月这段文字。创建MonthlyReport并调用title，最后显示开销记录冒号本月。继承把对象关系写进结构中；简单地复用几个独立计算步骤，也可以继续使用普通函数。先选择最容易表达当前关系的组织方式，再逐步补充类型和方法，避免为很小的需求安排过深的层级。

## 本页总结

- extends 建立派生关系
- 派生类可以补充或重写方法
- override 标明对应基类已有方法
- super 调用基类提供的实现
