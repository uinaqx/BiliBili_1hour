# 练习：处理异步查询

这一题把前面几章连起来。Result 有两种情况，成功带金额，失败带说明。查询函数暂时直接给出成功结果，金额十二。主函数等待结果，再检查 ok。请先沿着实际返回的对象走一遍，判断执行哪一行，最终输出多少。先看清状态，再选择对应字段，整个过程和普通条件判断是一样的。

答案是二十。await 取得成功对象，ok 为真，于是使用 amount 加八。如果把查询结果改成失败对象，另一条分支会读取 message。状态和数据放在同一个联合类型里，编译器就能跟随状态判断，提醒我们选用正确的字段。这种返回结构很适合表达常见业务结果，抛出异常则适合交给外层统一处理的失败。

## 本页总结

- await 后得到 Result，随后按 ok 区分情况
- 成功分支读取 amount，失败分支读取 message
- 联合类型同时约定状态和状态对应的数据
- 输出二十，成功路径完成一次金额计算
