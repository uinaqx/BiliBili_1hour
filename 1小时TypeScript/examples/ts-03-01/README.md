# 先整理类型，再完成运算

用户输入的金额经常先以文字形式出现。raw保存引号里的十二，类型是string。调用Number把它整理成数字以后，amount就按number继续处理。把数据类型整理清楚，再决定后面的运算，是输入处理里很实用的一步。你可以在编辑器中停留到变量名上，查看工具推断出的类型和相关操作提示。

十二加八得到二十，total接住这个数字，显示结果也是二十。再检查它是否小于等于三十，得到真假值true。加减乘除返回数值，比较表达式返回真假，类型信息沿着每一步的结果继续传递。写程序时，先明确输入是什么，再看当前操作返回什么，最后决定把结果交到哪里，就能把一条较长的表达式拆开阅读。

## 本页总结

- Number 把合适的文字转成数字
- 加法在数字上得到金额总和
- 比较运算返回 boolean
- 变量推断沿计算过程继续传递
