# 类型断言与真正的数据转换

unknown表示我们暂时还没有确认这份数据的具体类型。本例在代码里已经知道它是文字十二。通过as string，把这个已知信息提供给检查工具，后面text就按字符串来检查。类型断言适合你有明确依据、需要向工具补充说明的位置；项目中从外部取得未知数据时，可以先做实际检查再继续使用。

Number才负责运行时的转换，把文字十二整理成数字十二。显示text的类型名称，仍然是string。显示amount的类型名称，是number。amount再加八得到二十。读代码时把这两个步骤分开标注：as说明后面怎样检查，Number实际计算一个新值。有这条清楚的路线，看到更长的类型断言表达式时也容易判断数据在哪里变化。

## 本页总结

- unknown 接收暂未确认的数据
- as 提供检查阶段的类型信息
- Number 在运行时进行数字转换
- 转换和断言各自承担不同步骤
