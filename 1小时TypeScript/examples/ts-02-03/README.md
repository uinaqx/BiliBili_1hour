# 元组给不同位置安排类型

有时一组数据的位置含义固定，例如第一项是名称，第二项是金额，可以写成元组。方括号里依次写string和number，就是分别安排这两个位置的类型。读取下标零时，工具知道这里得到文字。读取下标一时，工具知道这里得到数字。每个位置携带自己的类型信息，使用方法也就跟着清楚了。

name可以调用字符串方法，午餐经过转大写仍然显示午餐。amount参加数字加法，十二加八得到二十。元组适合少量、位置稳定的数据组合。字段增多，或者阅读时更希望通过名字理解用途，就可以改用对象。我们会把同一笔开销写成对象记录，比较按位置读取和按属性名读取的两种表达。

## 本页总结

- 元组为每个位置指定类型
- 第 0 项按 string 处理
- 第 1 项按 number 处理
- 适合位置含义固定的小组合

## 预期输出

```text
午餐
20
```
