# 练习：在严格检查下处理空值

项目的tsconfig保存共同的检查和生成选项，strict用于打开一组严格检查。这里函数允许接收字符串或null，却直接读取text点length。请判断检查工具会提示哪种可能情况，以及怎样给这条路线安排一个明确的返回结果。当前调用交入null，你可以从输入开始跟踪，先找出读取发生以前缺少的步骤。

修正版先检查text是否为null，空值时直接返回零，有文字时再读取长度。本次调用因此显示零。配套项目还使用noEmitOnError，让检查失败时先修正再生成，target选择生成代码版本，module安排模块输出方式。刚开始先用课程提供的固定配置，把注意力放在错误位置和处理路线，再逐项理解配置怎样影响自己的项目。

## 本页总结

- strict 打开一组严格类型检查
- text 可能为 null 时要安排处理
- 先判断空值，再读取 length
- 修正版对空值返回 0
