# 循环处理一组开销

准备三笔开销，再让total从零开始。循环每次取出一项，用amount这个名字处理它。因为expenses是数字数组，amount会被推断为数字。每一轮执行加等号，把当前金额加进累计值。你可以先只看一轮：拿到什么、做了什么、累计怎样变化，再让同一条规则处理剩下的数据。

第一轮取十二，累计变成十二；第二轮取八，累计变成二十；第三轮取五，累计变成二十五。数组读完以后显示最终总额。循环体里也能先写一个if，只累计符合条件的记录。传统for循环适合按下标控制位置，while适合围绕一个持续检查的条件工作。这里先熟悉逐项处理，让后面的对象数组和回调函数有一个具体的参照。

## 本页总结

- for...of 逐项取得数组元素
- amount 的类型随元素推断为 number
- total 从 0 开始累计
- 每轮结果依次为 12、20、25

25
