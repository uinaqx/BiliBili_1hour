# 先检查未知数据

外部数据可能来自用户输入，也可能来自服务器。我们先用 unknown 接收，意思是现在还没有确认具体内容。这个函数的任务非常明确，最后交回一个数字。如果 typeof 检查得到 number，就原样返回。检查表达式同时帮助我们和编译器看清当前分支里是什么数据，后面的操作也就有了依据。

其他情况统一返回零，这就是本页约定的处理策略。第一次传入数字十二，结果是十二。第二次传入文字十二，结果是零。观察两次调用，值的外观接近，类型却决定了不同路线。如果业务允许数字字符串，可以增加一个转换分支，再检查转换结果是否为有限数字。规则由函数清楚地表达出来。

## 本页总结

- unknown 接收任意来源，使用前先判断类型
- typeof 判断后，分支里的值收窄为 number
- 检查失败时返回默认值，结果类型保持一致
- 数字字符串需要明确选择转换策略
