# 只读数组表达读取用途

有些函数只需要读取一组数据，可以把它标为readonly数组。这里source保存十二和八，这个名字提供的是只读访问方式。如果希望基于它新增记录，就用展开语法创建一个新数组copied。再向新数组push五。把读取来源和准备修改的结果分开，调用者就容易看出当前操作会动到哪一份数据。

显示source，仍然得到十二和八。显示copied，得到十二、八、五。只读类型让工具在检查阶段限制通过这份引用进行修改；这里的展开则实际建立了一个新的顶层数组。读代码时把类型约定和数据变化分别记清，就能判断一处函数调用是只观察数据，还是会产生一份更新后的记录。

## 本页总结

- readonly 数组用于只读访问
- 展开语法生成新的顶层数组
- 在新数组中添加数据
- 原数组和新数组分别显示
