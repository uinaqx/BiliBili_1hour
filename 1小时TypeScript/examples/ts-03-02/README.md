# 用 if 选择处理路线

有了总额和预算，就可以决定显示哪一种提示。if括号里检查二十五是否小于等于三十，条件成立，程序进入紧接着的大括号。这里显示预算内。大括号把同一条路线上的操作放在一起，缩进帮助我们看清它属于哪个条件。先找条件，再看对应的执行路线，是阅读分支结构的基本顺序。

如果把总额改成三十五，就会进入else这一支，显示超出预算。每次运行根据当时的数据选择路线。写完以后可以用二十九、三十和三十一分别测试，确认边界值三十的分类符合需求。多个条件还可以使用else if依次检查。类型帮助描述数据范围，分支则依据这一次实际的值，决定接下来执行哪些操作。

## 本页总结

- if 根据条件选择分支
- <= 返回一个真假结果
- 大括号组织同一路线的语句
- else 处理另一种情况
