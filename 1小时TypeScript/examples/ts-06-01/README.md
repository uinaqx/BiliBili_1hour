# 默认参数与可选参数

greet接收姓名和前缀，前缀默认采用你好。只传姓名时，函数就能完成常见的问候；需要其他前缀时，再显式传进去。模板把前缀和姓名连接成一段返回文字。默认值还能帮助工具推断参数类型，这里prefix从字符串默认值取得清楚的检查信息。

note的参数后面使用问号，表示调用时可以省略。函数里用默认文字处理undefined，让出口始终返回string。调用greet并传入小林，得到你好，小林。不提供备注时，得到暂无备注。设计函数入口时，先决定哪些数据必需、哪些有常用默认值、哪些可以缺省，再把这些安排写到参数中。

## 本页总结

- 默认参数提供常用起始值
- 可选参数使用 ? 标记
- 省略参数时要处理对应情况
- 返回类型保持明确

## 预期输出

```text
你好，小林
暂无备注
```
