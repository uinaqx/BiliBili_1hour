# readonly 与结构匹配

readonly放在属性前面，表示通过这份类型说明读取名称，保持只读用途。source对象除了name还有amount。把它交给Named类型的view时，检查工具关注需要的name字段是否存在，以及它是不是字符串。这里所需结构满足，所以可以建立这个视图。我们把这种按需要的属性结构来匹配的方式，称作结构类型检查。

view按Named提供的能力读取name，显示午餐。source仍然保留完整记录，可以读取金额十二。赋值让两个名字引用同一个对象；类型视图描述的是当前代码打算通过它使用哪些能力。直接书写对象字面量时，工具还有额外属性检查来帮助发现字段拼写问题。遇到提示就回到需要的字段和实际提供的字段，逐项核对。

## 本页总结

- readonly 限制通过该类型写入属性
- Named 只要求字符串 name 字段
- 已有对象可按所需结构匹配
- view 与 source 仍引用同一个对象
