# 从一个有类型的程序开始

同学们好，欢迎来到一小时学完TypeScript。我们从保存一笔金额开始，逐步写出带类型的函数、记录数组和开销管理工具。课程先补齐运行程序需要的基础，再认识类型怎样帮助我们整理数据和检查调用。每页都有可以亲手运行的代码，跟着预测结果、检查提示、改动一个条件，就能逐步建立自己的使用经验。

画面里的budget和spent分别保存预算三十与开销二十五。名字后面的冒号加number，说明这里准备使用数字。你可以先把类型理解成写给检查工具的一份数据说明。最后一行读取两个数字，相减得到五，再显示在控制台。我们会把每个例子分成写代码、检查和运行三个步骤，沿着具体结果理解语法。
