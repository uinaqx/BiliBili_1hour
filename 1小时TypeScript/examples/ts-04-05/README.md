# 对象数组与条件筛选

把Expense后面加上数组标记，就能描述多条开销记录。这里准备午餐十二元和交通八元。filter回调中的item会被推断为Expense，因此读取amount时，工具知道得到数字。金额达到十才保留，这个条件留下午餐那一条。每一层类型信息都有来源，数组传来元素类型，对象又提供属性类型。

筛选以后仍然是一组Expense记录，继续用map取出各条名称，再连接成文字，最后显示午餐。阅读这种连续处理时，在每一步后写出当前数组里有哪些记录，下一步读了哪个属性。类型检查协助我们选择合法的操作，具体保留哪些项则由运行时的条件决定。数据结构明确以后，筛选、汇总和页面展示都可以围绕同一种记录组合。

## 本页总结

- Expense[] 保存多条同形状记录
- 回调参数被推断为 Expense
- 按 amount 筛选后仍得到记录数组
- map 提取各条记录的名称

## 预期输出

```text
午餐
```
