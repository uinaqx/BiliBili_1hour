# Pick 与 Partial 复用已有结构

同一种记录会出现在完整详情、列表摘要和局部更新中，可以从原类型派生所需结构。Pick从Expense里选出name和amount，形成摘要类型Brief。Partial把Expense的各属性整理为可选，形成更新类型Update。先确定使用场景需要哪些字段、哪些可以省略，再选择对应的类型工具，关系就很具体。

brief提供名称和金额，适合列表显示。update只提供这次准备修改的金额十五。读取时分别显示午餐和十五。常见工具里，Omit按属性名排除字段，Readonly提供只读视图，Record按键类型安排对应值。它们都在复用已有的结构信息。入门先掌握选字段和设为可选这两种需求，再根据项目遇到的情况逐步扩展。

## 本页总结

- Pick 选取已有类型中的部分属性
- Partial 把各属性整理为可选
- 摘要对象只保留需要的字段
- 更新对象只提供本次准备修改的内容
