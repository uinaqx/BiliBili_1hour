# 静态成员与类本身的工具

有些信息适合放在类本身，例如这组开销统一使用的币种，可以声明为static成员。amount则属于每个具体对象，在创建时分别接收数值。静态zero方法安排一种常见的创建方式，直接返回金额为零的新对象。读静态和普通成员时，先确认调用位置是在类名后面，还是在具体对象后面。

Expense点zero通过类名调用，得到一条金额为零的记录。Expense点currency读取共享的币种文字CNY。item点amount读取这条具体记录的金额零。静态方法经常用于工厂入口或围绕这一类数据的工具，普通方法则处理某个对象自己的状态。把共享信息和实例状态分清，多个对象一起出现时也能判断每次读写影响哪一层。

## 本页总结

- static 成员通过类本身访问
- currency 表达这一类共享的信息
- 静态方法可以安排统一创建方式
- 普通 amount 属性属于具体对象
