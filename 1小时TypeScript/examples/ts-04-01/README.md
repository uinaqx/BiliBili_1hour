# 把一条记录写成对象类型

一条开销记录同时包含名称和金额，可以用对象把它们组织起来。冒号后面的对象类型写出两个属性：name按字符串处理，amount按数字处理。右边的对象提供具体内容，分别是午餐和十二。类型描述需要的形状，值提供这一次记录的数据，两边逐项对应，就能清楚看出这条记录有哪些信息。

读取expense点name，得到午餐。读取amount以后加八，得到二十。编辑器会根据对象类型提示属性名和方法，帮助我们减少拼写错误。字段较少时可以直接写在变量声明旁边；同一种记录会在多个位置使用时，就给这种类型起一个名字。下一页用type把这份说明单独保存，交给变量和函数共同使用。

## 本页总结

- 对象类型说明需要哪些属性
- 属性名称连接各自的数据类型
- 点号读取对应字段
- 每个字段支持的操作各有依据

午餐
20
