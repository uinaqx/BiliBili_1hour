# 练习：通过公开方法读取

这道题的钱包把amount标成private，内部先保存十二。同时提供一个read方法，返回内部金额。创建钱包以后，最后一行直接读取wallet点amount。请判断类型检查会指出哪一行，以及可以怎样利用现有的公开入口取得金额。给自己四秒，把字段的访问约定和调用位置对应起来。

修正版改成调用wallet点read。read在类内部访问amount，返回十二。外层再显示这个结果。访问修饰符让对象向外提供的能力更清楚，调用者按照公开入口使用，就能和类内部的维护方式配合。看到访问类字段的报错时，先查类定义，再找已经提供的公开方法，而不是急着改动整组字段的声明。

## 本页总结

- amount 是 private 字段
- read 是公开的读取方法
- 原调用直接访问了内部字段
- 修正为 wallet.read()
