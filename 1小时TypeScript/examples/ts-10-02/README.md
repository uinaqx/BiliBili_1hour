# 把统计写成独立函数

统计功能写成一个独立函数。参数是只读的开销数组，返回值是数字。这个约定告诉使用者，函数负责读取记录并计算结果。reduce 从零开始，每读到一条记录，就把它的金额加进累计值。这几行只关心数据计算，页面按钮和输入框可以留给另外的代码处理，职责清楚后测试也更直接。

先传入午餐十二和交通八，总额是二十。再传入空数组，结果是零。第二个例子对应用户刚打开页面，还没有添加记录的状态。以后增加分类统计，也可以保留这个函数，再写一个筛选函数选出目标记录。先用小输入和空输入验证结果，再把函数接到页面上，是很省力的开发顺序。

## 本页总结

- 统计函数接收只读数组，返回金额总和
- reduce 从零开始逐项累加 amount
- 空数组返回零，方便初始化页面
- 独立函数可在控制台和网页中共同使用
