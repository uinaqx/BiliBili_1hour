# 通过函数集中更新记录

有了数据和统计，再处理新增和删除。新增函数接收一条完整记录，用展开语法保留已有元素，把新记录接到末尾，再更新 items。删除函数只需要一个数字编号，用 filter 留下编号不同的记录。两种操作都生成新数组，页面刷新时读取当前的 items，就能看到最新状态。

现在按顺序添加十二元和八元两条记录，再删除编号一。数组里剩下编号二，所以输出八。请把代码中的编号和金额分开看，编号负责定位，金额负责计算。配套项目在更新完成后还会保存到本地存储，再重新绘制列表与总额。把这些步骤集中在更新函数附近，新增功能时更容易保持页面一致。

## 本页总结

- 新增使用展开语法生成更新后的数组
- 删除使用 filter 保留其他 id 的记录
- 参数类型约定每种操作需要哪些信息
- 集中更新后统一保存并刷新页面
