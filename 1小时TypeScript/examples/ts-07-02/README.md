# 访问范围与读取入口

这次把内部金额命名为amount，并标为private，类型检查会约束类外直接访问它的方式。增加金额统一通过add完成，方法在类内部读取和更新amount。get balance提供一个读取入口，外部用属性形式读取余额时，由这里返回内部数字。把写入和读取安排成明确入口，可以让对象的数据维护集中到类本身。

创建新钱包以后，amount从零开始。调用add并交入十二，内部金额变成十二。读取wallet点balance，得到十二。后面要增加金额检查或日志时，可以在方法中集中处理，而调用位置仍然按原入口使用。protected允许派生类在继承关系中使用相应成员，public则向使用者公开；先围绕实际需要的访问范围选择修饰符，类的职责会更清楚。

## 本页总结

- private 约束类外对字段的直接访问
- 方法在类内部维护 amount
- get 提供一个属性式的读取入口
- 调用者通过公开能力操作对象
