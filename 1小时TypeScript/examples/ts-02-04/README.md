# 用联合类型描述两种可能

编号有时使用数字十二，有时带着字母成为A十二，可以用联合类型描述。string和number之间的竖线，表示这个名字允许保存其中一种类型。开始赋入十二，先按照当前数字值继续处理。显示时得到十二。联合类型把真实需求写在声明中，让允许出现的几种情况有明确范围。

后来把A十二这段文字交给code，同样符合声明。再次显示就得到A十二。如果下一步要做文字转换或数字运算，需要先确认当前是哪一种情况，再使用对应操作。这个过程叫作收窄。先认识联合类型表达几种可能，等到条件判断章节，再用typeof把一条宽范围的路线拆成两个清楚的分支。

## 本页总结

- 竖线连接允许的类型
- code 可以保存 string 或 number
- 赋值仍需属于声明的范围
- 不同类型的操作要先确认分支
