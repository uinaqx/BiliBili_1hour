# keyof 约束可以读取的属性名

这一页把对象和属性名联系起来。T描述对象类型，keyof T取得它有哪些属性名，K再从这些名字里选一个。返回类型T方括号K，表示选中属性的值类型。函数体按照key读取对象中的值。读这条声明时，先看对象是谁，再看允许选择哪些字段，最后看所选字段会带出什么类型。

expense同时包含文字名称和数字金额。选择name时，调用结果按字符串处理，显示午餐。选择amount时，结果按数字处理，继续加八得到二十。检查工具还会约束传入的属性名称，帮助发现拼写错误。这个例子展示泛型怎样让两个参数和返回值共同保持一条具体关系，后面的类型工具也会沿用这种按字段推导的思路。

## 本页总结

- keyof T 取得 T 的属性名范围
- K 必须属于这组属性名
- T[K] 表示对应属性的值类型
- 返回类型随所选属性变化

## 预期输出

```text
午餐
20
```
