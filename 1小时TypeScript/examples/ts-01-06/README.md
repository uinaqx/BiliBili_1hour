# 基础类型与显示结果

价格十二用number表示，常见整数和小数都属于这一类。名称午餐用string表示，文字内容放在引号里面。是否付款用boolean表示，值只有true和false，可以先读成真和假。这三个基础类型，已经足够组织很多入门计算、显示和条件判断。先从右边的具体值出发，再认识左边写出的类型名称。

typeof在运行时查看一个值的类型名称，价格得到number。名称得到string。付款状态得到boolean。变量名帮助我们表达用途，类型帮助检查工具理解它支持哪些操作。类型标注和typeof分别服务于检查和运行两个位置，在后面按类型选择处理路线时，我们会让它们配合起来，逐步缩小一个值可能属于的范围。

## 本页总结

- number 表示常见数字
- string 表示文字
- boolean 表示 true 或 false
- typeof 在运行时取得类型名称
