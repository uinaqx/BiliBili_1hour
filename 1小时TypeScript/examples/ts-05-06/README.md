# 练习：根据类型选择格式

这道题的参数允许数字或文字。数字分支调用toFixed，并传入零，表示整理为零位小数。文字分支调用trim，去掉两端空白。请预测交入十二点六以及带两端空格的午餐时，各自返回什么。先确定每次进入哪条分支，再使用该分支对应的方法。给自己四秒，按两次调用分别推算。

十二点六进入数字分支，整理为零位小数，返回文字十三。带空格的午餐进入文字分支，trim返回午餐。两次结果都是字符串，符合函数出口的说明。这个例子把联合类型、运行时判断和不同方法连起来。以后参数允许多种形状时，也按先确认情况、再调用对应操作的顺序组织，函数就会既清楚又容易检查。

## 本页总结

- number 分支整理为 0 位小数
- string 分支去掉两端空白
- 12.6 显示为文字 13
- 第二次调用返回午餐
