# let、const 与类型推断

变量是程序里可以读取的名字。let total等于零，让total从数字零开始，检查工具会据此推断它用于保存数字。下一行先读旧total，再加十二，把结果交回total。等号在这里表示赋值，阅读顺序是先算右边，再更新左边。以后记录多笔开销，就可以沿着这个累计关系一步一步更新。

姓名user使用const，因为这段程序一直沿用同一个姓名绑定。初始化已经提供了清楚的信息，通常可以让工具推断类型；需要表达明确的接口或允许范围时，再写上类型标注。最后显示小林和十二。我们会让一个名字承担清楚的用途，例如金额一直处理数字，名称一直处理文字，让变量名和类型共同说明这份数据是什么。

## 本页总结

- let 适合后续重新赋值的变量
- const 保持同一个绑定
- 初始化值可帮助推断类型
- 先计算右边，再更新左边的变量
