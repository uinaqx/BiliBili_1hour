# 检查完整网页项目

配套网页工程已经把这些步骤连接起来。列表里的记录采用同一份 Expense 类型，提交表单时先检查名称和金额，成功后添加记录并更新总额。保存时把数组转成 JSON 文字，读取时再解析回来。取回的数据依然经过数组和字段检查，这样页面使用的始终是确认过形状的记录。

这一页的小例子显示解析结果确实是数组，总额是二十。完整项目的使用顺序是，先编译，再启动本地服务，打开页面测试。试着新增两条记录，删除一条，刷新页面看看剩下的数据。再输入空名称、负数和非数字，观察提示。README 里给出了具体命令和目录位置，所有示例也都可以单独运行。

## 本页总结

- JSON.stringify 保存数组，JSON.parse 取回运行时数据
- 本地存储读回后同样执行完整字段检查
- 网页工程包含新增、删除、统计和持久化
- 按首次打开、合法输入、错误输入、刷新顺序检查
