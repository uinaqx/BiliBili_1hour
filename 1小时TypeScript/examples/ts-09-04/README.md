# 验证 JSON 中的对象

现在处理一条服务器传来的开销记录。我们写一个检查函数，参数是未知值，返回位置写 v is Expense。这种写法把函数的检查结论传给调用者。函数依次检查它是非空对象，包含 name 和 amount，并且姓名是字符串，金额是数字。这里每一项都对应后续代码真正要使用的内容，读起来就是一份数据检查清单。

JSON.parse 把字符串解析成运行时的值，我们先把结果放进 unknown。通过检查函数以后，当前分支就能按 Expense 使用，输出午餐和十二。类型声明描述期望的数据结构，这段检查负责确认实际收到的内容。项目中可以把这样的函数集中保存，让网络请求、本地存储和表单导入共用同一套规则。

## 本页总结

- JSON.parse 的结果先交给 unknown 接收
- 依次检查对象、非空、属性存在和属性类型
- v is Expense 把检查结论传给调用处
- 检查条件要覆盖后续代码依赖的字段
