# 泛型保留输入与输出的联系

如果一个函数的处理步骤适用于多种类型，又希望保留输入和输出之间的联系，可以使用泛型。尖括号里的T是类型参数，这次调用决定T是什么；参数value和返回值都写T，表达同一种类型沿调用过程传递。identity直接返回交入的值，步骤很简单，适合先观察类型怎样变化。

交入数字十二时，这次调用的结果按数字处理。交入文字午餐时，另一次调用的结果按字符串处理。因此amount可以加八得到二十。name可以使用字符串方法。泛型让一份实现服务于不同类型，同时保留具体调用中的信息。先从这种一进一出的对应关系理解，再学习约束和多个参数之间的联系。

## 本页总结

- T 是本次调用使用的类型参数
- 参数与返回值使用同一个 T
- 每次调用分别确定对应类型
- 返回后继续获得正确的操作提示
