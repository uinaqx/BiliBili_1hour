# 让外部输入经过检查

输入框读出来的是文字，我们用一个专门的函数检查金额。返回类型是数字或者空值，成功给出金额，失败给出 null。首先处理只有空白的输入，让用户补充金额。接着转换成数字，检查结果有限且大于等于零，通过时返回金额，其他情况返回空值。每一步都对应页面上的具体规则。

三次调用依次得到十二点五、空值、空值。调用者检查结果是否为 null，就知道接下来展示提示，还是添加一条记录。这种把解析和页面操作分开的写法很适合练习。你可以直接增加小测试，输入零、带空格的数字和负数，逐项确认规则，再放心地把函数连接到提交按钮。

## 本页总结

- 先处理空白输入，再转换为数字
- 金额要求为有限数字且大于等于零
- 成功返回 number，失败返回 null
- 调用处检查 null 后继续新增记录
