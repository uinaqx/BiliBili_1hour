# 检查网页输入元素

最后把类型检查放到网页里。按选择器查找元素，返回值可能是一个元素，也可能是空值。浏览器环境的类型声明已经记录了这些可能。我们用 instanceof 确认它是一个输入框。进入分支之后，编译器就知道这个对象有 value 属性，也知道 value 读出来是一段文字。实际练习页面会预先填入十二。

用 Number 把输入内容转成数字，再用 Number.isFinite 检查结果是否为有限数字。通过检查后参与运算，程序输出二十。这几行串起了三个步骤，找到元素，检查种类，处理内容。网页里很多带空值的提示都能沿着这个顺序解决。下一章把对象、数组和这些检查方法连起来，完成开销统计小项目。

## 本页总结

- querySelector 可能返回元素或 null
- instanceof 确认取得输入框后读取 value
- 表单 value 是字符串，用 Number 转换
- 有限数字检查通过后再参与计算
