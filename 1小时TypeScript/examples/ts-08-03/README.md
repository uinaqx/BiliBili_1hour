# typeof 从已有值取得类型

默认配置已经写成对象，currency保存文字，limit保存数字。类型位置的typeof可以读取这个对象的类型信息，起名为Settings。再声明personal时，按照同一套字段结构提供币种和限额。这样配置值和对应的类型说明可以保持联系，避免分别书写后逐渐出现差异。

personal保存新的币种USD。限额改为五十。类型位置的typeof用于形成类型说明；放在运行语句中的typeof则取得类型名称文字。阅读时先看它出现在type声明里，还是普通表达式里，就能判断当前在做哪一层工作。此处默认对象的属性推断为string和number，因此新对象可以使用同类的其他文字和数字。

## 本页总结

- 类型位置的 typeof 引用已有值的类型
- Settings 描述 currency 与 limit
- 新的配置对象保持相同字段结构
- 与运行时 typeof 的用途分开阅读
