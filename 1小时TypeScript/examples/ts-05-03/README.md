# 可选链与空值处理

用户可能还没有选中，所以参数允许User或null；用户对象本身也可能省略备注。可选链把这两层情况连起来：user有值时读取note，note有值时再读取length，缺少其中一层时交出undefined。两个问号再把这种空结果整理为零。沿着对象到属性的路线逐层观察，就能读懂这一条表达式。

第一处调用提供两字备注午餐，得到长度二。第二处没有备注，采用零。第三处交入null，同样采用零。这样函数出口始终提供数字，调用者就能继续进行数值计算。需要对不同空状态给出不同提示时，也可以改写为几条if，分别返回说明。根据当前页面或接口的需求，选择清楚的处理路线即可。

## 本页总结

- ?. 在当前对象有值时继续读取
- 可选属性也可继续使用可选链
- ?? 为读取不到的情况提供默认值
- 本例统一返回数字长度
