# 导出类型与导出函数

当代码增多，可以把类型和相关函数放到独立模块。budget文件先导出Expense类型。total函数按这份类型接收记录数组，累计金额再返回数字。模块让使用者按需要导入工具，也方便回到定义位置查找实现。类型说明和实际操作围绕同一份数据组织，阅读时能够互相对照。

主文件普通导入total，因为运行时需要调用这个函数。再用import type导入Expense，说明它用于类型检查。建立两条记录并求总额，得到二十。路径中的点斜线从当前文件所在目录开始，编译器会处理相应的TypeScript来源。配套目录保留budget和main两个完整文件，用给出的配置编译，再运行生成的主文件即可。

## 本页总结

- export 提供类型与运行时工具
- import type 标明只用于类型检查的导入
- 普通 import 取得运行时函数
- 两个完整文件都在配套目录中
