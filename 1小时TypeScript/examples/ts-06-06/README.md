wrap把一个值放进带value属性的对象中，参数和属性都使用同一个类型参数T。返回时用属性简写组织对象。这次交入十二，再读取box点value加八。请判断box里的value应按什么类型处理，以及最后显示多少。给自己四秒，先在本次调用里确定T，再把它代回返回对象的说明。
