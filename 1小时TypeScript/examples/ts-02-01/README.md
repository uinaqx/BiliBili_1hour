# 数组类型与元素读取

记录多笔开销，可以用一对方括号把十二、八、五按顺序放在一起。number后面再写一对方括号，表示这个数组里的元素按数字处理。读取第一项使用下标零，得到十二。数组的位置编号从零开始，所以第二项是下标一，第三项是下标二。先把位置和对应金额对齐，再处理后面的读取和修改。

length取得元素数量，这里有三项。push把三加入末尾，数组就增加了一笔记录。join把各项用逗号连接，显示十二、八、五、三。数组类型让检查工具知道元素支持数字操作，也会检查新增元素的类型。实际按位置读取时，还需要结合长度判断位置是否存在；后面会用查找结果和undefined进一步练习。

## 本页总结

- number[] 表示数字组成的数组
- 下标从 0 开始
- length 取得元素数量
- push 在末尾增加一项
