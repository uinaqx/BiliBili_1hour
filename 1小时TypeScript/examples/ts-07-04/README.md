# implements 核对一组共同能力

Printable接口要求提供一个返回字符串的print方法。Expense声明实现这个接口，检查工具就会核对它是否具备相应能力。构造参数前面的public同时声明并初始化同名属性，这是一种参数属性简写。print读取对象的名称和金额，整理为显示文字。接口描述的是约定，类提供具体的数据和实现。

我们按Printable类型使用新建的Expense对象，只围绕这份共同能力调用。print返回午餐冒号十二元。以后其他类也能提供相同的方法，再交给同一组使用接口的代码。实现接口时还要在类本身写出合适的参数和字段类型，让具体实现也能得到清楚检查。把约定和实现分别定位，读多文件工程时会更容易找到各自的责任。

## 本页总结

- 接口描述需要提供的方法
- implements 核对类是否满足约定
- 构造参数修饰符可同时声明属性
- 使用者可以面向共同接口调用
