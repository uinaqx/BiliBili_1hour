# 用类型设计开销记录

最后做一个开销记录项目。我们先决定每条记录保存什么。id 用来区分记录，name 保存名称，amount 保存金额。把这三个字段写成 Expense，后面的新增、删除和统计都围绕这份约定展开。设计数据时，先想清楚页面要显示什么，以及操作时要用什么找到一条记录，通常就能确定主要字段。

数组保存两条示例记录，午餐十二，交通八。每个元素都接受同一份类型检查，字段名和金额类型可以在编辑时及时确认。最后提取名称并连接，输出午餐、交通。配套工程会把同样的记录画成网页列表，这一页先把数据形状看清楚。后续每一步都保持形状一致，程序就容易连接和维护。

## 本页总结

- 记录用 id 区分身份，name 描述名称，amount 保存金额
- Expense[] 约定每个数组元素的形状
- map 提取名称，join 把名称连接成一段文字
- 先设计数据，再连接输入、统计和页面

## 预期输出

```text
午餐、交通
```
