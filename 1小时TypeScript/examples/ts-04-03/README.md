# interface 与可选属性

interface也常用来描述对象结构。这里要求名称和金额两个字段。note后面加问号，表示备注可以省略。所以创建item时，只提供名称和金额，也能满足这个接口。用可选属性表达数据确实可能缺少的部分，调用者就能看清哪些内容是建立记录时的基础，哪些属于额外补充。

读取没有提供的note时，结果可能是undefined，因此用两个问号给出默认文字，显示暂无备注。有备注就显示备注，没有就采用默认值。interface适合持续描述对象之间的共同约定，type也能为对象结构命名；实际项目选择一致的组织方式即可。当前最重要的是把必需字段和可选字段写准确，并在读取时处理相应的可能情况。

## 本页总结

- interface 描述对象的属性约定
- 属性后的 ? 表示可以省略
- 读取可选属性需考虑 undefined
- ?? 提供适合显示的默认文字
