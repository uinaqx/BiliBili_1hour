# typeof 把联合类型分成两条路线

format准备同时接收文字和数字，所以参数写成两者的联合类型。函数先通过typeof检查当前值是不是number。进入这个分支以后，工具就把value按数字处理，可以调用toFixed，整理为一位小数。我们把根据条件缩小可能范围的过程叫作类型收窄，它让每条分支获得与实际情况对应的操作能力。

数字分支已经返回，来到下面这一行时，剩下的是字符串情况，因此可以调用转大写的方法。交入十二，返回文字十二点零。交入tea，返回大写TEA。这里运行时的条件判断和检查阶段的类型分析配合在一起。遇到联合类型，先列出可能有哪些值，再用清楚的判断把它们分开，往往就能顺着分支写出正确操作。

## 本页总结

- 参数先允许 string 或 number
- typeof 条件确认数字分支
- 数字分支可调用 toFixed
- 剩余字符串分支可调用 toUpperCase

## 预期输出

```text
12.0
TEA
```
