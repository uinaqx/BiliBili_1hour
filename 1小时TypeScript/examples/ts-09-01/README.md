# 等待稍后完成的结果

实际项目经常等待网络或文件结果。我们先用一个很小的异步函数认识写法。在函数前加上 async，返回类型写成 Promise，尖括号里填 number，表示这项工作完成后会得到一个数字。函数体直接返回二十，运行时会把它包装成一个承诺稍后给出结果的对象。现在先记住这组固定搭配。

主函数也写上 async，这样就能在函数内部使用 await。程序执行到第五行时，等待前面的工作完成，把得到的二十交给 amount。接着输出二十。主函数的返回类型是 Promise 加 void，表示它完成后没有额外的返回值。等你把第一段替换成真正的请求，等待和读取结果的写法依然相同。

## 本页总结

- async 函数返回 Promise，类型参数表示最终结果
- await 取得完成后的值，继续执行下一行
- Promise<void> 表示完成后没有返回值
- 练习把立即返回替换为实际网络请求
