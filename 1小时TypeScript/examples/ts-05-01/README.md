# 字面量类型列出允许的值

付款状态通常只有几个固定选项。这里把pending和paid两个具体字符串连接起来，给这组允许值起名Status。它们表示待付款和已付款。这样的类型比任意字符串更贴近业务需要，编辑器能够直接提示可用选项，也能检查状态单词有没有拼错。先列出实际允许的情况，再写处理逻辑，规则会更清楚。

label接收Status，用严格相等检查是否为paid，为真就返回已付款，否则返回待付款。交入paid，得到已付款。交入pending，得到待付款。问号和冒号组成条件表达式，在两种结果之间选一个值。我们让状态范围和显示函数使用同一份约定，新增状态时，也能沿着类型和处理函数一起检查。

## 本页总结

- 字面量类型把范围缩小到具体值
- 联合类型列出几种允许状态
- 参数调用按允许值检查
- 条件表达式为状态选择显示文字
