# 箭头函数与数组回调

箭头函数提供了紧凑的写法。这里value接收数字，箭头右边计算它乘二，整个函数也返回数字。交入六以后，显示十二。函数能够保存到变量，也能够传给别的工具。把一小段操作交出去，让工具在合适的位置调用，就是常见的回调用法，数组处理和网页事件都会遇到。

prices保存十和二十，map依次把每一项交给回调。回调参数price根据数组元素推断成number，返回当前价格加一，形成新的数字数组。因此显示十一和二十一。这里省略回调参数的显式标注，类型信息仍然来自清楚的上下文。先把每项怎样处理写明白，再让类型推断补上容易判断的信息，代码会更紧凑。

## 本页总结

- 箭头左侧写参数与类型
- 单个表达式可作为返回结果
- map 为每项生成一个新值
- 回调参数可根据调用位置推断类型
