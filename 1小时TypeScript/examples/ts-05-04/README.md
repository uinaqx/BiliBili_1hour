# 用标签区分不同形状

如果成功结果和失败结果包含不同字段，可以让它们共享一个标签。这里ok为真时，记录amount；ok为假时，记录message。每一种情况都把标签和相关数据放在同一个对象里，这样类型能够表达它们之间的联系。读取结果时，先看标签，再沿对应的数据形状往下走。

show函数检查result点ok，进入成功路线就能读取金额，整理成十二元。其余路线读取message，返回输入提示。下面两次调用分别展示成功和失败。这种带标签的联合类型适合表单检查、网络请求和任务状态。后面增加加载中或空列表等状态时，也可以给它们各自安排清楚的标签和字段。

## 本页总结

- 联合成员用 ok 字段区分
- ok 为 true 时读取 amount
- ok 为 false 时读取 message
- 相关字段随标签一起收窄
