# 参数类型与返回类型

如果经常计算预算还剩多少，可以把步骤写成函数。remaining接收budget和spent两个参数，参数后面的number说明交入数字；括号后面的number说明返回数字。函数体里用预算减去开销，再通过return交回结果。把入口和出口说明清楚，调用处就能得到更准确的提示，函数实现也有了需要满足的约定。

调用remaining时，把三十交给budget，把二十五交给spent。函数完成相减，返回五，left接住它。最后显示五。阅读函数时，先从调用处找到传入值，再进入函数体跟踪，最后带着返回值回到调用处。普通计算函数的返回类型也能被推断出来；对外提供的工具，显式标注返回类型有助于长期保持接口清楚。

## 本页总结

- 参数后标注接收的数据类型
- 括号后标注返回结果的类型
- return 交回结果并结束本次调用
- 调用检查与函数内部检查相互配合
