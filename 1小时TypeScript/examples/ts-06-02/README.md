# 用函数类型描述回调

函数本身也有类型。Transform描述一种操作：接收数字，返回数字，箭头左边写参数，右边写返回类型。apply除了接收一个值，还接收符合这份约定的action。它把value交给action，再返回action完成后的结果。这样一个工具可以把固定的调用步骤和变化的处理方法组合起来。

double符合Transform要求，接收当前值并返回它的两倍。回调参数value能从上下文推断为数字。把六和double交给apply，就得到十二。数组方法、事件函数和异步任务里，经常需要描述回调的入口与出口。把这份函数类型写清，交入的方法是否能按约定工作，就可以在检查阶段得到反馈。

## 本页总结

- 函数类型描述参数和返回值
- Transform 接收数字并返回数字
- apply 调用交入的操作
- 回调中的 value 可由上下文推断

12
