### 00:24:15 typeof 把联合类型分成两条路线

```typescript
function format(value: string | number): string {
  if (typeof value === "number") {

  return value.toUpperCase();

console.log(format("tea"));
```

运行结果：
```text
12.0
TEA
```

数字分支已经返回，来到下面这一行时，剩下的是字符串情况，因此可以调用转大写的方法。交入十二，返回文字十二点零。交入tea，返回大写TEA。这里运行时的条件判断和检查阶段的类型分析配合在一起。遇到联合类型，先列出可能有哪些值，再用清楚的判断把它们分开，往往就能顺着分支写出正确操作。

### 00:25:11 可选链与空值处理

```typescript
type User = {name: string; note?: string};
function noteLength(user: User | null): number {
  return user?.note?.length ?? 0;
}
console.log(noteLength({name: "小林", note: "午餐"}));
console.log(noteLength({name: "小林"}));
console.log(noteLength(null));
```

运行结果：
```text
2
0
0
```

第一处调用提供两字备注午餐，得到长度二。第二处没有备注，采用零。第三处交入null，同样采用零。这样函数出口始终提供数字，调用者就能继续进行数值计算。需要对不同空状态给出不同提示时，也可以改写为几条if，分别返回说明。根据当前页面或接口的需求，选择清楚的处理路线即可。

```typescript
function parseAmount(text: string): number | null {
  if (text.trim() === "") return null;
  const amount = Number(text);
  return Number.isFinite(amount) && amount >= 0
    ? amount : null;
}
console.log(parseAmount("12.5"));
console.log(parseAmount("abc"));
console.log(parseAmount(""));
```

```text
null
null
```

三次调用依次得到十二点五、空值、空值。调用者检查结果是否为 null，就知道接下来展示提示，还是添加一条记录。这种把解析和页面操作分开的写法很适合练习。你可以直接增加小测试，输入零、带空格的数字和负数，逐项确认规则，再放心地把函数连接到提交按钮。

```typescript
type Item = { amount: number };

  return items.reduce((n, item) => n + item.amount, 0);
}
```
