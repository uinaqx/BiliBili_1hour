## 运行环境与变量类型

### 00:00:00 从第一行程序开始

```csharp
int budget = 30;
int spent = 25;
Console.WriteLine(budget - spent);
```

运行输出：
```text
5
```

先看这三行。budget保存预算三十，spent保存已经花掉的二十五。名字前面的int表示整数，可以先理解成这份数据的种类。等号把右边的值交给左边的名字，分号表示这一条语句结束。最后一行把两个数字相减，通过Console点WriteLine显示出来，得到五。后面所有功能都会从这样的小步骤组合起来。

## 运算符与输入输出

把两个中间结果放进显示文字里，就得到已花二十，剩余十。表达式变长时，可以用括号明确先计算哪一部分。乘除通常先于加减，例如预算减去两份午餐，可以先看乘法再看减法。入门阶段把复杂计算拆成带名字的中间步骤，既方便预测结果，也方便在输出里检查每一步有没有按预期执行。
