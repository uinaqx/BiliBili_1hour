# 运行完整项目并检查结果

运行：`dotnet run --project .`。


保存数据时，把列表序列化成JSON，再写入固定文件。这里用金额数组演示保存步骤，完整项目保存的是Expense对象列表。下次运行先读取文件，按相同数据类型解析回来，再检查编号、名称和金额是否满足规则。文件缺失就从空列表开始，读取失败时显示原因，并保留原文件便于检查，然后再开始新的操作。

本页取回两笔金额，总额是二十点零零。完整项目请依次测试添加两条、删除一条、退出后重新打开，再尝试空名称、负数和无效菜单编号。README提供运行命令和文件位置，源码也可以直接打开阅读。每次只改变一个输入，观察菜单反馈、列表和保存文件，三者对应起来，就能确认程序的整条数据路线。

## 总结

- JSON 保存数据结构，文件把内容保留到下次运行
- 读取后检查记录字段，异常时给出恢复提示
- 完整项目包含新增、查看、删除和保存退出
- 检查首次运行、非法输入、刷新读取和损坏文件
