# 用编号删除目标记录

运行：`dotnet run --project .`。


删除记录时，使用独立编号会比较清楚。本页先用编号列表一、二、三单独观察删除步骤，target是准备删除的二。RemoveAll接收一个判断方法，编号等于target时移除，并把实际移除数量返回。把条件读成找到编号二的记录，再看方法怎样处理匹配项，和前面的筛选逻辑就能互相对应。

本次移除一项，列表剩下一和三。完整项目把条件写成item点Id等于输入编号，删除后重新统计并保存，再告诉用户是否找到了目标。编号描述记录身份，列表位置则随着排序和删除变化，所以菜单里展示编号能让用户选择得更明确。添加新记录时统一分配编号，也方便后续查找、更新和导出数据。

## 总结

- 编号作为记录身份，显示位置可以变化
- RemoveAll 按条件移除所有匹配项并返回数量
- 本页只匹配编号 2，删除数量为 1
- 完整项目用相同方式比较 item.Id 与输入编号
