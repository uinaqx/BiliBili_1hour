# 空值与模式匹配

运行：`dotnet run --project .`。


有些数据可能暂时没有内容，例如记录备注，可以用string后面加问号表示允许空值，null就是这种空值。问号点号表示对象存在时再读取Length，两个问号为得到的空值提供备用的零。所以这一行显示零。把可能缺失的数据写进类型约定，再在使用处选择默认值或条件分支，代码就能把两种情况表达完整。

object可以接收各种值，这里保存整数十二。is int amount检查当前数据是否是整数，匹配成功时，把可用的整数交给分支里的amount。随后加八显示二十。这种一边检查一边取得匹配结果的写法属于模式匹配。和前面TryParse配合out类似，先确认情况，再使用确认后的数据，程序的每一步都有明确依据。

## 总结

- string? 说明变量允许保存 null
- ?. 在对象存在时继续读取成员
- ?? 为 null 的结果提供备用值
- is int amount 检查类型并在分支中提供整数变量
