# 属性提供读取和设置入口

运行：`dotnet run --project .`。


属性把对象成员的读取和设置入口写在一起。get表示允许读取，set表示允许设置。这种简短写法叫自动属性，编译器会安排实际保存数据的位置。Name初值是空字符串，Amount采用整数的默认值零。先理解公开的属性是怎样被外部使用的，再逐步学习在入口里加入检查或计算，学习顺序会更自然。

创建对象以后，使用方式依然是通过点号给Name和Amount赋值。随后读取金额，显示十二。你会在很多C sharp项目里看到属性名大写开头，局部变量小写开头，这是常见命名习惯，方便区分类的成员和临时数据。属性还可以只公开读取，把修改集中交给类自己的方法，这正是下一页要观察的组织方式。

## 总结

- 属性把读取和设置约定放在成员声明中
- get 提供读取入口，set 提供赋值入口
- 自动属性由编译器安排保存数据的位置
- 属性名采用大写开头，局部变量常用小写开头
