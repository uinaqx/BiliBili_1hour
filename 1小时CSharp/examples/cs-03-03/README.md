# 用 switch 匹配固定选项

运行：`dotnet run --project .`。


菜单经常让用户选择编号。choice保存二，switch围绕这个值匹配具体选项。你可以把switch理解成一张编号和操作的对应表，左边找编号，右边执行动作。case一安排添加记录。case二安排查看总额。每条路线末尾的break表示结束这次switch处理，再回到它后面的程序。

default负责其他编号，提示重新选择。本页choice是二，所以显示查看总额。和上一页相比，这里的判断更像逐项匹配固定值，if则更适合比较范围或组合多个条件。两种结构可以围绕实际任务选择。接下来做交互菜单时，先读取用户选择，再进入对应case，把输入、判断和动作连接起来就可以了。

## 总结

- switch 适合菜单编号等固定选项
- case 写具体匹配值，冒号后安排动作
- break 结束当前 switch 的处理
- default 接住其他值，提供明确反馈
