# 把运算表达式读成小步骤

运行：`dotnet run --project .`。


这一页把开销计算写完整。预算三十，午餐十二，交通八。每个名字对应一份具体数据，后面就能通过名字读取。先把午餐和交通相加，得到已花金额spent二十。再用预算减去已花金额，得到剩余金额left十。像加法和减法这样组合出结果的写法，统称为表达式，执行后会产生一个值。

把两个中间结果放进显示文字里，就得到已花二十，剩余十。表达式变长时，可以用括号明确先计算哪一部分。乘除通常先于加减，例如预算减去两份午餐，可以先看乘法再看减法。入门阶段把复杂计算拆成带名字的中间步骤，既方便预测结果，也方便在输出里检查每一步有没有按预期执行。

## 总结

- 表达式把值和运算符组合成计算步骤
- 先计算午餐加交通，再计算预算减总额
- 括号可以明确希望先计算的部分
- 变量名说明中间结果在任务中的含义
