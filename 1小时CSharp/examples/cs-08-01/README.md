# 把一段做法作为参数传递

运行：`dotnet run --project .`。


除了传递数字和文字，程序也能传递一段做法。Func的两个int分别说明输入整数，返回整数。箭头左边的value是输入，右边把它乘二，这种简短的方法表达式叫lambda。变量doubleValue保存这份可调用的做法。Action接收字符串并完成显示动作，适合只执行操作的情况，这些类型都是常用委托。

像调用方法一样，给doubleValue传入六，得到十二，再显示。给show传入处理完成，就会执行显示动作。先看委托约定接收什么、交回什么，再看lambda写了怎样的处理，就能把两部分配起来。下一页筛选集合时，我们会把判断条件写成lambda交给筛选工具，让它对每个元素应用同一份规则。

## 总结

- Func<int,int> 接收 int 并返回 int
- Action<string> 接收文字并执行动作
- lambda 箭头左边是参数，右边是处理表达式
- 委托变量保存可以调用的做法，便于传递行为
