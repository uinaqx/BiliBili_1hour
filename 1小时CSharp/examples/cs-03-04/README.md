# 用 for 重复执行固定次数

运行：`dotnet run --project .`。


重复做相同的事，可以写成循环。total先保存零。for括号分成三部分，先让i从一开始，每轮检查i是否小于等于三，本轮结束后把i增加一。把i当作当前进行到第几次，就容易读懂这段循环。每通过一次条件检查，就把十二加进total，表示再记录一份十二元开销。

第一轮i为一，总额十二。第二轮i为二，总额二十四。第三轮i为三，总额三十六。更新到四以后，继续条件为假，循环结束。最后显示三十六。跟踪循环时，可以画出轮次、条件和total三列，每轮写一行。以后统计数组中的数据，也是让一轮处理一项，再把结果逐步累计起来。

## 总结

- for 括号内依次是初始化、继续条件和更新
- 每轮先检查条件，通过后执行循环体
- i++ 在本轮结束后把 i 增加一
- 3 轮各累加 12，最终得到 36
