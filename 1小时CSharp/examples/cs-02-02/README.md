# 整数除法与类型转换

运行：`dotnet run --project .`。


总量五，份数二，直接相除显示二。因为两边都是整数，这次采用整数除法，结果向零截断。把五个物品按每份两个分组，可以得到两组，剩下一个，这样读结果就很具体。如果要计算平均值，在total前写括号里的double，先把这一份值转换成浮点数，再进行除法，就会得到二点五。

最后一行用百分号求余数，五除以二余一，所以显示一。余数等于零常用来判断能否整除，例如判断编号是偶数。请特别观察转换的位置，先转换再相除，运算就按浮点数规则处理。把转换放在已经算出的整数商后面，保存的是前一步得到的整数结果。按执行先后顺序阅读，就能理解两种写法的结果。

## 总结

- 两个整数相除得到整数商，向零截断
- 先将一个操作数转换为 double，再做小数除法
- % 取得余数，常用于整除判断
- 转换发生的位置决定后续参与运算的类型
