# 排序与常用统计

运行：`dotnet run --project .`。


OrderBy负责排序，lambda选择排序依据，也叫键。这里直接选金额本身，所以得到按金额从小到大的结果序列。遍历显示时，看到五、八、十二。换成记录对象以后，也可以选择记录的金额作为键，让整条记录按金额排列。先问按什么排序，再把对应值放进lambda，规则就能准确表达。

Sum求出总额二十五。Max取得最大值十二。统计方法完成的是一类常见遍历操作，使用前先确认输入数据和所需结果。这里排序结果单独保存，原数组仍然保持十二、八、五的原有顺序。需要把结果固定到新列表时，可以再调用ToList；下一页就观察查询什么时候读取原始数据，以及固定结果以后有什么变化。

## 总结

- OrderBy 根据选择出的键生成升序结果
- 本页直接用金额本身作为排序键
- Sum 求和，Max 取最大值
- 原数组仍按原顺序保存，排序结果单独遍历
