# 筛选记录并计算总额

运行：`dotnet run --project .`。


列表里现在有两条完整记录，午餐十二和交通八。循环里的当前元素从整数变成对象，但逐项处理的思路相同。Sum的lambda取出每条记录的Amount，把金额相加，得到二十。Select取出Name，形成准备显示的名称序列。先从当前元素读出目标字段，再交给统计或显示工具，步骤就很清楚。

最后显示午餐、交通和总额二十点零零。数据变化以后，重新按当前列表统计，总额就会跟着更新。这里把名称展示和金额求和分开写，阅读时更容易看出每个结果从哪里来。如果要按名称筛选，可以先加Where条件再统计。原始数据、选择字段、形成结果，这条路线可以覆盖很多日常的数据展示任务。

## 总结

- Sum 的选择器指出每条记录取哪个金额
- Select 提取名称，再连接成展示文字
- 总额来自当前完整列表，更新后重新统计
- 金额显示格式统一，便于核对新增和删除结果
