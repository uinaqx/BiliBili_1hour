# 跟踪参数与作用范围

运行：`dotnet run --project .`。


方法里面的value是本次调用的局部参数。执行到第三行时，把它改成九十九，然后显示这份局部值。外面的amount先保存十二，普通整数参数传递时把数值的一份副本交给value。你可以画两个分别写着十二的小格子，一个叫amount，一个叫value，进入方法后修改的是后面那个格子。

所以方法里面先显示九十九，回到主流程再显示amount，仍然是十二。跟踪参数时，先确认当前正在执行哪个方法，再区分各自的局部名字。需要根据旧金额算出新金额时，可以让方法返回一个整数，再由调用者决定保存到哪里。后面学习对象引用时，还会观察多个名字共同找到同一个对象的情况，届时再对照这份数值副本理解。

## 总结

- 普通 int 参数接收调用时数值的一份副本
- value 属于方法内部，amount 属于外部主流程
- 修改 value 后，外面的 amount 继续保存 12
- 希望交出新值时，可以设计一个返回 int 的方法
