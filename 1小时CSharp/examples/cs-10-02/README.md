# 把新增操作集中到方法

运行：`dotnet run --project .`。


列表的元素类型改成Expense，每一项就能同时保存名称和金额。新增方法接收两项输入，建立一个对象并添加到列表。本页用局部方法组织步骤，它可以使用外层作用范围中的items。项目变大以后，也可以把这些数据和操作放到专门的管理类里，先保持数据由哪一部分维护这条关系清楚即可。

主流程调用两次，分别添加午餐十二和交通八。当前列表Count是二。完整项目在进入新增操作前检查名称有内容、金额是大于等于零的有限十进制数，再分配独立编号。成功后统一保存并显示反馈。把新增规则集中在一处，按钮、菜单或其他输入方式都能连接到同样的处理步骤，后面扩展也更方便。

## 总结

- List<Expense> 保存多条记录对象
- 新增方法接收名称和金额，建立对应对象
- 局部方法可以使用外层同一作用范围的数据
- 完整项目先检查输入，再统一分配编号和保存
