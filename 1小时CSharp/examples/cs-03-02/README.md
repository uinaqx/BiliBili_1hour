# 按顺序检查多种情况

运行：`dotnet run --project .`。


有时候需要区分三种以上情况。这里保存成绩七十八，准备按优秀、及格、继续练习三个档次显示。先检查是否大于等于九十，结果为假，继续往下看。else if再检查是否大于等于六十，这次为真，于是显示及格。整组选择到这里就已经确定了处理路线，程序随后继续执行分支结构后面的内容。

最后的else承接前面条件都没有满足的情况。把成绩改成四十五，就会显示继续练习。这里把九十这一档放在前面，再检查六十，让较高要求优先匹配。写分档题时，可以先列几个代表值，例如九十五、七十八和四十五，逐个从第一条条件走一遍。这样检查分支顺序和边界，会比只看一个结果更清楚。

## 总结

- else if 从上到下继续检查条件
- 匹配到一条路线后完成整组选择
- 把较高门槛放在前面，分档范围更清楚
- 78 未达到 90，随后满足 60，输出及格
