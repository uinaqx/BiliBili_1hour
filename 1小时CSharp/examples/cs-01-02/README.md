# 准备工具并运行程序

运行：`dotnet run --project .`。


第一行程序把你好，C sharp显示在控制台。引号包住准备显示的文字，括号把这份文字交给显示工具。点号可以先读成找到里面的功能，Console里的WriteLine负责显示后换行。运行之前安装点NET开发工具包，也就是SDK，里面包含创建、检查、编译和运行项目所需的工具。安装完成后可以在终端查看版本。

输入dotnet new console创建项目，项目名字叫Hello。打开里面的Program点cs，把第一行代码保存进去。下面带双斜线的文字是注释，用来给人阅读操作说明。最后执行dotnet run，工具先把代码编译成可运行的程序，再执行并显示文字。配套示例已经分别准备好项目文件，你可以直接运行相应目录。

## 总结

- 安装 .NET SDK，获得创建、编译和运行工具
- dotnet new console 创建控制台项目
- Program.cs 保存本页程序代码
- dotnet run 编译并执行当前项目
