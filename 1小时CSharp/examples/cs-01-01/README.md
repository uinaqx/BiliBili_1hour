# 从第一行程序开始

运行：`dotnet run --project .`。


同学们好，欢迎来到一小时学完C sharp。我们从一行显示文字的程序开始，逐步学习怎样保存数据、处理输入、作出判断，再把这些步骤写成方法和对象。课程围绕开销记录展开，每章都有小例子和练习。你可以一边观察代码，一边预测结果，再亲手改动数字和条件，逐步建立编程的基本感觉。

先看这三行。budget保存预算三十，spent保存已经花掉的二十五。名字前面的int表示整数，可以先理解成这份数据的种类。等号把右边的值交给左边的名字，分号表示这一条语句结束。最后一行把两个数字相减，通过Console点WriteLine显示出来，得到五。后面所有功能都会从这样的小步骤组合起来。

## 总结

- int 表示整数，变量名描述数据用途
- 赋值号把右边的值交给左边的名字
- Console.WriteLine 把结果显示在控制台
- 贯穿案例：记录开销、统计金额、保存数据
