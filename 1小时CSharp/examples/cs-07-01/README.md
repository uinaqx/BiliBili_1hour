# 继承已有类型的成员

运行：`dotnet run --project .`。


如果几类对象有共同信息，可以把共有部分放到一个基类。Person保存姓名属性。Student后面写冒号Person，表示学生继承人员这份结构，再增加成绩Score。这样学生同时具备姓名和成绩，后续另外一种人员类型也可以从共有部分扩展。先从数据之间的关系出发，继承就有了具体用途。

创建学生时，用花括号一次设置姓名小林和成绩八十，这叫对象初始化器。随后读取两项内容，显示小林和八十。读取Name时，使用的是从Person继承来的成员，读取Score时，使用Student自己声明的成员。设计类型时，可以先找出稳定的共有部分，再决定怎样扩展；当几个对象需要共同参与一种操作时，还可以通过接口描述操作要求。

## 总结

- 冒号在类声明中表示继承基类
- Student 继承 Person，并增加 Score
- 派生类对象可使用继承来的公开成员
- 共有数据放到基类，专有数据放到派生类
