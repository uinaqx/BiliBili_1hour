# 练习：修正金额赋值

运行：`dotnet run --project corrected`。


第一道练习，amount从整数十二开始。第二行准备交入引号里的二十，也就是一段文字。请判断编译检查会指出什么问题，并想想当前任务需要的是文字还是金额。第三行准备显示amount，整个目标是让它保存数字二十后再输出。先对照变量的声明和赋值右边的内容，找到应该处理转换的位置。

编译检查会指出文字和整数类型不匹配。修正版使用int点Parse，把固定合法的文字二十解析成整数，再交给amount。运行后显示二十。处理类型问题时，从业务目标出发选择转换方法。这里希望继续进行金额计算，所以把文字整理成数字。接下来学习键盘输入时，我们会使用TryParse，根据解析是否成功安排两条清楚的处理路线。

## 总结

- 第 2 行交入 string，变量约定为 int
- 修正版通过 int.Parse 得到整数
- 固定合法文字可用于本页转换练习
- 用户输入将使用 TryParse 分支处理
