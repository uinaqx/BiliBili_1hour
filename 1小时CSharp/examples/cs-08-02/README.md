# Where 筛选，Select 转换

运行：`dotnet run --project .`。


继续处理十二、八、五这组三笔金额。Where接收一个判断方法，对每一项检查是否大于等于八，通过的保留下来，因此得到十二和八这条结果序列。Select再把每一项加一，形成十三和九。把两步先后写开，就像先筛选符合条件的记录，再整理准备显示的数据，处理路线很直观。

Join实际遍历结果并连接显示，最后看到十三和九。这组查询工具叫LINQ，它把常见的筛选、转换和统计整理成一致的调用形式。刚开始先分别写出每一步，确认输入和输出，再按需要连接调用。lambda里的value代表当前元素，判断或转换的规则由右边表达式决定，和前面循环里一轮处理一项的思路相通。

## 总结

- Where 根据返回 bool 的条件保留元素
- Select 把每个元素转换成新的结果
- 本页先保留 12、8，再分别加一
- 这些集合查询工具属于 LINQ，先按步骤读即可
