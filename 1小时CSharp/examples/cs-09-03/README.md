# 把文字保存到文件

运行：`dotnet run --project .`。


数据想保留到下次运行，可以写进文件。path保存文件名note点txt，这个相对路径按程序当前工作目录解释。File点WriteAllText把午餐十二写到文件里，如果文件已经存在，会用本次内容覆盖。实际练习先使用专门的示例目录和明确文件名，这样每次运行都能清楚找到生成的数据，也方便观察内容发生了什么变化。

ReadAllText读取文件的文字内容，交给text。最后显示午餐十二。写入和读取组成了保存数据的最小过程。配套验证会在每个例子的独立运行目录执行，生成的文件可以直接打开检查。实际项目还可以使用完整路径，把保存位置安排在固定数据目录，并在读取时处理文件缺失或访问失败，让用户得到清楚的操作反馈。

## 总结

- WriteAllText 写入文字，已有文件会被覆盖
- ReadAllText 读取文件内容并返回字符串
- 相对路径按程序当前工作目录解释
- 配套示例在独立目录运行，生成文件保留供检查
