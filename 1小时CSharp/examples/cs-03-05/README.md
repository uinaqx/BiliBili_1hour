# while、do 与循环控制

运行：`dotnet run --project .`。


while适合重复到某个条件改变为止。left从二开始，先检查是否大于零。通过后显示当前数字，再把left减一。于是先显示二，再显示一，减到零后结束。写循环时，把继续条件和让条件变化的语句放在一起看，就能判断重复过程怎样向前推进，什么时候完成。

do循环把检查放到后面，所以本轮先显示检查完成，再看条件false，随后结束。菜单程序常需要先显示一次菜单，再决定是否继续，就适合这种安排。循环里还会用到break和continue，前者结束当前循环，后者转到下一轮的更新或条件检查。先用普通循环写清过程，再按需求加入这两种控制，读起来会更顺。

## 总结

- while 先检查条件，通过后执行一轮
- 更新循环条件相关变量，让重复过程前进
- do 先执行一轮，再检查是否继续
- break 退出循环，continue 开始下一轮检查
