# 用变量保存和更新数据

运行：`dotnet run --project .`。


变量是程序里带有名字的数据位置。我们用total表示累计金额，先保存整数零。读代码时，可以在纸上给total画一个小格子，旁边写当前值。接着计算旧值零加十二，再把十二交回total。等号在这里表示更新数据，沿着执行顺序看，当前值就从零变成了十二。名字保持一致，保存的数字逐步变化。

第三行使用加等号，意思是把原来的total加上八，再更新total。这种简写适合累计金额或统计次数。执行到显示语句时，当前值已经是二十，所以控制台显示二十。练习时先按顺序记下零、十二、二十，再运行核对。遇到更长的程序，也可以用同样的方法跟踪变量在每一步的变化。

## 总结

- int total = 0 创建整数变量并给出初值
- 赋值时先算右边，再更新左边
- += 把加法和赋值写在一起
- 变量可多次赋值，类型保持为 int
