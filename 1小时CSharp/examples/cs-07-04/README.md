# 接口约定对象能提供的操作

运行：`dotnet run --project .`。


接口把一组操作要求起一个名字。IPrintable要求提供Print方法，可以读成具备打印或显示能力的对象。Expense在类声明里列出这个接口，并提供公开的Print实现，把自己的名称显示出来。接口名称常用大写I开头，方便在项目中识别。你可以先围绕方法约定理解接口，再学习更丰富的成员形式。

调用者用IPrintable接收一条开销记录，然后只需要调用Print，实际显示午餐。以后另外一个类型也实现同样接口，就能通过相同入口参与这项操作。基类适合组织共同基础，接口适合描述调用者依赖的能力。项目里先问当前代码真正需要对象做什么，再把这份需要写成接口，依赖关系通常会更清楚。

## 总结

- interface 描述调用者可以依赖的操作
- 实现接口的类提供相应方法
- 接口变量统一使用具体对象的能力
- IPrintable 命名中的 I 是常见接口命名习惯
