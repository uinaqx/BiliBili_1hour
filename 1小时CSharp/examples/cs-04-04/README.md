# 用 List 增加和删除记录

运行：`dotnet run --project .`。


记录数量会变化时，可以用List。尖括号里的int说明每一项是整数，new创建这份列表，花括号给出最初的十二和八。Add把五添加到末尾。Remove按值找到八并删除第一次匹配的那一项，列表里剩下十二和五。读这些操作时，可以把列表画成一排格子，随着增加和删除更新内容。

Count得到当前两项，方括号零读取第一项十二。最后把完整列表连接成一行，看到十二和五。数组通常用Length读取长度，List用Count读取数量，配合编辑器提示就容易找到。删除后后面的元素会向前排列，所以位置要依据当前列表理解。综合项目里每条记录还会拥有独立编号，便于稳定地找到准备删除的那一条。

## 总结

- List<int> 保存可以增删的一组整数
- Add 在末尾加入元素，Remove 按值删除首次匹配项
- Count 取得当前数量，方括号读取元素
- 删除后元素位置可能变化，重新按当前列表读取
