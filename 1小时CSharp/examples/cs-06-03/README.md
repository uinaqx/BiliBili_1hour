# 构造函数建立可用的对象

运行：`dotnet run --project .`。


Wallet表示钱包，余额属性公开读取，把设置入口留在类内部。与类同名的Wallet方法是构造函数，new创建对象时会执行它，把传入的初始余额保存好。Spend表示消费，接收金额并减少余额。把数据和围绕数据的操作组织在一起，外面的代码就能按业务动作使用这个对象。

创建钱包时传入三十，构造函数把Balance初始化为三十。调用Spend交入十二，余额更新为十八。读取并显示余额，结果是十八。private表示只在类内部访问，public表示向外提供入口。实际业务还可以在Spend里检查金额和余额，保证每次消费都经过同一份处理。读对象程序时，沿着创建、调用、读取这三个阶段跟踪状态。

## 总结

- 构造函数与类同名，创建对象时负责初始化
- private set 把属性设置限制在类内部
- 公开 Spend 方法表达一次业务操作
- 30 初始化余额，消费 12 后读取到 18
