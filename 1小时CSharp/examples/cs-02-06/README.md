# 练习：预测金额计算

运行：`dotnet run --project .`。


来练习一次完整的计算。预算五十，一份开销十二，购买三份。请先在纸上写下各个名字对应的数字。第四行把单价和份数相乘，保存到spent。随后先显示spent，再显示预算减去spent。请预测两个输出，并想一想如果份数改成四，哪些结果会跟着改变。先跟踪变量，再读显示语句。

答案是先显示三十六，因为十二乘三等于三十六。再显示十四，因为五十减三十六等于十四。把份数改成四，总额会成为四十八，剩余成为二。这个小程序已经包含了输入数据、计算中间结果和显示结果三个环节。下一章再加上条件判断，就能根据剩余金额给出不同提示，让程序开始按具体情况选择行动。

## 总结

- 先读取单价和份数，再求乘积
- spent 保存三份开销的合计 36
- 剩余预算为 50 减去 36，得到 14
- 按表达式、赋值和输出的顺序逐行核对
