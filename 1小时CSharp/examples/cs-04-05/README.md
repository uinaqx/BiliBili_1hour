# 用字典按名称查询

运行：`dotnet run --project .`。


按名称快速查金额，可以使用Dictionary，也就是字典。这里两个类型参数分别说明键是字符串，值是整数。用午餐关联十二，用交通关联八。你可以把它想成两列对应表，左边是名称，右边是金额。同一个键再次赋值，会更新它对应的值，所以键很适合表达唯一的查询入口。

TryGetValue尝试查找午餐，找到后返回真，并通过out把十二交给amount，随后显示十二。ContainsKey检查是否存在住宿这个键，这里得到假。按位置取一组数据适合数组和列表，按唯一名称或编号查询则适合字典。先想清楚后续最常做的操作，再选择容器，代码的组织方式就会更贴合实际需求。

## 总结

- Dictionary<string,int> 用文字键关联整数值
- 通过键设置金额，同一键再次赋值会更新
- TryGetValue 同时报告是否找到并交出值
- ContainsKey 适合只判断指定键是否存在
