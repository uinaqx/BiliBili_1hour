# 比较结果与逻辑条件

运行：`dotnet run --project .`。


预算三十，已花二十五，比较是否小于等于预算，结果为真。再检查开销是否大于零，同样为真。两个条件用双与号连接，意思是两项都满足，最后得到真。以后检查输入时，可以把金额合法和名称有内容组合起来，让程序按完整条件继续执行。每一个比较都先产生真假值，再参与逻辑组合。

双等号判断数值是否相等，二十五和三十得到假。单等号负责赋值，双等号负责比较，记住各自任务就容易区分。感叹号把已有真假结果取反，预算内为真，取反后就是假。另一种连接方式是双竖线，表示至少一项为真。读逻辑表达式时，先分别判断每一项，再根据连接符组合结果，复杂条件也能逐步拆开。

## 总结

- 比较表达式产生 bool 结果
- && 要求两项都为真，|| 表示至少一项为真
- == 比较是否相等，= 用于赋值
- ! 把真假结果取反，便于表达相反条件
