# 常量与类型推断

运行：`dotnet run --project .`。


有些数据在程序里采用固定值，例如一周七天，可以用const声明常量。名字Days表达含义，数字七给出具体内容。下一行的var让编译工具根据右边推断类型。右边是文字小林，所以name得到string类型。右边是整数二，count就得到int类型。类型信息依然明确，只是由初始化表达式提供。

我们随后把count更新为整数三。最后显示小林、七和三。阅读var时，先回到初始化表达式，就能理解这份数据是什么。刚入门时显式写int和string有助于熟悉种类，表达式已经很清楚时可以用var简化。两种写法都服务于清晰表达，让下一位读代码的人顺着名字和初值理解当前任务。

## 总结

- const 声明编译时即可确定的常量
- var 根据初始化表达式推断具体类型
- name 推断为 string，count 推断为 int
- 根据数据后续用途选择清楚的名称和类型
