# 练习：解析文件数据并统计

运行：`dotnet run --project .`。


本章练习，把十二、八、五这段逗号分隔的文字写入文件，再读回来。total从零开始，Split按逗号拆开文字，foreach逐项取得字符串片段。每次用TryParse尝试转换，成功就累计。请预测最后显示的总额，再想一想如果文件中间多了一个abc片段，当前程序会怎样安排这一项的处理。

三个合法片段分别转换成十二、八和五，total累计为二十五。最终显示二十五。按照当前规则，abc解析失败时跳过这一项，继续处理后面的内容。如果业务需要逐项提示，也可以在失败分支记录行号或片段内容。先明确处理规则，再把读取、解析和统计连接起来，文件操作就能自然进入前面已经学会的数据处理流程。

- Split 以逗号分开文字，取得三个片段
- 每个片段通过 TryParse 尝试转换
- 解析成功的数字参与累加
- 文件内容 12、8、5，合计输出 25
