# 虚方法根据实际对象选择实现

运行：`dotnet run --project .`。


基类Animal提供Speak方法，virtual表示派生类可以给出自己的实现。Cat继承Animal，用override写出猫的发声方法，显示喵。请把virtual和override配成一组记忆，基类开放这项操作的变化位置，派生类在对应位置写出自己的做法。代码读起来就像同一个动作有不同对象版本。

外面把一只猫交给Animal类型的变量pet，变量负责按动物的共同约定使用对象。调用虚方法Speak时，运行时根据实际对象是一只猫，选择Cat提供的实现，最后显示喵。这种同一调用根据实际对象表现出不同做法的方式叫多态。实际项目里，形状求面积、不同渠道发通知，都可以用共同操作连接各自的实现。

## 总结

- virtual 允许派生类提供自己的实现
- override 明确重写基类的虚方法
- Animal 变量可以引用 Cat 对象
- 虚方法调用根据实际对象类型选择实现
