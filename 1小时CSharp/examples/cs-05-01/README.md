# 把计算步骤写成方法

运行：`dotnet run --project .`。


同一段计算要多次使用时，可以把步骤写成方法。Remaining表示计算剩余金额，括号里的两个参数分别是预算和已花金额，前面的int说明返回一个整数。这里先使用static写一个独立计算步骤，后面学习类时再把方法组织到对象里。方法体执行相减，return把计算结果交回调用的位置。

调用时写方法名和实际数据，三十交给budget，二十五交给spent。方法计算出五，再把它交给外面的left。随后显示五。可以把方法想成一个输入和输出明确的小工具，先看它需要什么，再看它交回什么。以后统计总额、检查金额和生成文字，都可以分别写成方法，让主流程更像按顺序连接这些小工具。

## 总结

- 方法用名称组织一组可复用步骤
- 参数说明调用时需要哪些输入
- 返回类型 int 说明最后交回整数
- return 把结果交回调用位置，再继续后续语句
