# 练习：通过公开方法修改属性

运行：`dotnet run --project corrected`。


本章练习，新建钱包以后，直接把Balance设置为十二。但属性的设置入口写着private，请根据访问范围判断编译工具会在哪里给出提示。类已经提供Add方法，可以接收一个整数增加余额。请想一想，调用者希望完成增加金额这个动作，怎样使用现成的公开入口把程序改通。

修正版把直接设置改成调用wallet点Add，传入十二。方法在类内部执行，所以能够通过设置入口更新Balance。最后公开读取余额，显示十二。把修改动作集中到方法里，随后就可以在同一处加入金额检查、操作记录或通知。调用代码按清楚的动作使用对象，类内部负责维护数据，这就是封装在本页例子中的具体作用。

## 总结

- Balance 公开读取，设置入口为 private
- 类外通过公开 Add 方法执行增加操作
- 修正版将直接赋值改为 wallet.Add(12)
- 修改路径集中在类中，后续方便统一加入检查
