# 抽象类约定需要完成的方法

运行：`dotnet run --project .`。


Shape表示形状，写成abstract class。抽象方法Area只声明返回一个整数，具体面积怎样计算留给具体形状来完成。Square表示正方形，构造函数保存边长，重写Area返回边长乘边长。这里把共同的面积操作和正方形的计算公式分开组织，使用者就能统一提出求面积的请求。

创建边长三的正方形，通过Shape变量调用Area，得到九。抽象类适合表达共同基础，并把部分操作留给派生类补齐。学习时先看基类要求哪些方法，再看具体类怎样实现这些方法，最后跟踪对象创建和调用路线。这样从声明到实现再到结果连起来，就能理解抽象类型在这段程序中承担的角色。

## 总结

- abstract class 描述有待具体化的共同类型
- 抽象方法只声明操作约定，由派生类实现
- Square 的构造函数保存边长
- 通过 Shape 调用 Area，执行正方形的实现
