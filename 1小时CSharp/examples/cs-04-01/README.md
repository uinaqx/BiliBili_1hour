# 用数组保存一组数据

运行：`dotnet run --project .`。


把多笔金额放在一起，可以使用数组。int后面加一对方括号，表示一组整数，花括号里给出十二、八、五三项。读取方括号零得到第一项十二，下标从零开始计数。Length给出元素数量，这个数组有三项。画图时给三个格子分别标零、一、二，就能把下标和数据位置对应起来。

把下标一的位置更新为十，数组内容成为十二、十、五。最后用string点Join把各项用逗号连接，方便在一行观察完整结果。数组在创建时确定长度，适合保存数量已经明确的一组数据。读取下标时，根据Length安排范围，从零到长度减一。下一页用foreach依次读取元素，就能把整组数据交给同一个计算步骤处理。

## 总结

- int[] 表示整数数组，创建时确定长度
- 下标从 0 开始，第一个元素写作 [0]
- Length 取得元素数量，合法下标到 Length 减一
- 按下标更新元素，Join 连接成可显示的文字
