# 用 TryParse 接收数字

运行：`dotnet run --project .`。

本页键盘输入：
```text
12
```

键盘输入读出来是文字。即使用户按下十二这两个数字键，程序接到的仍是一段字符串。int点TryParse尝试把文字解析成整数，返回一个真假结果。解析成功时，把得到的数字交给out后面的amount。你可以先把这一行读成，尝试读取整数，成功以后得到amount，接下来再决定执行哪一条路线。

本页输入十二，解析成功，进入花括号，把十二加八，显示二十。输入abc这样的文字，解析失败，就执行else后面的提示。下一章会详细学习if，现在先记住这个输入模板。读取文字，尝试解析，成功后使用数字，失败后说明该怎样重新输入。把每一步写清楚，用户交入不同内容时，程序都有明确的处理方式。

## 总结

- 键盘输入先作为字符串接收
- TryParse 返回 bool，说明解析是否成功
- 成功时通过 out 参数取得 amount
- 成功路径做计算，失败路径给出输入提示
