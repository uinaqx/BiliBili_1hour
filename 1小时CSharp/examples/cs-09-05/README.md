# 用 async 和 await 等待文件结果

运行：`dotnet run --project .`。


文件和网络操作经常需要等待。Async结尾的这些方法返回Task来表示一项异步工作，await等待本次结果准备好，再继续当前流程。先等待写入完成，再读取并显示文字，这样执行关系很清楚。异步等待期间可以把执行机会交回，让应用更方便地同时处理其他事情，界面程序和服务程序都经常使用这套写法。

自己的异步方法在前面写async，返回Task加尖括号int，表示最终得到一个整数。方法先用Delay模拟短暂等待，再返回十二。调用处await取得这份整数并显示。入门先沿着发起操作、等待结果、继续处理三个步骤阅读。课程采用顶层语句，入口也可以直接写await，配套项目已经设置好相应的语言版本。

## 总结

- 异步操作返回 Task 或带结果的 Task<T>
- await 等待本次操作完成后继续当前流程
- async 让方法内部可以使用 await
- 等待期间把执行机会交回，适合文件与网络等 I/O
