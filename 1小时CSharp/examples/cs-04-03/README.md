# 读取和组合字符串

运行：`dotnet run --project .`。


名称来自输入时，两端可能带空格。Trim返回去掉两端空白后的文字，我们把结果保存到cleaned。再调用ToUpper，得到大写的LUNCH并显示出来。Contains检查是否包含指定片段，这里包含小写的un，所以结果为真。沿着点号依次找到操作，再看参数和返回结果，就能读懂这些文字处理语句。

Length给出字符串的UTF十六代码单元数量，这段英文有五个字母，因此得到五。遇到表情等字符时，可以根据需要再学习专门的字符枚举工具。最后把cleaned放入显示文字，看到名称Lunch。cleaned保存的仍然是Trim的结果，大写操作返回的那份文字已经单独用于输出。想保留某次处理结果时，就把返回值接到一个名字上。

## 总结

- Trim 取得去掉两端空白后的字符串
- ToUpper、Contains 和 Length 处理文字
- 字符串操作返回新结果，按需要保存
- Length 按 UTF-16 代码单元计数，常见英文每个字母占一项
