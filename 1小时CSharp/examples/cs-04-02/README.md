# foreach 逐项处理元素

运行：`dotnet run --project .`。


这里继续使用三笔金额，准备求出总额，total先设为零。foreach可以读成，对expenses里的每一个整数amount，重复执行下面的步骤。第一轮amount是十二，第二轮是八，第三轮是五。它直接提供当前元素，适合只关心每项内容的处理，代码里就可以把精力放在每一轮实际要做的事情上。

每轮把amount加进total，累计值依次成为十二、二十、二十五。最后显示二十五。请区分amount和total的作用，amount代表当前这一项，total代表目前为止的合计。这个模式可以用在求总分、统计库存或计算订单金额。先找一项怎样处理，再让循环把同样做法应用到整组数据，重复逻辑就自然连起来了。

## 总结

- foreach 按顺序取得集合中的每一项
- amount 表示当前轮次读到的金额
- total 保存跨轮次累计的结果
- 依次加上 12、8、5，最终得到 25
