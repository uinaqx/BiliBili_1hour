# 引用让多个名字找到同一对象

运行：`dotnet run --project .`。


这一页先创建金额十二的对象，让first保存它的引用。把first赋给second，复制的是找到对象的这份引用。可以画一个记录方框，再画first和second两个名字，各自用箭头指向同一个方框。和前面整数参数的数值副本相比，这次两个名字共同找到了一份对象数据，观察方式也就跟着改变。

通过second把Amount改成二十，再从first读取，同样得到二十，因为读取的是同一个对象。ReferenceEquals进一步确认两个引用找到同一个对象，结果为真。要建立另一份独立记录，就再次使用new，并按需要复制字段。学习引用时，先数清楚一共创建了几个对象，再看每个名字指向哪里，很多更新行为都能由这张关系图解释。

## 总结

- 类变量保存对象引用，赋值会复制这份引用
- first 与 second 找到同一个 Expense 对象
- 通过 second 修改后，从 first 也读到 20
- ReferenceEquals 判断是否引用同一个对象
