# 用泛型保留输入输出的类型

运行：`dotnet run --project .`。


如果同样的步骤可以处理不同类型，就能把具体类型留成一个参数。Echo的尖括号里写T，参数类型和返回类型也写T，意思是本次传入哪种类型，就按同一种类型交回。这种带类型参数的写法叫泛型。这里直接返回输入，步骤非常简单，正好用来观察输入和输出之间的对应关系。

传入十二时，本次T确定为int，返回整数十二，接着加八显示二十。传入午餐时，本次T确定为string，返回文字，随后可以调用字符串操作。前面见过的List加尖括号，也是用类型参数说明容器保存什么。泛型先掌握这条主线，让一套做法适应多种类型，同时把调用之间的类型关系保留下来。

## 总结

- T 是本次调用使用的类型参数
- 参数和返回值使用同一个 T，保留两者关系
- 编译器可根据实参推断本次 T 的类型
- List<int> 等容器也用泛型约定元素种类
