# 练习：筛选后的数量与合计

运行：`dotnet run --project .`。


本章练习，从十二、八、五里保留大于等于八的金额，再使用ToList保存结果。随后分别显示数量和合计。请先写出筛选后到底有哪些元素，再计算Count和Sum。调用链可以从左到右拆开看，原数组交给Where，筛选规则产生结果，ToList把结果保留下来，后面的统计都围绕这份新列表完成。

满足条件的是十二和八，五被筛掉。列表有两项，所以先显示二。两项相加等于二十，所以再显示二十。到这里你已经能把多种方法连成一个处理过程，先按规则选数据，再根据目标做转换、排序或统计。练习时可以每次只改变一个条件，先预测结果再运行，逐步熟悉每个工具具体读入什么、交出什么。

## 总结

- Where 保留满足金额条件的元素
- ToList 得到本次查询的具体结果列表
- 筛选后剩下 12 和 8，数量为 2
- Sum 对筛选后的列表求和，得到 20
