# 练习：方法调用与求和

运行：`dotnet run --project .`。


本章练习，把列表求和包装成Sum方法。参数values接收一组整数，局部total从零开始，foreach逐项累计，最后返回结果。主流程准备十二、八、五，交给方法，再显示result。请先跟踪调用进入方法时发生什么，再跟踪return以后程序回到哪里，判断最后的输出。

累计过程是零变成十二，再变成二十，最后成为二十五，return交回二十五。调用位置用result接住它，显示二十五。想计算另一组数据，只要准备另一份列表再次调用。这样把变化的输入放到参数里，把稳定的处理保留在方法体中，程序就能自然复用。下一章再把每条记录的名称和金额放在一起，建立自己的数据类型。

## 总结

- 方法参数接收本次准备统计的列表
- 局部 total 从零开始逐项累加
- return 将 25 交给外面的 result
- 可改变输入列表，再复用同一个方法
