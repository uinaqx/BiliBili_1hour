# 用 try 和 catch 处理异常

运行：`dotnet run --project .`。


执行过程中有些操作会用异常报告失败。int点Parse尝试把abc解析成整数，遇到这份文字时抛出FormatException，也就是格式异常。把可能抛出异常的操作放进try，就能在附近安排处理。异常抛出后，执行路线转向匹配的catch，因此本页的金额显示语句会被跳过，程序开始寻找对应的处理方法。

catch写出准备接住的异常类型，这里显示请输入整数，随后继续执行结构后面的代码。请按抛出位置、匹配类型和处理动作三个步骤跟踪。面对日常输入，TryParse能把成功和失败直接写成分支；文件访问等操作则经常采用异常处理。根据操作本身提供的接口选择相应写法，就能把失败路线放到清楚的位置。

## 总结

- try 包住可能出现异常的操作
- Parse 遇到无法解析的文字会抛出格式异常
- catch 按异常类型接住对应失败
- 可预期的输入问题优先用 TryParse 表达分支
