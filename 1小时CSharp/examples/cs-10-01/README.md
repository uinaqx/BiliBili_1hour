# 设计开销记录的数据结构

运行：`dotnet run --project .`。


最后把知识点连成一个开销管理程序。Expense保存编号、名称和金额。编号用来找到某条记录，名称用于展示，金额采用decimal完成十进制计算。把这三项设计清楚，后面的新增、删除、统计和保存就能围绕同一种记录格式连接。每增加一个功能，先确定它需要哪些字段，再决定相应的方法接收什么输入。

这里创建编号一、午餐、十二元的记录，再读取三个属性显示出来，金额统一保留两位小数。配套完整项目使用控制台菜单，选添加、查看、删除或保存退出，就会调用对应的处理方法。本章先分几页看清关键步骤，再按README里的命令运行完整程序。跟着自己的输入观察数据怎样变化，就是把语法转成实际使用经验的过程。

## 总结

- Id 区分记录，Name 描述名称，Amount 保存金额
- 金额采用 decimal，输入输出使用同一约定
- 公开属性便于列表显示与 JSON 保存
- 先设计数据，再接上输入、统计和文件
