# 练习：列表更新后的结果

运行：`dotnet run --project .`。


这一题从十和二十开始，先添加五。随后更新下标零，再删除值为二十的元素。最后求当前列表的总额，并同时显示数量和总额。请按四次列表操作的顺序写出每一步内容，再进行foreach累计。先整理数据变化，再做统计，这样就能避免把已经删除的值继续算进结果。

添加以后是十、二十、五，更新以后是十二、二十、五。删除二十，剩下十二和五。所以数量是二，总额是十七，最终显示二和十七。列表的增删改查是很多应用的共同基础，任务列表、学生名单和开销记录都可以从这里扩展。下一章把统计步骤写成方法，就能在不同位置重复使用同一份计算逻辑。
