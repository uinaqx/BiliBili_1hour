# 练习：追踪条件与累计值

运行：`dotnet run --project .`。


这一题同时包含循环、判断和累计。i从一走到四，total开始为零。每轮先检查i是否等于二，满足时执行continue。随后可能把当前i加进total，最后显示累计结果。请列出四轮各自的i，再标出哪一轮跳过了加法。特别留意continue之后，for还会执行更新，让循环继续向前。

第一轮累加一。第二轮i为二，跳过后面的加法。第三轮累加三，第四轮累加四。所以最终结果是一加三加四，得到八。把条件改成i等于三，跳过的那一轮也会随之改变。做循环预测题时，先画出实际执行路线，再计算变量变化，条件判断和数值累计就能分开处理，思路会很清楚。

## 总结

- continue 跳过本轮后续语句，随后执行 for 更新
- i 为 2 时跳过累加，其他轮次累加当前 i
- 累计经过 0、1、4、8，最终输出 8
