# 练习：接口调用选择哪份实现

运行：`dotnet run --project .`。


这一题创建Welcome对象，交给IMessage类型的变量。接口只要求Show这个操作。Welcome提供具体实现，显示欢迎学习。请判断从message调用Show时，程序会执行哪里，最终显示什么。先把变量的类型和实际创建的对象分别写下来，再用箭头连接两者，沿着方法调用找到实际实现。

最终显示欢迎学习，因为message引用的对象是Welcome，它的Show方法负责完成这次调用。接口让调用者依赖共同约定，具体类把约定落成实际动作。学到这里，可以把对象程序分成三层阅读，数据和能力如何声明，对象怎样创建并初始化，最后哪些方法真正被调用。顺着这三层跟踪，继承、接口和多态就能放到同一段程序里理解。

## 总结

- message 按 IMessage 的约定使用对象
- 实际创建的是 Welcome，提供 Show 实现
- 调用 Show 时执行对象对应的实现
- 先看接口约定，再看 new 创建了哪个具体类型
