# 结构体与枚举表达小型数据

运行：`dotnet run --project .`。


struct定义结构体，它是一种值类型。这里Point只有一个整数属性X，用来观察复制行为。first的X为一，把first赋给second，会复制这份结构体值。随后修改second的X为九，从first读取依然得到一。请与上一页的类对象对照，一页是两个引用找到同一对象，这一页是两个各自保存数值的小记录。

enum定义枚举，给有限的一组情况起清楚的名字。PayStatus包含待付款和已付款两种选项。显示Paid会得到这个枚举成员的名称。状态数据使用具名选项，条件判断就能直接围绕业务含义来写。入门先掌握类、结构体和枚举分别适合什么，再根据需要学习更详细的复制规则、约束和表现形式，跟着实际例子逐步扩展即可。

## 总结

- struct 定义值类型，本页赋值复制 X 的值
- 更新 second 后，first.X 仍然是 1
- enum 为一组具名选项提供共同类型
- 类、结构体和枚举按数据用途选择
