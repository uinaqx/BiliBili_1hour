# 整数、小数、文字与真假

运行：`dotnet run --project .`。


数据也分种类。数量二使用int，适合整数。金额十二点五使用decimal，数字后面的小写m帮助编译工具确认这种十进制数类型，金额计算常用它。温度可以用double，适合常见的浮点数计算。先根据数据用途选择一种合适类型，后面的计算和调用就会围绕这个约定展开。

名称用string保存，引号里面是文字。是否付款用bool保存，true表示真，false表示假。最后一行在字符串前加美元符号，把变量放到花括号里，运行时就会代入当前值。价格后面的F2表示保留两位小数用于显示，因此结果包含十二点五零。控制台显示的True首字母大写，源代码中的true使用小写。

## 总结

- int 保存常见整数，double 保存浮点小数
- decimal 配合 m 后缀，适合十进制金额计算
- string 保存文字，bool 保存 true 或 false
- 插值字符串把变量放进花括号，F2 显示两位小数
