# 返回值、默认参数与命名参数

运行：`dotnet run --project .`。


有的方法主要完成动作，例如显示记录，返回类型就写void。这里Show接收名称和金额，金额参数提供默认值十二，方法体把两项组织成文字显示出来。参数名在方法内部承担局部名称的作用，每次调用都使用本次交入的数据。把输入和动作放在一起看，就能理解它为什么需要这些参数。

第一次只交入午餐，金额采用默认值十二，所以显示午餐十二。第二次按参数名写出金额八和名称交通，最后显示交通八。命名参数能让某些调用更清楚，尤其是多个参数类型相同时。需要把结果交给后续计算，就选择具体返回类型，需要完成显示或更新动作，就可以使用void，让每个方法的用途保持明确。

## 总结

- void 表示方法执行后没有返回值
- 默认参数在调用者省略该项时提供值
- 命名参数按名称说明传入数据的用途
- 方法参数只在该方法的作用范围中使用
