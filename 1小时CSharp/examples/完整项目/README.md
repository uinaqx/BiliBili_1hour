# C# 开销记录：完整控制台项目

安装可编译 net8.0 项目的 .NET SDK，在此目录执行：

```powershell
dotnet run
```

菜单：1 添加、2 查看、3 删除、0 保存退出。数据默认保存到当前工作目录的 `expenses.json`。可传入其他保存位置：

```powershell
dotnet run -- my-records.json
```

`Program.cs` 是程序入口，连接菜单与输入输出；`Expense.cs` 描述记录；`ExpenseBook.cs` 管理新增、删除、统计、JSON 读取和异步保存。

可以按顺序试验：添加午餐 12、交通 8 → 查看总额 20.00 → 删除编号 1 → 退出再打开，查看剩余交通 8.00。

金额接受小数点写法，例如 `12.50`，零也是合法金额。空名称、负数、无效编号都有对应反馈。读取失败时会保留异常文件的备份并显示恢复提示。
