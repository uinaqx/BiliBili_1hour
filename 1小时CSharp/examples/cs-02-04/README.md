# 从键盘读取一行文字

运行：`dotnet run --project .`。

本页键盘输入：
```text
小林
```

程序先显示请输入名称，给用户一个操作提示。Console点ReadLine等待用户输入一行文字并按回车。输入结束时它也可能交回null，表示当前没有取得一行内容。两个问号在这里提供备用值，左边为空时使用右边的空字符串，取得正常文字时继续使用那份文字。我们把结果保存进name。

最后把name放进问候语，实际输入小林，显示你好，小林。配套验证会自动把这段文字交给标准输入，运行结果和画面一致。你自己运行时可以换成其他名称，观察程序怎样接收和显示。这里建立了交互程序的基本路线，先给提示，再读取输入，再处理和反馈，后面的菜单和金额输入都会沿用这条路线。

## 总结

- ReadLine 等待并读取一行输入
- 返回的 string? 可以保存文字或 null
- ?? 在左边为空值时提供备用文字
- 本页实际输入为小林，运行结果可复现
