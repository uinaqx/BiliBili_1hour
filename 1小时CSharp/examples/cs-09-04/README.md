# 用 JSON 保存结构化记录

运行：`dotnet run --project .`。


JSON适合保存结构化数据，使用工具前引入System点Text点Json命名空间。把十二和八的列表交给Serialize，得到方括号包住两个数字的JSON文字。再把这份文字写进amounts点json文件。这里可以分成两层理解，JSON负责表达数据结构，文件负责把文字保存下来，它们分别完成格式转换和持久保存这两个步骤。

重新读取文字，用Deserialize按整数列表解析回来。返回值可能为空，两个问号在这里提供空列表作为备用。最后显示JSON文字和总额二十。完整记录也可以按同样方式序列化对象列表。读取以后再检查名称、金额和编号等业务规则，文件损坏时通过异常处理给出提示，恢复为可继续操作的状态，项目的数据路线就完整了。

## 总结

- Serialize 把数据整理成 JSON 文字
- 文件负责保存文字，数据格式由 JSON 表达
- Deserialize 按指定类型读取回列表
- 实际项目读取后继续检查金额、名称等业务规则
