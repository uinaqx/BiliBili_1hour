# 用类描述一条记录

运行：`dotnet run --project .`。


一条开销同时有名称和金额，可以用class把它们组织起来。Expense描述这类对象的结构，Name保存文字，Amount保存整数，public让类外面的代码可以访问这些字段。你可以把类看作记录格式，把对象看作按这个格式建立的一份具体记录。后面增加分类和日期时，也可以继续围绕这份记录整理字段。

new Expense创建一个对象，item保存找到这个对象的引用。通过点号设置名称午餐和金额十二。再读取同一对象的两个字段，显示午餐十二。先看类定义有哪些成员，再看对象创建以后怎样填写和读取，关系就很清楚。本页先用字段直接展示数据，下一页认识属性，为读取和修改提供更清楚的公开入口。

## 总结

- class 描述一类对象保存哪些数据
- new 创建一个具体对象，变量保存它的引用
- 本页 Name 与 Amount 是公开字段
- 点号访问该对象的字段，再按需要显示
