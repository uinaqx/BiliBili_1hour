# 重载为不同输入提供做法

运行：`dotnet run --project .`。


一个功能有不同类型的输入，可以提供同名方法的不同版本，这叫重载。这里用Formatter集中组织显示工具，public static先看作让外部直接使用这组方法的写法。接收整数的Label返回金额文字。接收字符串的Label返回名称文字。箭头把只有一个表达式的方法体写得更短，表达式的结果就是返回值。

第一次交入整数十二，编译工具选择整数版本，显示金额十二。第二次交入文字午餐，选择字符串版本，显示名称午餐。判断调用哪个重载时，重点看参数的数量、类型和排列。方法名相同可以表达相近用途，各版本的输入约定则把具体处理区分开。下一章会正式认识class，再把这些组织方式放进完整的类和对象关系中理解。

## 总结

- 同名方法可通过不同参数列表形成重载
- 编译器根据调用处的参数选择匹配版本
- => 在本页用来简写单个表达式的方法体
- Formatter 暂时作为相关显示方法的组织位置
