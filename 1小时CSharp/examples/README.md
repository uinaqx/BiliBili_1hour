# C# 配套示例索引

安装支持 net8.0 的 .NET SDK；各页代码都有独立项目。进入示例文件夹执行 `dotnet run`。

预期编译错误题目的原始程序会报错；正确版本请执行 `dotnet run --project corrected`。

`Program.cs` 是本页示例，`ConsoleEnvironment.cs` 统一 UTF-8 输入输出及数字显示格式，`Example.csproj` 保存 C# 12 与 net8.0 项目配置。

完整菜单项目见 [完整项目/README.md](完整项目/README.md)。
