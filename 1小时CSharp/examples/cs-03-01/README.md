# 用 if 选择执行路线

运行：`dotnet run --project .`。


程序已经会计算金额，现在让它根据情况给出提示。已花二十五，预算三十。if后面的括号检查已花是否小于等于预算，这份比较会得到真假结果。条件为真时，执行紧接着的花括号，显示预算内。花括号把一组语句放在一起，告诉程序它们共同属于这一条处理路线。

else表示另一种情况，条件为假时执行这里的显示语句。本页比较结果为真，所以最终显示预算内。你可以把已花改成三十五，再运行看看另一条路线。阅读分支程序时，先代入当前数据算条件，再选中实际执行的那一组语句。每次运行根据条件选择对应路线，显示结果也就跟着当前情况变化。

## 总结

- if 后面的括号放 bool 条件
- 条件为真执行第一组花括号
- 条件为假执行 else 对应的语句
- 本页 25 小于等于 30，输出预算内
