## 00:18:49 练习：把列表求和封装为函数

### 题目

题目把前面学过的循环放进函数。函数接收一组整数，内部从零开始累计，最后把总数交回去。外面准备十二、八、五，调用 sum，再显示 result。请先指出哪一行真正开始调用，随后分别写出三轮结束时的 total，再看 return 之后回到了哪里。

```swift
func sum(_ values: [Int]) -> Int {
    var total = 0
    for value in values { total += value }
    return total
}
let amounts = [12, 8, 5]
let result = sum(amounts)
print(result)
```

### 解析

循环依次累计十二、二十、二十五，return 交回二十五。result 接住它，再显示出来。如果把输入换成空数组，循环执行零轮，局部 total 保持初值零，所以函数会返回零。把处理步骤放进函数以后，准备不同输入就能验证很多情况，代码只需要维护一份。

运行结果

```text
25
```

## 00:41:37 练习：同一个泛型能推断出什么

### 题目

读一遍这道泛型题。pair 的两个参数都写成 T，返回的是一组 T 类型的值。题目把这两个参数按原来的顺序放进数组。现在给函数传四和九。请判断这次 T 是什么类型，并在脑子里记下数组中的顺序。程序会先输出元素个数，再输出下标为一的元素。暂停几秒，分别写下这两行会打印什么。

```swift
func pair<T>(_ a: T, _ b: T) -> [T] {
    return [a, b]
}
let values = pair(4, 9)
print(values.count)
print(values[1])
```

### 解析

四和九都是整数，这一次 T 推断成 Int。return 的数组先放四，再放九。count 给的是数组里的元素个数，所以第一行输出二。下标从零数。下标零对应四，下标一对应九，因此第二行输出九。用这一题复习一下两层信息。泛型告诉你数组装什么，数组本身的顺序和下标规则决定你能取到哪个值。

运行结果

```text
2
9
```

### 题目

来预测一个输出。数组里有一百、九百、五百和七百。题目先从里面找出至少五百的数，再对选中的数求和。判断时留心大于号旁边的等号，五百正好在边界上。这里把加法操作直接交给 reduce，初始值是零，作用相当于每轮写一次 sum 加 amount。暂停几秒，先写出 chosen 中的元素，再算最后的输出。


运行结果

```text

```

## 00:55:56 练习：捕获错误后程序走到哪里

### 题目

这个函数检查参数是否为负数，遇到负数就抛出 negative。函数没有提供一个用来继续计算的返回值，调用方只关心这次检查走到了哪里。题目传的是负二。请按行号追一下，先判断通过会不会打印，再判断最后一行的继续会不会打印。这里有一个 catch，还有一个放在整个结构后面的 print。暂停几秒，把输出按顺序记下来。

```swift
enum CheckError: Error { case negative }
func check(_ n: Int) throws {
    if n < 0 { throw CheckError.negative }
}
do {
    try check(-2)
    print("通过")
} catch {
    print("请重输")
}
print("继续")
```

### 解析

负二小于零，check 抛出错误。当前的 try 调用中断，do 里面的下一行被跳过。错误被 catch 接住，第一行输出请重输。catch 执行结束后，程序回到这个结构后面，第二行输出继续。这个模式可以用于带菜单的程序。一次录入有问题就提示一下，之后回到菜单，用户还有机会输入新的数据。

运行结果

```text
请重输
继续
```

## 01:01:51 练习：求当前列表总额

### 题目

做一道收尾练习。初始有三百和一千二百，再添加五百。接着删除位置零上的第一项。把数组写在纸上，每执行一行，就在下一行写出现在还剩哪些数据。removed 保存删掉的金额，total 用当前数组重新求和。这是两个不同的结果。题目会先打印删除金额，再打印当前总额。给自己几秒钟，先预测这两行输出。

```swift
var cents = [300, 1200]
cents.append(500)
```

### 解析

```text
300

```
