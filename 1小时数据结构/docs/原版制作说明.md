# 一小时学习数据结构

面向已认识 C++ 变量、函数、循环和简单指针的初学者与大学生。成片约 60 分钟，采用中文教师讲解、代码逐行高亮、二维结构图、运行结果和课堂小题。视觉沿用 Rust 第二讲的深色布局。

## 课程内容

导学、复杂度、数组与动态数组、链表、栈与队列、哈希表、树与二叉搜索树、堆与优先队列、图与图的遍历、二分查找、基础排序、综合应用与回顾。

12 章、69 个分镜、64 个可运行代码示例、11 道课堂题。范围为一小时基础入门；平衡树、最短加权路径等后续内容没有展开。完整讲稿位于 `content/完整讲稿.md`，实际时间见生成后的章节目录。

## 工程结构

| 文件 | 用途 |
|---|---|
| `content/chapters_a.py` 至 `chapters_c.py` | 原创旁白、屏幕代码、要点和习题 |
| `content/author.py` | 内容结构、完整程序上下文 |
| `public/course.json` | 课程清单 |
| `public/timeline.json` | 音频实测时间轴、字幕与动画事件 |
| `src/video.tsx` | 1920×1080 画面布局与代码高亮 |
| `src/diagrams.tsx` | 数组、链表、树、图等 SVG 图解 |
| `public/audio_original/` | 原始配音缓存 |
| `public/audio/` | 处理后的旁白与字幕时间数据 |
| `scripts/` | 内容构建、编译验证、配音、对齐、渲染和验收 |

工程包包含已制作的配音，可直接重渲染。修改旁白后才需要重新请求语音服务。更换课程时，应同步更换讲稿、图示和代码验证；不要仅替换标题。

## 安装与预览

需要 Node.js 22 或更新版本、Python 3.11、FFmpeg/FFprobe，以及支持 C++14 的 g++。本次实际编译器为 MinGW GCC 6.3，示例也适用于较新的 C++ 编译器。

```powershell
npm ci --ignore-scripts
python -m pip install -r requirements.txt
npm run studio
```

`npm ci --ignore-scripts` 避免 npm 将名为 prepare 的课程构建脚本当作安装钩子执行。首次运行 Remotion 时可能下载浏览器。中文字体使用 Microsoft YaHei，代码字体优先 Cascadia Code/Consolas；其他系统需安装或替换为具有中文字符的字体。

## 完整制作流程

在工程目录执行：

```powershell
python scripts/build_course.py
python scripts/verify_examples.py
python scripts/property_checks.py
# 需要新配音时，完成下面的凭据配置后执行：
python scripts/voice.py --from-env
python scripts/prepare_audio.py
python scripts/timeline.py
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/package.py
```

已有配音不变时，可跳过 voice 和 prepare_audio。`prepare_audio.py` 首次需要下载 Whisper base 模型；它按已知讲稿做声音对齐，不依赖额外在线识别服务。代码校验失败或布局溢出时会停止并报告分镜编号。

分章编码和静帧具有内容缓存。单章可用 `python scripts/render.py --chapter 05` 重做；画面变更后先重新运行 stills，再渲染。输出目录默认是工程同级的 `交付/数据结构一小时`。

## 阿里云百炼配音配置

本工程使用北京地域的 `qwen-audio-3.0-tts-plus`，声音 `longanlufeng`。密钥和业务空间 ID 只从环境或标准输入读取，不写入项目、音频缓存或日志。

在自己的百炼账号创建 API Key，取得同一业务空间的 Workspace ID，然后在本机进程环境中设置 `DASHSCOPE_API_KEY` 和 `SFM_WORKSPACE_ID`。不要将真实值写进脚本、终端共享记录、截图或公开仓库。示例文件仅提供占位符；免费额度与计费以本人控制台为准。

- [百炼开通说明](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)
- [创建 API Key](https://help.aliyun.com/zh/model-studio/get-api-key/)
- [获取 Workspace ID](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)
- [免费额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota)

默认服务语速统一为 1.0，配音完成后全课使用同一个 atempo 系数，本次约为 1.029。句号之间额外增加 0.1 秒，逗号不增加。题目结束后保留 4 秒思考；声音没有背景音乐。字幕逐句对齐到实际音频，持续到下一句出现，末句覆盖到朗读结束。

## 画面与编码

1920×1080、16:9，使用 30fps 时间刻度。代码 34px，运行结果在左侧代码下方、通常 32px，四行输出使用 30px 与紧凑行距；中文字幕底部居中、40px。动画的变化帧由 Remotion 绘制，静止段由 FFmpeg 保持，H.264 使用可变帧率编码；播放器显示的平均帧率可能较低，这是静态教学画面的编码方式。音频为 AAC 48kHz 单声道，MP4 含 12 个章节标记。

字幕的每次切换都生成一个编码事件。验收脚本逐个解码显示状态，检查有字幕的时段是否实际显示；另以每章 PCM 与最终 AAC 波形相关性核对拼接同步，并对全片进行严格解码。字幕对齐采用声音强制对齐和起音修正，机器检验不能代替人工听课。
