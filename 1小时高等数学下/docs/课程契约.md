# 高等数学（下）制作约定

面向零基础大学生，继承高数上课程的期末基础题型定位。使用常见理工类高数下范围：向量与空间解析几何、多元微分及极值、重积分、曲线曲面积分、数项/幂级数与傅里叶级数。不同学校顺序与取舍不同；未收到本校考纲，文档明确这一默认范围。

目标约一小时，优先原始自然语速，接受合理浮动。配音保持原始1.0倍速，禁止按时长自动调速；若需调整必须提前说明并取得用户同意。句号停顿额外0.1秒，逗号不额外处理。10道练习，每题4秒思考，答案另页。

1920×1080，30fps动画时间网格，静止状态VFR保持。深色公式板、持续高亮、右侧条件与步骤提示。重要区域、方向与法向用原创2D/3D连续动画，按人工选定旁白短语及最终PCM对齐。无底部字幕、无音乐，无无关座右铭。开头直接展示10章知识地图。

讲公式、条件、固定解题步骤与易错点，不展开证明。不承诺观看后自动及格。公式与例题独立计算核验，定理条件按一手教材核对；原片验收与改稿后版本分开。

交付成片、原始章节目录、讲稿、公式速查、练习答案、参考来源和可编辑工程。账号配置不进包。制作不自动授权上传GitHub。
