# 百炼语音配置与免费额度检查

已有工程内的配音可离线复用，不需要提供任何账号配置。只有修改讲稿后生成新语音才需要自己的账号。

## 一、开通账号与服务

打开[百炼控制台](https://bailian.console.aliyun.com/)，注册或登录自己的阿里云账号，完成要求的实名认证，阅读服务协议并开通百炼。地域选择**华北2（北京）**。

本工程调用普通百炼语音模型API，不需要购买服务器或创建智能体应用，也不要求购买Token Plan。开通账号不等于语音调用永久免费。步骤参考[官方首次调用说明](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。

## 二、创建API Key

在控制台API Key入口创建密钥，选择北京地域、自己的归属账号、默认业务空间或专门创建的空间。若设置自定义模型权限，应包含实际使用的语音模型。需要的是百炼API Key，不是阿里云AccessKey，也不是旧版语音服务Access Token。

密钥保存在自己的密码管理器中，不放到聊天、截图、代码或公开仓库。[官方密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key/)

## 三、获取对应的Workspace ID

进入业务空间，复制**API Key所属的同一个空间**的Workspace ID，不能用另一个空间、账号UID或APP ID代替。[官方获取说明](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)

## 四、确认当前模型与声音

本课程原片使用qwen-audio-3.0-tts-plus、系统声音longanlufeng，原生rate=1.0。生成前在模型详情页确认北京地域可用状态、空间权限、调用方式、当前价格及可用额度；额外开通或申请以页面实际要求为准。

模型清单、权限和免费活动可能变化，工程中的成功缓存不能保证另一个账号也能调用。遇到403 AccessDenied.Unpurchased应先检查服务开通、具体模型额度和空间权限，恢复后从缓存继续。

## 五、首次调用前检查免费额度

在控制台免费额度中查找**实际使用的完整模型名称**，查看剩余额度与有效期。如果该模型提供“免费额度用完即停”开关，建议开启。如果没有额度、额度过期，或没有相应保护开关，先确认价格并决定是否接受付费，再调用。

不保证每个账号、每个模型都有免费额度，具体规则以[官方免费额度说明](https://help.aliyun.com/zh/model-studio/new-free-quota)与控制台为准。

## 六、设置本地环境

在本地终端设置DASHSCOPE_API_KEY、SFM_WORKSPACE_ID；.env.example只有变量名，不含真实值。脚本通过进程环境读取配置，不自动加载.env。不要把带真实值的命令或终端截图提交Git。

先运行python scripts/voice.py --test，通过后再运行python scripts/voice.py。改变文字、模型、声音、指令或语速会使对应缓存失效。不要为了试听重新批量生成全部课程，避免不必要的调用。
