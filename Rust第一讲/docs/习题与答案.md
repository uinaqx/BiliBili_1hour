## 答案与讲解

### 01 给数据起名字 · 00:03:57

可以运行，输出六。第二行有 let，创建的是一个新的同名变量。它先用原来的三乘以二，再把结果保存下来。

变量这一节，我们先记住三个写法：let 保存数据，mut 允许修改，重复写 let 可以重新声明。接下来看看这些变量能保存哪些数据。

```rust
fn main() {
    let count = 3;
    let count = count * 2;
    println!("{count}");
}
```

结果：
```text
6
```

### 02 数据也分种类 · 00:08:27

输出九十和四。位置从零开始，位置二是第三个成绩。数组一共有四个元素。

如果访问位置四呢？这个数组没有第五个元素。越界访问会失败，而不是让你放心地读取旁边的内存。在直接写出的常量索引中，编译器有时就能发现问题；运行时才确定的非法索引，也会让程序发生 panic，通常会停止当前执行。这类失败不等于“读到了零”。

这一节不用记完所有类型，先把数据分成几类：整数、小数、真假、字符，以及放在一起的一组数据。知道自己要保存什么，再选择类型。

```rust
fn main() {
    let scores = [60, 75, 90, 95];
    println!("{} {}", scores[2], scores.len());
}
```

结果：
```text
90 4
```

### 03 把步骤写成函数 · 00:11:44

把 n 乘二后面的分号去掉，就可以把十二返回。也可以改成 return n 乘二，保留分号。

所以，函数这一节先记住：参数要写类型，需要返回值时写箭头；使用最后一行返回结果时，注意不要多加分号。

```rust
fn double(n: i32) -> i32 {
    n * 2
}

fn main() {
    println!("{}", double(6));
}
```

结果：
```text
12
```

### 04 根据情况作决定 · 00:13:46

两种情况都会报错。因为两条分支的类型不一致，编译器在运行前就会检查这一点。条件今天走哪一边，不会取消这个要求。

可以把两个分支都改成文字，例如“有成绩”和“没有成绩”。如果真正需要表示有一个数字或没有数字，后面 Option 一节会给我们更合适的写法。

```rust
fn main() {
    let value = if true {
        "有成绩"
    } else {
        "没有成绩"
    };
    println!("{value}");
}
```

结果：
```text
有成绩
```

### 05 交出去、复制或借一下 · 00:21:41

没有交出去，两次输出都可以执行。&name 创建的是借用，拥有者仍然是 name。

把这一节浓缩成三个动作：直接交给另一个变量或函数，可能发生移动；需要独立副本，可以主动 clone；只是使用一下，优先考虑借用。

这三个动作分清以后，后面学习结构体、集合和字符串会轻松很多。如果刚才某一段还不熟，建议回看“函数显示姓名”的两种版本：参数是 String 与参数是 &String，区别就集中在那里。

```rust
fn main() {
    let name = String::from("小林");
    let view = &name;
    println!("{view}");
    println!("{name}");
}
```

结果：
```text
小林
小林
```

### 06 把学生信息放在一起 · 00:26:19

在 student 前面加 mut。因为 add_bonus 会修改学生的成绩，调用它时需要可变借用。修改后的完整版本就是刚才那个输出八十五的程序。

结构体这一节的核心很简单：相关的数据放在一起，相关的操作也可以放在一起。字段负责保存信息，方法负责使用这些信息。

```rust
let mut student = Student::new(String::from("小林"), 80);

```

结果：
```text

```

### 07 几种情况分别处理 · 00:28:40

因为 match 没有处理 No。即使这里创建的是 Yes，匹配代码也要把这种枚举的可能情况处理完整。

加上一条 No 的分支就可以了，比如显示“不同意”。我们常说 match 需要“穷尽匹配”，意思就是别遗漏可能情况。这个名字认识即可，真正要做的是把每种情况想一遍。

下一节会用到 Rust 已经准备好的一种枚举。它专门表示：有一个结果，或者没有结果。

```rust
enum Answer { Yes, No }
fn main() {
    let answer = Answer::Yes;
    match answer {
        Answer::Yes => println!("同意"),
        Answer::No => println!("不同意"),
    }
}
```

结果：
```text
同意
```

### 08 有结果或没有结果 · 00:32:31

先输出零，再输出六十。Some 零表示确实有一个值，而且它就是零；默认值只在没有值时才会使用。

这个区别记牢，Option 就有了最重要的用途：把“缺少数据”清楚地表达出来。下面访问集合时，我们马上会遇到它。

```rust
fn main() {
    let first = Some(0);
    let second: Option<i32> = None;
    println!("{}", first.unwrap_or(60));
    println!("{}", second.unwrap_or(60));
}
```

结果：
```text
0
60
```

### 09 保存一组成绩 · 00:36:30

它会正常输出“没有第五个成绩”。get 把不存在的位置表示成 None，match 已经处理了这种情况。

到这里，Vec 的基本操作就齐了：创建一组值，push 增加，pop 取出末尾，get 查询，再用 for 遍历。结合 Option 和借用，我们就能安全地处理一组数据。

```rust
fn main() {
    let scores = vec![70, 80];
    match scores.get(4) {
        Some(score) => println!("{score}"),
        None => println!("没有第五个成绩"),
    }
}
```

结果：
```text
没有第五个成绩
```

### 10 保存与读取文字 · 00:40:56

分别是六和二。两个普通汉字各占三个 UTF-8 字节，所以字节数是六。chars 在这里依次得到“你”和“好”，所以 count 得到二。

字符串这一节，先抓住两点：String 负责拥有文字，&str 用来借用文字；处理中文时，字节数量和字符数量要分开看。

```rust
fn main() {
    let greeting = "你好";
    println!("{}", greeting.len());
    println!("{}", greeting.chars().count());
}
```

结果：
```text
6
2
```

### 11 根据姓名查成绩 · 00:44:48

结果是九。因为原来的记录存在，or_insert 不会覆盖它。原来的二继续增加七，得到九。

这一节记住三个操作就够了：insert 放入或更新，get 查询，entry 配合 or_insert 处理“有就使用，没有就初始化”。有了这些操作，我们已经可以写简单的成绩查询和次数统计。

```rust
use std::collections::HashMap;
fn main() {
    let mut counts = HashMap::new();
    counts.insert("小林", 2);
    let count = counts.entry("小林").or_insert(0);
    *count += 7;
    println!("{count}");
}
```

结果：
```text
9
```

### 12 同样做法、不同类型 · 00:49:05

第一种可以。第二种不可以，因为同一次调用中的两个 T 需要是相同类型，一个整数和一个文字引用不一致。

泛型这一节，先记住两句话：T 是一个类型位置，具体使用时才确定；需要对 T 做某种操作，就要说明它具备对应能力。

```rust
make_pair(80, 90)       // 两个参数同类型

// make_pair(80, "小林")  // 类型不同，不能这样调用
```

### 13 说明能做什么 · 00:53:31

不可以。show 要求传入类型实现 Introduce。名字叫课程，或者我们认为它应该能介绍自己，都不够；要在代码中真正实现这个约定。

给 Course 写 impl Introduce for Course，再补上 introduction 方法，就可以使用同一个 show。

到这里，我们不用背长串 trait 名称。先理解它在做什么：让代码明确说明需要哪种能力，让不同类型用各自的方式提供这种能力。

```rust
impl Introduce for Course {
    fn introduction(&self) -> String {
        String::from("课程：Rust 基础")
    }
}

show(&Course);
```

结果：
```text
课程：Rust 基础
```

### 14 借来的数据必须还在 · 00:59:46

不能。标记描述引用之间的关系，不改变数据实际何时被清理。要修正，需要真正调整数据保存的位置、使用位置，或者创建独立拥有的数据。

如果今天只记住生命周期的这一点，就很好：借来的引用，不能比它依赖的数据使用得更久。

```rust
fn main() {
    let name = String::from("小林");
    let view = &name;
    println!("{view}");
}
```

结果：
```text
小林
```
