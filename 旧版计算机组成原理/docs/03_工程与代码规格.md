# 工程实现规格

## 执行入口与产物

当前由主代理亲自实现可运行工程，保留课程目标。用户已暂停配音工作；下面的配音规范仅保留为未来接入设计，不属于本轮完成条件。

```text
build_content.py           # 作者源，60镜完整内容
data/course.json           # 7200秒时间轴与全稿，禁止删减成标题
docs/                     # 规划、逐字稿、制作规范、验收
src/experiments.py        # 可导入的确定性教学模型
src/build.py              # 生成实验数据和离线播放器
src/render.py             # 真实导出样片；依赖与限制明确
audio/                    # 后续配音接口预留，本轮不实施声音处理
tests/                    # 验证边界、机制和课程一致性
output/index.html         # 无需账号或网络的互动预览
output/experiments.json   # 所有模型运行证据
output/preview.mp4        # 至少30秒实渲染样片，无配音标注
output/validation.json    # 实际测试与覆盖情况
audio/                    # 用户提供S01.wav…S60.wav的接口
```

实现语言优先Python3标准库＋原生HTML/CSS/JavaScript/SVG。不要引入React、复杂构建器、付费API或TTS。必要渲染依赖可安装，但先核对云网络技能和策略，记录版本；无需Docker。播放器应读取内嵌JSON，支持直接打开，不依赖跨源fetch；持久内容输出UTF‑8。需要网络下载的依赖不可成为阅读讲稿或运行模拟器的前提。

## 数据与时间轴

输入course.json含schema_version、title、duration、fps、width、height、chapters、scenes。镜头字段id/title/start/duration/narration/visual/on_screen/question/answer/demo/beats/audio/timing_status。原始时间严格连续，无空隙无重叠，60×120=7200。beats为段内相对时间，覆盖完整120秒。

播放器支持：播放/暂停、全片进度定位、上一镜/下一镜、章节与镜头选择、0.5/1/1.5/2倍速、字幕/全文面板、单步实验、显示模型假设。缺少配音时清楚显示“无配音预览”。重置或seek后状态由绝对时间重建，不能依赖累计setInterval产生的漂移。动画依照`scene_local_time`映射到beat，再映射到实验事件。

用SVG函数分别生成：位串/编码、加法与ALU、芯片扩展、地址拆分、Cache状态、CPU数据通路/寄存器、流水线甘特图、性能时间条、I/O泳道图。已有专用分镜不能被忽略。首版若仅实现部分专用动画，必须输出逐镜覆盖清单区分“专用”“复用解释图”“文字占位”，最终完成前文字占位应清零。

## 教学实验：输入、输出与验收

### representation

实现`to_unsigned(value,bits)`与`to_signed(value,bits)`；位宽必须为正整数。验证−5→8位0xFB、0x80→−128、0xF0→−16；8位补码/4小数位0xF0→−1；−5算术右移1位→−3；0x12345678小端字节[0x78,0x56,0x34,0x12]。这些为位串模型，不把Python无限精度整数行为直接冒充固定位宽硬件。

### arithmetic

提供全加器真值表、n位加法结果/无符号进位/有符号溢出；120+20在8位里结果0x8C且溢出，0xFF+1有进位但补码不溢出，127+1溢出。无符号移位乘法13×11=143，逐步部分积；恢复余数除法13÷3=商4余1，输出每轮余数与商，除零显式失败。ALU对12和10给出加22、与8、或14、异或6。

### floating

用Python `struct` 取得binary32位模式并明确每步转换为binary32；5.75→0x40B80000；2^24+1在binary32就近偶数规则下回到2^24；构造零/非规格化/无穷/NaN分类表。只演示、验证给定算例，不宣称完成了IEEE 754全部运算实现。0.1+0.2的例子注明若直接用Python float则通常为binary64。

### memory

存储扩展2K×8→8K×16：8片，2片位扩展、4组字扩展，按字编址13位地址、11位片内、2位选组。四体低位交叉`bank=word_address%4`，0/1/2/3分散，0/4/8/12冲突。分页4KiB偏移12位、32位VA的VPN20位；演示翻译保留offset，显式区分TLB miss与缺页。

### cache

配置合法性：总容量、块大小、路数为正且整除；块大小、组数为2的幂。支持直接映射/组相联、LRU、写分配、回写和脏位；输出每次操作前后组内容、tag/index/offset、hit/miss/eviction/writeback事件。若不实现直写等其他策略，仅把它们作为概念讲解，不声称模拟器全支持。

- 4KiB、16B块、直接映射、32位地址→tag20/index8/offset4；0x12345678→tag0x12345/index0x67/offset0x8。
- 同参数2路→tag21/set7/offset4。
- 16B总容量、4B块、地址0/16/0/16：直映4次失效；2路后两次命中。
- 2路同组A/B/A/C，LRU淘汰B；脏B淘汰必须有写回事件。
- 综合：64B容量、16B块、1路，冷启动读0x100/104/108/10C→M/H/H/H；写0x200时写分配、替换干净数组块，结果块置脏。分别报告4次read命中率75%与包括store在内的总命中率60%，两者不能混淆。

### cpu

支持语义指令addi/add/lw/sw/bne足以完成下面程序；不声称完整解码器。32个32位寄存器，x0硬连零；有界字节内存，小端字读写，地址对齐检查；有最大步数防止无限循环。每步输出before_pc、instruction、寄存器改变、内存访问、after_pc、分支是否成立。

```asm
# 手工教学程序；不是遵守ABI的独立函数；地址为十进制
 0: addi x1, x0, 256
 4: addi x2, x0, 0
 8: addi x3, x0, 4
12: lw   x4, 0(x1)
16: add  x2, x2, x4
20: addi x1, x1, 4
24: addi x3, x3, -1
28: bne  x3, x0, 12    # 语义目标绝对地址12；不是原始立即数字段
32: sw   x2, 512(x0)
# PC到36由测试框架停止，没有杜撰halt指令
```

初始化[0x100,0x104,0x108,0x10C]=[3,5,7,9]。最终x1=0x110、x2=24、x3=0、x4=9、M[0x200]=24，退休24条，分支T/T/T/F。另测负数回绕、非法操作、非对齐、越界、写x0、无限循环保护。

### pipeline

先实现清楚限定的短序列调度器，或生成算法可核验的指定片段。五级单发射、顺序、有EX转发、分离指令/数据资源。必须用生产者可用周期与消费者需求周期判断，不可仅凭相邻寄存器同名就盲目停顿。

- 独立n条→n+4周期。
- add→依赖sub：0额外停顿。
- lw→依赖add：1停顿，2条共7周期。
- lw→依赖add→独立addi：共8周期。
- lw→独立addi→依赖add：共7周期。
- 分支概念图独立注明预测与恢复前提；若未实现实际分支调度，明确分类为“预设时序示意”，不能冒充通用模拟。

展示的时间表必须包含实际冻结/气泡，不能让依赖指令提前进入EX却只在总数上加1。

### performance / io / integrated

统一输出单位明确的计算：AMAT3.5ns与3.45ns两种条件；2+0.1×30=5ns；CPU0.75ms/4ms/0.6ms；缓存停顿CPI1.6；Amdahl2.5倍/极限5倍；64bit×100MT/s=0.8GB/s；7200rpm平均旋转4.1667ms。I/O事件流轮询第5次ready、4次空查；中断与DMA采用教学事件泳道，不编造硬件测量。

## 配音、字幕与导出

用户提供音频，默认按镜头`audio/S01.wav`…`S60.wav`；支持映射清单指向其他本地音频格式。仅做接入，不生成配音。未来若新增`src/audio.py`，应使用ffprobe获取真实时长并输出missing/ok/too_long状态；缺失不能标为合格。超过镜头预算时阻止“最终成片”导出，不截断，不偷偷倍速。

精确字幕必须来自用户提供的句级时间戳，或在音频已提供后完成实际对齐。无音频时只输出标明“估时草稿”的字幕/分段稿，不能声称逐字精确。建议以同一语义句作为字幕和动画cue，单条不超过2行，每行尽量不超过22个中文字，公式单独校对。

导出样片时可不带声音，但文件名/页面必须注明silent_preview。导出范围可选镜头与起止秒，要求样片至少30秒，包含位运算/Cache或流水中至少一种真正状态变化。精剪母版目标H.264、yuv420p、1920×1080、30fps；本轮全长静音状态保持版可采用VFR并明确标注，使用时间戳保持每个教学状态；音频存在时AAC/48kHz；封装.mp4。需要写清如何重现，失败时不输出空文件冒充成功。

至少提供完整7200秒静音预览的命令或导出入口。若尚不能完成全长离线视频，明确限制和后续实现步骤；网页可播放7200秒不自动等于已导出两小时MP4。
