# 技术审核、资料与成片验收

## 事实审核重点

|位置|必须保留的限定|错误表达示例|
|---|---|---|
|S02/S26/S28|本片选择RV32I且关闭压缩扩展；编号位宽与数据位宽区分|所有RISC指令一定一样长|
|S04–06|明确位宽和补码/无符号解释；移位规则按模型|有最高进位就有有符号溢出；负数右移等于所有语言的除二|
|S07–08|normal与subnormal公式分开；binary32与Python默认float分开|所有指数域都使用隐含1；浮点数等于实数|
|S10/S16|标志计算为观察量；基础RISC-V没有传统算术条件码|模拟器显示overflow就说明RV32I有溢出标志寄存器|
|S11–12|主片迭代例子是无符号；乘除不属于基础RV32I|无符号移位累加直接代表完整补码乘法|
|S15|时钟约束包含寄存器和组合路径；例子忽略部分现实细节|缩短周期会自动缩短组合电路传播延迟|
|S18|芯片题按16位字编址，与一般字节编址另行声明|8K×16永远只需13根CPU字节地址线|
|S20–23|Cache数据容量不含元数据；区分额外代价与总时间|AMAT的miss penalty可以不看定义随意套|
|S24|TLB miss与缺页区分，页内偏移保持|TLB miss一定读磁盘|
|S25/S30|手工教学汇编、非完整ABI；PC=36由框架停止|这就是任意优化编译器生成的程序；RV32I有halt|
|S31/S39|模型明确不支持非对齐字访问|所有真实机器都以相同方式拒绝非对齐访问|
|S32–37|每张图标单周期/多周期/流水模型|把不同实现的寄存器与控制步骤混成一张真实CPU图|
|S38|同步/异步来源与返回点按事件定义|所有异常返回PC+4；中断瞬间打断任何半步|
|S40–44/S58|转发路径、数据可用时刻、分支判定阶段明确|load-use永远只有1周期；所有分支都固定2周期|
|S45|重命名不能消除真实RAW|乱序执行可以忽略程序依赖|
|S46–49|CPU时间/墙钟时间、基础/总CPI、概率分母明确|命中率提升多少，程序就必然加速多少|
|S50–54|GB/MiB、传输次数、旋转等待、MMIO副作用明确|时钟频率直接等于带宽；DMA没有CPU参与|
|S55|语义内存与回写Cache不同观察层；读命中率单列|写进Cache就等于已经写回主存；75%含全部访问|

## 核对与延伸资料

这些是核对概念和继续学习的来源，不表示本课程逐章复刻某一教材，也不声称覆盖任何学校当期教学大纲。在线入口检查记录保存在 `data/reference_checks.json`；网页能打开仅证明入口可用，不等于逐段事实已被该页面直接证明。

1. [RISC-V官方RV32I说明](https://docs.riscv.org/reference/isa/unpriv/rv32.html)：寄存器、基础整数指令、load/store、分支、指令语义。用于核对S02、S25–35；教学模拟器是该体系的有限语义子集。
2. [RISC-V官方Supervisor说明](https://docs.riscv.org/reference/isa/priv/supervisor.html)：分页、地址翻译、异常相关接口。用于核对S24/S38的边界，不要求入门者在两小时里掌握所有特权机制。
3. [IEEE 754-2019标准入口](https://standards.ieee.org/ieee/754/6210/)：浮点格式、舍入与特殊值的标准来源。标准全文可能受访问许可限制；本项目没有把未取得的全文当成已读资料。
4. [MIT 6.004 Computation Structures](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/)：从数字逻辑到处理器、存储与并行机制的公开大学课程，适合补充电路到系统的连接。
5. [UC Berkeley CS61C](https://cs61c.org/)：机器表示、RISC-V、CPU、Cache与性能的大学课程入口。不同学期页面与安排会变化，选择适合自己的公开讲义。
6. [Nand2Tetris课程](https://www.nand2tetris.org/course)：适合希望自己从逻辑门搭建简化计算机的课后实践。它使用自己的教学体系，不要把其指令或硬件约定直接混入RV32I示例。
7. Patterson与Hennessy，《Computer Organization and Design: The Hardware/Software Interface》，RISC-V Edition：围绕数据通路、流水线、存储层次与软硬件接口的系统阅读。使用所在学校指定版次，不凭空标页码。
8. 学校指定的《计算机组成原理》教材与实验指导：对照本片未展开的算法推导、控制字设计和实验电路，保持术语与授课要求一致。

- [ ] 每镜音频已提供并测量，含停顿的总安排不超过120秒；缺失和超长不得标成完成。
