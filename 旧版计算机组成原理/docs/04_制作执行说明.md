# 制作执行说明

本项目由当前助手直接制作，配音暂不处理。以下入口以实际本地工程为准。

```bash
python build_content.py
python -m src.build
python -m unittest discover -s tests -v
python -m src.audit_browser
python -m src.render --start 2565 --duration 30 --mode smooth --output output/silent_preview.mp4
python -m src.render --duration 7200 --mode keyframes --output output/course_120min_silent.mp4
```

离线审片入口为`output/index.html`。所有旁白、分镜与300个阶段提示已由统一课程数据生成。`src/experiments.py`提供确定性模型；`src/player.js`将绝对时间映射为SVG画面；`src/render.py`使用相同画面导出真实视频。

全长静音版采用教学状态保持方式：在关键计算、字幕或机制变化点更新画面，全长文件采用VFR时间戳保持画面；短样片为恒定30fps。短样片使用逐帧捕获。两者的视觉状态来源相同，不能将状态保持版描述成全片逐帧过渡动画。

配音方案不在本轮实施范围，音频选择、TTS、对齐及声音合成均暂停。画面内的文稿展示是估时阅读提示，不宣称已和语音对齐。

完成记录见README与output中的验证报告；文案修改从build_content.py开始，重新生成后再build，避免只改派生文件。
