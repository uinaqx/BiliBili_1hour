# 课程字幕契约

适用于所有课程版本，包括原速、变速、重制和无字幕母版。每个版本使用对应的母版、时间轴和最终 PCM。需要含字幕成片时，先生成并验证时间表，再从无字幕母版烧录。

## 1. 时间源

- 从 `public/timeline.json` 读取 fps、场景 startFrame、durationFrames 和 leadFrames。场景旁白全局起点为 `(startFrame + leadFrames) / fps`。
- 从场景音频 JSON 读取最终 WAV 上各 part 的 start、end，以及插入停顿前的切点。优先使用该处的 addedSeconds，其次用工程声明的 sentencePauseSeconds 或 fullStopExtraSeconds。存在切点却缺少长度时，先补齐可核验的元数据。
- 词时间来自本版本 `build/alignment/<rawKey>.json`。将切点换算为实际 PCM 采样位置。词首用 bisect_right 累加之前及同位置的停顿，词尾用 bisect_left 累加严格在此前的停顿，再加上场景起点和 part.start。逐段重组 PCM，验证与最终 WAV 一致。已经以最终 PCM 为时基的旧版对齐只走一次映射，旧格式要先核验出处和单位。
- 时间轴、正式讲稿、PCM、切点及词对齐均记录 SHA-256。任一输入变更后重新生成。变速版的缓存须来自其实际播放速度和时基。

## 2. 字幕条目

- 文本取自本版本正式讲稿或页面 cue。ASR 只用于复核。语音服务的异读写法可通过明确的词组映射还原成讲稿，如 sequel 对应 SQL。保留代码、数字、IP、文件路径的写法。
- 起点取首词起点。末词、其他有效词的最晚结束时间构成 spokenEnd。默认结束时间为 `max(spokenEnd, min(spokenEnd + tail, nextStart, partEnd))`，tail 介于 0 和 0.12 秒。显式启用 hold 时，统一保留至同一 part 下一条字幕开始，末条仍遵循 part 边界。
- 依据句号、问号、分号、较长逗号分句、显示宽度和实测词间静音断句。相邻有效词时间重叠时合并，保护原词尾。零时长、倒置词并入相邻有效词，仅继承文本。整段无法定位有效词时应重校对齐。
- 对齐若与实际发音有差异，先核对并修订对齐源，保留证据。全局平移、拉伸、统一延长字幕或以显示边界回填 spokenEnd 均不能替代修复。

## 3. 烧录

- 输入为同版本无字幕母版。检查其时基、章节、音频和原有字幕层。VFR 或长持帧必须先用 `fps=fps=工程FPS:round=up` 展开画面，再运行 ASS 滤镜，输出 `-fps_mode cfr`。恒帧母版也可使用同一入口。保持原音轨 stream copy、原章节和 metadata。输出另存。
- ASS 两端都向上取到百分之一秒，SRT 向上取到毫秒。校验转换后的时间仍覆盖词尾。视频实际 PTS 用来验证显示位置，字幕生成以音频时基为准。

## 4. 交付检查

- 逐条统计最小 `end - spokenEnd`、负数条数、提前超过 100 ms 的条数。负数即失败。报告 FPS、公式、母版帧时序与输出 CFR、ASS/SRT 哈希、母版与成片哈希。
- 从成片取每条字幕结束前 0.10 秒和结束后 0.10 秒的实际显示帧。视觉核对结束前仍为本条、结束后为下一条或空白。对短字幕，前采样点限制在其有效区间内。采用 hold 时取下一句前 0.05 秒，并按 ASS/CFR 的实际采样位置解释交点的边界帧。
- 核对时长、章节、音轨、完整解码及无软字幕流。抽样用 ASR 与讲稿对照，低分项逐项人工复核，区分同音字和真实错位。仅做了结构或像素抽检时，报告范围据实填写，不算完成语音验收。
