# 零基础 Python 练习指南

## 先运行第一句话

1. 打开 [Python 官方下载页](https://www.python.org/downloads/)，选择适合系统的受支持 Python 3。
2. Windows 新版可按 [官方 Windows 安装说明](https://docs.python.org/3/using/windows.html) 使用安装管理器；传统安装器若提供 Add Python to PATH，可勾选。安装后重新打开终端。
3. 输入 `python --version` 检查版本。Windows 也可尝试 `py --version`；macOS/Linux 通常检查 `python3 --version`。
4. 打开 `Python示例/01-1` 文件夹，在这个文件夹打开终端。Windows 11 通常可右键空白处选择“在终端中打开”。
5. 执行 `python main.py`，或使用本机已经确认的 `py main.py` / `python3 main.py`。
6. 看到 `Hello, Python!` 后，只修改引号里面的文字，保存，再运行。

文件后缀必须是 .py，不要误存成 main.py.txt。若屏幕出现 `>>>`，说明进入交互模式；可以输入 `exit()` 返回终端，再执行运行文件的命令。本课展示的是文件代码，不需要把 `>>>` 抄进文件。

## 每次只改一个地方

先预测，再运行，再解释差异。可以把预算 30 改成 20、把开销 25 改成 35、把 `<=` 改成 `<`，或者改动列表中的一笔开销。不要第一次就同时修改几个条件和多个变量。

Python 的缩进有实际作用，建议统一使用四个空格。if、for、while、def、try、with 等结构末尾的冒号不能随意省略。某行回到外层缩进，通常表示它不再属于上一组重复或条件范围。

## 模块与文件怎样练习

`10-2` 有 main.py 和 budget_tools.py 两个文件，保留在同一个目录，运行 main.py。不要把自己的文件取名为 math.py 等常用模块名，以免遮住本来想导入的工具。

`10-3` 写出费用文件；`10-4` 自带读取所需的 expenses.txt。所有文件操作都在对应练习目录运行，别把工作目录设在自己的重要资料目录。w 会覆盖旧内容，a 才是追加。

`10-q`、`10-a` 的初始 expenses.txt 都是一行 `12`，末尾有换行。每次重新比较答案前，将文件恢复为这份初始内容；追加程序重复运行，会继续追加，不会自动恢复。

## 看懂错误类别

- 01-q：缺少右括号，属于语法错误，先修正写法。
- 06-q：写法可以解析，但运行时读取不存在的位置，发生 IndexError。
- 11-1：捕获不符合整数写法的输入所引发的 ValueError，显示自己的提示。

先找错误消息里自己文件对应的行，再看这一行想对什么数据做什么操作。没有错误消息不代表逻辑一定正确，还要核对输出是否符合需求。

## 五个课后小任务

1. 把三笔开销改成其他整数，计算总额和余额；用预算附近的值检查判断。
2. 用循环处理列表，再用 sum 对照；也试试空列表的总和。
3. 让两个名字使用同一列表，观察 append；再用 copy 比较独立的一层列表。
4. 用字典保存商品价格，分别处理零元商品和没有记录的商品。
5. 把费用文件逐行读入，转换并求和；为不合法的数据设计清楚的提示。

先独立写，再翻答案核对。熟悉以后继续学习调试和测试、类与对象、更多标准库，再选择感兴趣的自动化、数据或网络方向。
