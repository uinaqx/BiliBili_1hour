# 一小时学习 Python：零基础入门

面向完全没有接触过编程的学生。沿用 Rust 第二讲的画面：深色代码区、逐段高亮、左侧代码下方大字运行结果、右侧中文要点与关系图。1920×1080，中文沉稳男声，**无字幕、无背景音乐**。底部只保留片段编号。

全课围绕“记录开销、判断预算、统计总额”展开，按概念依赖分为 13 章：课程导学、第一个程序、变量与数据类型、运算符与输入输出、条件判断、循环、列表、字符串、字典元组与集合、函数、模块与文件、异常处理、综合回顾。11 道原创课堂练习，朗读题目以后保留完整四秒，再解释答案。

目标时长一小时，允许 50～70 分钟，实测时长见交付目录。示例采用 Python 3 的常见语法，兼容 3.11 及以后版本；制作机器实际以 Python 3.11.6 验证。新安装请从官方网站选择当前受支持的 Python 3，无需特意安装制作机器的旧补丁版本。

本课先学会解释和改写小程序，不在一小时内展开类与对象、装饰器、生成器、异步、第三方框架或复杂工程配置。正常程序、刻意保留的语法错误与运行时异常分别检查；文件例子同时检查实际文件内容。

## 先运行一个例子

从 [Python 官方下载页](https://www.python.org/downloads/) 安装适合系统的 Python 3，按 [练习指南](练习指南.md) 完成首次运行。进入某个示例目录，执行：

```powershell
python --version
python main.py
```

部分 Windows 环境使用 `py main.py`，macOS/Linux 通常使用 `python3 main.py`。若不确定命令指向哪个版本，先检查版本输出。屏幕代码没有交互模式的 `>>>` 提示符，文件里不要抄这些提示符。

需要键盘输入的程序见各目录的 `预期行为.json`。`01-q` 故意缺少右括号，预期语法检查失败；`06-q` 故意访问列表不存在的位置，预期发生 IndexError。错误例子并非可直接完成任务的正确写法。

## 工程结构

| 路径 | 作用 |
|---|---|
| `content/chapters_a.py` ～ `chapters_d.py` | 讲稿、屏幕代码、完整脚本、输入输出与题目 |
| `public/course.json` | 课程清单，从上述内容生成 |
| `src/video.tsx` | 代码、运行结果、要点及高亮动画 |
| `src/diagrams.tsx` | 容器、数据变化、执行路线与文件关系图 |
| `scripts/verify_examples.py` | 分开运行完整程序，核对输出、异常和文件 |
| `scripts/property_checks.py` | 检查边界与数据关系的额外案例 |
| `scripts/voice.py`、`audio.py` | 百炼配音，按文本和音色缓存 |
| `scripts/prepare_audio.py` | 声学对齐后在句号处额外插入 0.1 秒 |
| `scripts/timeline.py` | 依照实际音频长度建立时间轴 |
| `scripts/stills.mjs`、`render.py` | 分镜渲染、分章编码、合并与章节标记 |
| `scripts/check.py`、`final_frames.py` | 媒体检查与实际成片关键帧 |

可编辑压缩包包含本课原始配音、处理后的配音与对齐缓存。复用现有旁白重新渲染不需要语音账号；修改旁白才需要重新调用语音服务。包内没有原作者的 API Key、Workspace ID、依赖目录、解释器或渲染图片缓存。

## 重新制作

视频制作建议使用 Node.js 22、Python 3.11 和 FFmpeg，与本工程验证过的环境保持一致。学生运行学习示例可以使用受支持的 Python 3.11 及以后版本；这不代表所有较新解释器版本都已经验证过音视频制作依赖。首次语音对齐使用本地 Whisper base 模型；已有的对齐结果和音频可以复用。

```powershell
npm ci
python -m pip install -r requirements.txt
python scripts/build_course.py
python scripts/verify_examples.py
python scripts/property_checks.py
python scripts/prepare_audio.py
python scripts/timeline.py
npx tsc --noEmit
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/final_frames.py
python scripts/package.py
```

先查看每页完整状态、所有题目的倒计时与答案，并检查 90 秒内部试片，再完成全片。分镜有缓存，失败以后重试可以继续；修改画面、课程或时间轴会更新缓存版本。`npm run studio` 可打开编辑预览。交付写入工程同级的 `交付/Python一小时`。

若修改旁白，将 `.env.example` 列出的两个变量设置在自己的进程环境中，然后运行 `python scripts/voice.py --from-env`。示例文件不会自动读取 .env，不能直接把占位名称当成真实配置。实际凭据不要写入源文件或提交仓库。

## 画面与时间处理

代码字号 34px，每页主要代码不超过 12 行。结果在代码下方，常规字号 32px，四行结果使用 30px。右侧要点为 27px，并用关系图逐步显示关键变化。底部没有字幕，也没有字幕流。

使用北京地域百炼 `qwen-audio-3.0-tts-plus`、`longanlufeng` 男声，保持全课一致语速。在实际语音的句号位置增加 0.1 秒静音，不额外改变逗号停顿。按样本长度切换分镜，避免声音尚未结束就换到下一页。

成片为 H.264/AAC。动画在 30fps 时间网格上设计，高亮过渡使用 0.1 秒状态，静态讲解画面用可变帧率保持，减少反复编码同一张图。章节音频采样精确拼接，视频内嵌章节标记。

## 阿里云百炼账号与免费额度申请教程

### 一、开通账号与百炼服务

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，注册或登录自己的账号，并按要求完成实名认证。
2. 阅读并同意服务协议，开通百炼，地域选择 **华北2（北京）**。
3. 本项目使用普通百炼模型 API，不需要购买 Token Plan、服务器或创建智能体应用。账号开通不代表语音调用一直免费。参见 [官方开通说明](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)。

### 二、创建 API Key

在首页“常用功能 → API Key”创建密钥：地域北京，归属自己的主账号，业务空间选择默认空间或专用空间。若设置自定义模型权限，应包含将要调用的语音模型。需要的是百炼 API Key，不是阿里云 AccessKey，也不是旧版语音服务 Access Token。存入自己的密码管理器，勿公开或提交仓库。参见 [官方密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key/)。

### 三、获取 Workspace ID

进入“业务空间”，复制 **该 API Key 所属空间**的 Workspace ID。不能使用另一个空间，也不能以账号 UID 或 APP ID 代替。参见 [官方获取说明](https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id)。

### 四、确认语音模型

在模型目录查找完整名称 `qwen-audio-3.0-tts-plus`；本工程实际验证使用这个模型。`qwen-audio-3.0-tts-flash` 是可另行调查的语音模型，本工程不声明已验证它能直接替换。核对地域、调用说明、账号权限及价格。如果页面要求额外开通，按模型页面办理；子空间还需获得模型权限。不要误选名称相近的语音识别或实时对话模型。参见 [官方语音模型与声音说明](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)。

### 五、首次调用前检查免费额度和费用保护

1. 在控制台的“免费额度”查询**具体模型**的剩余额度和有效期。
2. 如果模型提供“免费额度用完即停”，建议开启。
3. 如果没有额度、已过期或没有对应开关，先确认当前价格及是否接受付费，再调用。

免费额度因账号、模型和活动规则而异，不保证每个账号都有。支持的模型在开启“用完即停”后额度耗尽会停止服务。以 [官方额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota) 和自己控制台为准。
