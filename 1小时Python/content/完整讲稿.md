## 变量与数据类型 · Variables and Types

### python-02-1 给数据起一个好认的名字

假设今天的预算是三十元，可以写 budget 等于三十。budget 是我们起的名字，等号右边是要保存的值。以后显示 budget，就能读到它当前对应的三十。下一行把 budget 改成四十，后面读到的就是四十。这里一个等号表示赋值，也就是把右边得到的值交给左边这个名字。它不是数学里永远不能变化的一条等式，程序会按语句顺序继续更新。变量名尽量让人看出用途，比如 budget 表示预算，spent 表示已花金额。Python区分大小写，名字也不能以数字开头。先保存，再读取；没有准备过的名字，计算机不会替我们猜一个数。每次看到赋值，都问一下：这一行之后，哪个名字对应的值变了？

```python
budget = 30
print(budget)
budget = 40
print(budget)
```

运行或错误检查结果：
```text
30
40
```

画面要点：= 把右边的值交给左边的名字；按执行顺序看当前值；名字区分大小写，先保存再读取

### python-02-2 整数、小数、文字与真假

数据也分种类。没有小数部分的数量，例如三十，可以先用整数 int。八点五这样的金额例子是小数，常见类型叫 float。文字是字符串 str，可以表示一个词，也可以表示一句话。还有 bool，用 True 和 False 表示真和假，注意首字母大写。以后判断“有没有超出预算”，得到的就是这种真假结果，而不是另一笔金额。Python通常根据我们交给它的值确定当前数据的类型，不需要每次在变量名前面都声明类型。这不意味着所有类型能做相同的事情：两个数字可以相加，文字也有自己的连接方式。接下来会专门比较数字十二和文字十二，先把“屏幕看起来相似”与“程序里是什么种类”分开。

```python
budget = 30
price = 8.5
item = "tea"
over_budget = False
print(budget, price)
print(item, over_budget)
```

运行或错误检查结果：
```text
30 8.5
tea False
```

画面要点：int 整数；float 小数；str 文字；bool 真或假；True、False 的首字母大写

### python-02-3 数字十二和文字十二

画面中第一组是数字十二和数字八，相加得到二十。第二组都加了引号，成为文字十二和文字八，再用加号连接，就得到一段文字一二八。不要因为显示出来都是数字形状，就以为它们一定能按同一种方式计算。字符串里的内容可以是姓名，也可以是看起来像数字的字符。有没有引号，是观察当前代码的一条线索。print 一次显示多个值时，可以用逗号隔开，默认会在它们中间放一个空格，在最后换行。这里的逗号是给显示工具交入多个内容，不会把数字自动连接成一个大数。后面读取键盘输入时，这个类型差别尤其重要：读到的通常先是文字，需要计算时再做合适的转换。

```python
print(12 + 8)
print("12" + "8")
print("spent", 20)
```

运行或错误检查结果：
```text

```

画面要点：数字相加与文字连接不同；引号内的数字仍然是文字；print 多项内容默认用空格分隔

### python-02-4 先算右边，再更新左边

已经花了十二元，又花八元，可以写 spent 等于 spent 加八。先读取 spent 原来的十二，算出二十，再把新值交回 spent。也可以把这个更新简写成加等于八。不要从等号左边开始猜测，看到同一个名字出现两次就觉得矛盾。程序的步骤很明确：右边先计算，左边再接收结果。下一次读取这个名字，就使用新的值。名字可以重新对应另一种类型的值，但为了让初学程序容易读，本课尽量让同一个名字一直表示同一类东西。不要今天用 spent 表示金额，下一行又拿它保存姓名。能写和适合写，是两件事；用清楚的名字和小步骤，后面排查问题会轻松很多。

```python
spent = 12
spent = spent + 8
print(spent)
spent += 5
print(spent)
```

运行或错误检查结果：
```text
20
25
```

画面要点：先读取旧值，再计算新值；+= 是这里的更新简写；让名字始终表达清楚的含义

### python-02-q 课堂练习：改一个名字会怎样

a 先得到十二，b 再得到 a 当时对应的整数。接着把 a 改成二十，最后一起显示 a 和 b，会得到二十和二十，还是二十和十二？请按先后顺序跟踪，不要只看最后出现的那个数字。b 等于 a 这一行执行时，a 还没有被重新赋值。给你四秒，分别写出最后两个名字对应的值。这一题只讨论整数以及重新赋值，后面学列表时，我们还会专门观察“修改数据里面的一项”和“给名字另一个值”有什么不同，先别把两种操作混在一起。

（朗读结束后，四秒独立思考）

```python
a = 12
b = a
a = 20
print(a, b)
```

运行或错误检查结果：
```text
20 12
```

画面要点：b 得到的是当时的整数 12；随后只给 a 重新赋值；分别跟踪两个名字

### python-02-a 答案：b 仍然对应原来的十二

结果是二十和十二。执行 b 等于 a 时，a 对应十二，b 也就对应这个整数。后来给 a 另一个整数二十，没有再次给 b 赋值，所以 b 仍然是十二。这里不要把 b 理解成一条会不断重新计算 a 的公式，也不要认为两个名字出现过赋值关系，以后就一定自动同步。要看后面到底执行了什么操作。当前只需要记住这个执行顺序。下一章我们把变量拿来计算余额，接收键盘输入，再显示带有说明的结果。名字的作用不是增加要背的英文，而是让程序中的数据能被反复使用，让每一步的意思更容易看清楚。

```python
a = 12
b = a
a = 20
print(a, b)
```

运行或错误检查结果：

画面要点：最后 a 是 20，b 是 12；重新赋值只改变这次使用的名字；不要把赋值当成持续计算的公式

## 运算符与输入输出 · Operators and Input Output

### python-03-1 用表达式完成一笔计算

一杯饮料十二元，买两杯。把 price 乘 count 算出来，得到二十四，再交给 total。星号表示乘法，加减乘除分别使用加号、减号、星号和斜杠。把数据和运算符组合起来、能够算出结果的写法，叫表达式。这个名字不用神秘化，price 乘 count 就是一个例子。通常先乘除，再加减；括号可以明确要求先计算哪一部分。预算三十减去总额二十四，得到余额六。程序的价值，就是把已经保存的数据按规则连接起来。初学时不要故意把所有运算挤进一长行，先给中间结果起清楚的名字。这样发现结果不对，就能逐步检查单价、数量、总额和余额，知道问题从哪一步开始。

```python
price = 12
count = 2
total = price * count
remaining = 30 - total
print(total, remaining)
print((2 + 3) * 4)
```

运行或错误检查结果：
```text
24 6
20
```

画面要点：* 表示乘法，括号决定先算什么；先保存中间结果，方便核对；30 - 24 得到余额 6

### python-03-2 除法、整除与余数

七个东西平均分成两份，普通斜杠除法得到三点五。如果只想知道每份先能分到几个整件，可以使用两个斜杠，七整除二得到三，百分号则给出余数一。准确地说，双斜杠是向下取整，不是对所有数字都简单删去小数。看负七整除二，结果是负四，因为要向更小的整数靠。先把这组区别认识清楚，避免以后遇到负数时用错规则。两个星号表示乘方，二的三次方得到八。不是每一段程序都会用到所有运算符，现在先通过明确的小例子观察结果。遇到计算问题，先看运算符本身的含义，再看数据类型和括号，别只凭日常口语里的“除一下”来猜。

```python
print(7 / 2)
print(7 // 2, 7 % 2)
print(-7 // 2)
print(2 ** 3)
```

运行或错误检查结果：
```text
3.5
3 1
-4
8
```

画面要点：/ 普通除法；// 向下取整；% 取得余数，** 表示乘方；负数的整除也向更小的整数靠

### python-03-3 从键盘读取一行文字

现在让使用程序的人输入，而不是把所有内容事先写死。input 会等待一行输入，使用者输入内容并回车以后，它把这一行作为字符串交回来。本页输入 Ana，保存进 name，再用 print 显示 Hello 和这个姓名。输入时只需要键入 Ana，不需要抄 name 等于，也不需要自己加上代码里的引号。这里 input 的括号里没有提示文字，是为了让下方运行结果只包含程序真正显示的内容。实际项目可以在括号里写提示，比如请输入姓名，那段提示也会出现在屏幕上。程序停在输入位置时没有继续向下显示，常常是在等你输入回车，并不一定是程序已经坏了。先分清自己应该交入什么数据，再看程序会怎样处理。

```python
name = input()
print("Hello", name)
```

运行或错误检查结果：
```text
Hello Ana
```

画面要点：本页输入：Ana，然后回车；input() 读到一行字符串；输入内容，不用抄变量声明

### python-03-4 把数字文字转换成整数

如果这次需要输入一笔整数开销，input 读到的十二，仍然先是一段文字。用 int 把合适的数字文字转换成整数，再加八，才能得到数值二十。所以这里分成两行：text 保存原始输入，spent 保存转换后的整数。这样你能看见类型变化发生在哪里，也更容易找到失败的那一步。int 不是把任何文字都变成一个合理数字的魔法。abc 不能转换成整数，会报告错误；十二点五这样的文字也不是这里接受的整数写法。如果需要小数，可以考虑 float。本页的测试输入明确是十二，先让正常路线运行起来，最后的异常处理一章会教你怎样处理不合适的输入。

```python
text = input()
spent = int(text)
print(spent + 8)
```

运行或错误检查结果：
```text
20
```

画面要点：本页输入：12，然后回车；先读文字，再用 int 转换；输入必须符合整数写法

### python-03-5 把计算结果写进一句提示

显示结果时，只给一个二十，有时看不出它表示什么。我们可以用带 f 的字符串，把变量放进一对大括号中，得到一段带说明的文字。spent 是二十，就显示 spent 等于二十。这叫格式化字符串。现在先把它理解成一句有空位的说明，大括号里的表达式会先求出值，再填到对应位置。数字不必为了连接文字而手动写一长串转换。第二行把预算减去开销的结果放进大括号，显示 remaining 等于十。你也可以像上一页那样先把余额交给单独的变量，再填进文字。两种写法都可以，优先选自己能解释清楚的形式。不要把 f 漏掉，否则大括号里面的名字就可能只被当成普通文字显示出来。

```python
budget = 30
spent = 20
print(f"spent={spent}")
print(f"remaining={budget - spent}")
```

运行或错误检查结果：
```text
spent=20
remaining=10
```

画面要点：字符串前面加 f；{变量或表达式} 填入计算结果；用说明文字让结果更容易理解

### python-03-q 课堂练习：输入以后先看类型

### python-03-a 答案：文字连接与数值相加

## 条件判断 · Conditional Statements

### python-04-1 把一个问题算成真或假

现在问一个具体问题：预算三十元，已经花二十五，是否超出预算？spent 大于 budget 的结果是 False，表示这个判断不成立。两个等号比较是否相等，得到的也是真假结果；一个等号才是前面学习的赋值。小于、大于、小于等于、大于等于和不等于，都能帮助我们描述条件。本页第三行要求开销不小于零，并且不大于预算，两个要求之间用 and 连接，表示同时满足。or 表示至少满足其中一个条件，not 可以把真假反过来。先把每个小判断本身看懂，再组合，避免把一串符号当成一句含糊的中文去猜。这里得到的 True 或 False，下一页就会直接决定程序执行哪一组操作。条件不是装饰，它必须回答一个明确的问题。

```python
spent = 25
budget = 30
print(spent > budget)
print(spent == budget)
print(spent >= 0 and spent <= budget)
```

```text
False
True
```

画面要点：比较得到 True 或 False；== 比较相等，= 用于赋值；and 同时满足，or 至少满足一个

### python-04-2 用缩进标明两条执行路线

### python-04-3 多种情况按顺序检查

如果输入负五元，我们可能想先提示金额不合适，再考虑有没有超预算。可以用 if、elif、else 列出三种情况。先看 spent 是否小于零，是就显示 invalid。不是负数，才继续看是否不大于预算，是就显示 within。前面都没有选中，最后才显示 over。elif 可以理解成“前面没有成立，再判断这个条件”。这组分支一旦选中一块，就不会继续把其他块也执行一遍。判断顺序因此很重要：先把不合适的负数处理掉，再比较预算范围。初学时可以拿几组具体数来走路线，比如负五、二十五、三十和三十五。不要只测试一个正常数，就觉得所有边界都已经写对。

## 循环结构 · Loops

### python-05-1 让同一步骤重复执行

如果要依次显示一、二、三，不一定要写三次 print。for 可以从一组数据中依次取出值，每次交给变量 number，再执行下面缩进的操作。range 括号一、四，产生从一开始、到四之前的整数，四本身不包含。所以三次执行中，number 依次是一、二、三。for 后面的 in 可以先理解成“从这里依次取值”。和 if 一样，for 这一行末尾也有冒号，下面通过缩进表示每次要重复的步骤。看循环时，先找数据来自哪里，再找本次取到什么，最后找重复范围在哪里结束。不要把 range 的第二个数当成一定会被处理的最后一个值，这正是初学时最常见的差一问题。

```python
for number in range(1, 4):
    print(number)
```

运行或错误检查结果：
```text
1
2
3
```

画面要点：range(1, 4) 包含 1，不包含 4；number 依次取到 1、2、3；缩进范围内的操作重复执行

### python-05-2 把每次结果累加起来

显示数字只是观察循环的第一步。现在准备 total 为零，每次把当前 number 加进来。第一次加一，total 变成一；第二次加二，变成三；第三次加三，变成六。最后的 print 退回循环外面，表示全部累加结束以后只显示一次总和。要是把它也缩进到循环里，就会显示每一步的中间结果，而不是只显示最后一个六。还要看清 total 等于零的位置。它写在循环之前，只准备一次。如果错误地放进重复范围，每次都从零重新开始，就不能保留前面已经加好的结果。一个变量在哪里准备、在哪里更新、在哪里读取，往往比循环那一行的英文更值得仔细跟踪。

```python
total = 0
for number in range(1, 4):
    total += number
print(total)
```

运行或错误检查结果：
```text
6
```

画面要点：total 在循环前只准备一次；每轮把当前 number 加入总和；循环外显示最后的结果

### python-05-3 条件满足时继续重复

for 适合从数据或范围里依次取值。while 则是每次先检查条件，条件仍然为真，就再执行一轮。本页 remaining 从三开始。先判断大于零，显示三，再减一。接下来显示二、一，减到零以后，条件变成 False，循环结束。这里减一使用减等于一，和前面加等于的更新思路相同。一定要问：什么变化能让条件最终不再成立？如果忘了减少 remaining，它会一直保持三，条件也就一直为真，程序可能不断重复下去。遇到这种情况，可以在终端中按 Control 加 C 停止。我们不是为了凑一个循环而写 while，而是要明确重复什么、为什么继续、何时结束。

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
```

运行或错误检查结果：
```text
3
2
1
```

画面要点：while 每次先判断条件；显示以后 remaining 减少 1；变为 0 后条件不成立，结束

### python-05-4 满足条件时提前结束循环

有些任务不必把整个范围都处理完。break 可以结束当前这一层循环。代码依次取一到五，遇到四时就执行 break，所以只有一、二、三被显示。请看位置：判断四并执行 break，写在 print 之前。因此四这一轮已经开始取值，但后面的显示还没做，就离开循环了。不能因为 range 里包含四，就认为四一定出现在运行结果里。如果把条件或显示语句的位置移动，结果也可能改变。读循环不能只看最外面那一行，要沿着每一轮内部实际发生的操作往下走。以后在查找一个目标、找到就停止时，这种提前结束的方式很常见。多层循环的情况可以以后再学，先把这一层的路线看清楚。

```python
for number in range(1, 6):
    if number == 4:
        break
    print(number)
```

运行或错误检查结果：
```text
1
2
3
```

画面要点：遇到 4 时，在显示之前 break；break 结束当前这一层循环；所以只显示 1、2、3

### python-05-5 跳过本轮的一部分操作

continue 和 break 不一样。它跳过当前这一轮后面还没执行的部分，然后继续下一轮。画面中遇到三就执行 continue，所以三没有显示，后面四和五仍然会显示。这一次结果是一、二、四、五。可以把两种动作分别说清楚：break 是结束当前循环，continue 是这轮到这里就先停，接着准备下一轮。特别是在 while 里，如果跳过了让条件变化的更新，就可能造成意料之外的不断重复。所以写 continue 时，要检查被跳过的是哪些语句，不要只把它背成一个“省略某个数”的工具。本页用 for 和明确范围练习，就是为了让每一轮从哪里来、下一轮是什么都能看见。

```python
for number in range(1, 6):
    if number == 3:
        continue
    print(number)
```

运行或错误检查结果：
```text
1
2
4
5
```

画面要点：continue 跳过本轮剩余部分；下一轮仍然继续；本例跳过 3，随后显示 4、5

## 列表 · Lists

### python-06-1 把几笔开销放在一起

### python-06-3 读取一段连续的数据

### python-06-4 让循环逐项读取列表

前面的 for 从 range 依次取整数，现在直接从列表依次取开销。每一轮 amount 得到一笔金额，再把它加进 total。十二、八、五加起来，最后得到二十五。这个循环不必先自己计算位置编号，因为当前任务只需要每项的值。以后需要位置时，再学习相应的写法，先用最直接的方式完成眼前任务。理解了每轮累加的过程以后，也可以使用已经准备好的 sum，直接计算这些数的总和。本页两次显示都是二十五：第一次帮助我们看清循环怎样工作，第二次认识一个常用工具。工具能让代码简短，但你仍然要清楚它接收的是什么数据、返回的是什么结果，不能只靠某个名字看起来像在求和就盲目使用。

```python
expenses = [12, 8, 5]
```

### python-06-5 两个名字可能使用同一份列表

现在回到变量那章留下的问题。b 等于 a，并没有建立一份新列表。a 和 b 都使用同一份列表，通过 b 追加八，再显示 a，也能看到十二和八。这和先前给整数变量重新赋值的操作不同。那次是让一个名字对应另一个整数；这次是在修改一份列表内部的内容。请把“名字对应谁”和“数据里面有什么”分开画。如果希望得到独立的一层列表，可以使用 copy，再对新列表追加五，原列表就保持十二和八。这个例子每项都是整数，所以这样足够；以后列表里还套着列表时，需要再学习更深一层的复制关系。现在先把共享同一份、和另外建立一份的区别弄清，不要把赋值一概当成完整复制。

```python
a = [12]
```

### python-09-3 为常用参数准备默认值

## 异常处理 · Exceptions

### python-11-1 输入不合适时给出清楚提示

回到键盘输入。如果使用者交入 abc，int 无法把它转换成整数，会报告 ValueError。把可能失败的操作放在 try 的缩进范围，用 except 指定处理这种异常，就能显示自己的提示。转换失败以后，try 里剩下的显示不会继续执行，而是跳到对应的 except，显示 not an integer。处理结束后，再继续执行结构外面的 done。如果输入十二，转换成功，显示十二，不进入这段异常处理。不要因为学会 except，就把所有代码都塞进去，或者捕获以后什么也不解释。先知道哪一步可能失败，具体是什么问题，应该怎样回应。本页只处理数字转换失败，其他不相关的问题仍应让我们看见，便于找到真正原因。

```python
text = input()
try:
    amount = int(text)
    print(amount)
except ValueError:
    print("not an integer")
print("done")
```

运行或错误检查结果：
```text
not an integer
done
```

画面要点：本页输入：abc，转换失败；try 尝试操作，except 处理指定异常；处理后继续执行外面的 done

### python-11-2 按约定拒绝不合适的数据

有时输入虽然能转换成整数，却不符合程序自己的规则。例如当前这个记录普通支出的函数，规定金额不能为负。require_amount 检查到负数，就用 raise 主动报告 ValueError，并说明 negative amount。完整程序在调用处交入负五，再用 except 取得错误对象，把里面的提示显示出来。换成正数，就会正常返回金额。报告异常之后，不会再继续走这次函数里后面的正常返回。不是每个判断都必须用异常。比较有没有超预算，用 if 就能表达；当一个函数不能按约定完成任务时，再清楚报告失败，让调用处决定怎样处理。先把正常返回和失败处理这两条路线分清，比盲目记住很多错误名称更重要。

```python
def require_amount(amount):
    if amount < 0:
        raise ValueError("negative amount")
    return amount
```

画面要点：本例规定普通支出金额不能为负；raise 主动报告不能按约定完成；调用处 except 后显示错误提示
