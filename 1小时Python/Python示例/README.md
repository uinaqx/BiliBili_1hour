# Python 课程完整示例

这里提供课程全部 64 组示例，下载仓库后即可打开和运行，无需安装视频制作工具或配置语音账号。

## 开始跟练

1. 安装 Python 3。
2. 打开某个例子文件夹，例如 `01-1`，在该文件夹打开终端。
3. 执行 `python main.py`。Windows 也可用 `py main.py`，macOS/Linux 通常用 `python3 main.py`。
4. 对照同目录 `预期行为.json` 中的输入、输出或预期错误。

每个例子单独保存为 main.py；请进入对应目录运行。`q` 是课堂题目，`a` 是答案或修正版。部分题目刻意保留语法错误或运行时异常，供判断和纠错。

模块示例 [10-2](10-2/) 包含 `main.py` 和 `budget_tools.py`，请保留在同一个文件夹。文件读写示例包含所需初始数据；反复运行追加示例前，请先按 `预期行为.json` 的 `fixtures` 恢复初始文件内容。
