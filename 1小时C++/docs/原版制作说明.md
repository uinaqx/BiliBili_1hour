# 一小时学习 C++：基础与面向对象

面向认识 C 语言基础语法、第一次系统学习 C++ 类与对象的学生。先用函数和引用衔接，再逐步学习类、构造与析构、封装与共享、组合、继承、多继承、重载、多态和异常处理。12 章、65 个分镜、10 道原创课堂练习。讲稿采用教师逐步解释的口吻，完整示例可以独立编译。

## 视觉与声音

沿用 Rust 第二讲：1920×1080 深色画面，左侧 34px 代码，代码下方 32px 运行结果，右侧中文要点和二维关系图。四行输出使用 30px。主标题使用正规章节名，每屏主要代码最多 12 行。代码节选提供完整 `main.cpp`。

**本部成片无字幕**，保留代码、运行结果、中文图示和旁白。底部字幕区留空，工程不生成 SRT，也不烧录字幕。使用阿里云百炼北京区域 `qwen-audio-3.0-tts-plus`、系统男声 `longanlufeng`，无背景音乐。句号之间额外增加 0.1 秒，逗号不额外增加。每题朗读完成后保留完整 4 秒思考，再进入答案。

全课保持统一语速，实际时长和设置见 `build/audio-settings.json`。为准确定位增加停顿的位置，内部使用已知讲稿与实际音频的声音对齐；这不表示成片包含字幕。视频以 30fps 时间刻度组织，H.264/AAC 编码，带章节标记。静止画面采用可变帧率保存，播放器报告的平均帧率可能低于 30。

## 运行一个例子

本次制作使用 Windows、MinGW G++ 6.3.0、C++14。也可用支持 C++14 的较新 GCC 或 Clang。进入某个普通示例的目录后执行：

```powershell
g++ -std=c++14 -Wall -Wextra main.cpp -o example.exe
.\example.exe
```

`01-1` 需要输入整数，例如 `80`。其中输入 `x` 的失败路径预期返回 1。标成 `compile_error` 的目录是错误示例，应对照后续修正版本学习。

## 重制视频

需要 Node.js、Python、FFmpeg/ffprobe、C++14 编译器，以及 Microsoft YaHei/Cascadia Code 字体。更换系统时调整字体和可执行文件名称。

```powershell
npm ci --ignore-scripts
python -m pip install -r requirements.txt
python scripts/build_course.py
python scripts/verify_examples.py
python scripts/property_checks.py
# 工程包已带本课配音，无需再次调用在线服务。
python scripts/prepare_audio.py
python scripts/timeline.py
npx tsc --noEmit
npm run studio
node scripts/stills.mjs --qa
python scripts/qa_sheets.py
node scripts/stills.mjs
python scripts/render.py --preview
python scripts/render.py
python scripts/check.py
python scripts/final_frames.py
python scripts/package.py
```

Whisper base 首次使用需要下载模型。原始声音在 `public/audio_original/`，处理后的 WAV 在 `public/audio/`。工程包保留这些音频和对齐缓存，便于离线修改画面。画面与分章编码采用内容缓存，失败后重新执行可继续。时间轴、画面源改变后应重新生成并检查。

修改旁白时，使用自己的百炼凭据，通过进程环境变量传入：

```powershell
$env:DASHSCOPE_API_KEY = '<自己的百炼 API Key>'
$env:SFM_WORKSPACE_ID = '<同一业务空间的 Workspace ID>'
python scripts/voice.py --from-env --test
python scripts/voice.py --from-env --workers 3
```

脚本也支持标准输入接收凭据，真实值不会写入缓存。`.env.example` 只展示变量名，不自动加载。工程包不含原作者 API Key 或 Workspace ID。

## 教学依据与范围

内容和习题为原创。对象初始化顺序依据 [C++ 工作草案 class.base.init](https://www.eel.is/c%2B%2Bdraft/class.base.init)，继承与对象关系依据 [class.derived](https://www.eel.is/c%2B%2Bdraft/class.derived)，接口表达参考 [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/)。示例仅采用 C++14 支持的基础语法，不把较新草案的新增语法混入代码。

重点区分同名隐藏与虚函数覆盖、引用与对象切片、构造初始化与函数体赋值、按值与按引用接收。析构和多继承只作必要介绍，不展开虚继承、模板、容器、复杂资源管理或高级异常安全。
