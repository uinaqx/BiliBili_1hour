# C++ 初学者练习路线

先运行资料中的完整程序，再一次只改一处，并写下预期结果。不要把编译失败当作有一个尚未打印出的答案：先解决语法、访问权限与类型规则。

1. 引用：把 `r = b` 前后的 a、b、r 分别记录下来，检查 r 是否始终对应 a。
2. 类：创建两个成绩对象，只修改其中一个，观察另一个的状态。
3. 构造：分别传入 0、60、80，再尝试不传参数，检查类是否提供对应入口。
4. 封装：把只读对象传给 const 查询函数；尝试调用修改函数，阅读编译器拒绝的位置。
5. 组合与继承：在构造函数、析构函数打印不同标签，按基类列表和成员声明判断顺序。
6. 重载：分别传入整数和小数，预测选中的函数；只改返回类型，观察为何不能区分。
7. 多态：保留 Base 引用与独立 Base 值对象两条路线，比较虚函数输出。
8. 异常：分别输入正常参数与零除数，在每一条输出旁边标明是否执行。

综合练习：为 Score 增加检查分数范围的 set 函数；用 Student 组合两份成绩；给显示操作增加一个抽象接口。每一步先保证能够编译，再解释新增规则。

本课默认已认识 C 的变量、条件、循环、数组和普通函数。如果读代码仍常卡在这些位置，先单独运行相关的小片段，再继续类与继承。
