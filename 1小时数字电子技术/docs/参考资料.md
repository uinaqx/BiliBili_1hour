# 数字电子技术参考资料与模型约定

课程按常见大学数字电子技术基础组织，例题、讲稿与动画为本项目原创。不同学校大纲涉及的具体芯片、化简方式与设计深度可能不同。

## 一、逻辑器件、存储与时序

- [Toshiba CMOS Logic IC Basics](https://toshiba.semicon-storage.com/eu/semiconductor/knowledge/e-learning/cmos-logic-basics/chap3/chap3-1.html)：逻辑电路的基础与分类；从组合功能进入带状态的时序功能。
- [Toshiba Flip-flops and latches](https://toshiba.semicon-storage.com/us/semiconductor/knowledge/e-learning/cmos-logic-basics/chap3/chap3-3-2.html)：锁存器的电平控制、触发器的边沿控制以及存储状态的区别。
- [Georgia Tech ECE2020 Sequential Timing](https://ece2020.ece.gatech.edu/new/topics/sequentialtiming.php)：同步寄存器之间的时序路径、建立保持与时钟周期约束。
- [TI Logic Guide / SDYA002](https://www.ti.com/lit/an/sdya002/sdya002.pdf)：逻辑系列、接口、电平、驱动与延迟相关术语，可继续查具体器件的数据手册。

公式中的加号表示逻辑或，相邻字母表示逻辑与，横线表示取反。卡诺图变量顺序为ABC，A是高位；BC列为00、01、11、10。SR锁存器限定为交叉耦合或非门、高有效输入；11是禁止组合。换成与非型或低有效输入时，不能沿用该表。

时序预算例题明确忽略时钟偏斜与额外裕量：T≥2ns+5ns+1ns=8ns，对应理想频率上限125MHz。真实设计还须单独检查保持时间、复位释放、跨时钟域、电气和实际器件条件。本课没有进行硬件上板、综合时序收敛或电气测量。

## 二、数模转换与量化

- [Analog Devices Electronics Text, Chapter 20](https://wiki.analog.com/university/courses/electronics/text/chapter-20)：数模、模数转换以及数字码、分辨率与输出关系。
- [Analog Devices MT-001](https://www.analog.com/media/en/training-seminars/tutorials/mt-001.pdf)：理想量化误差与量化模型；误差区间须连同量化规则理解。
- [Microchip ADC Output Codes](https://onlinedocs.microchip.com/oxy/GUID-DE09DA5A-1CBB-49A8-9DA0-B2EB94E57E56-en-US-11/GUID-AF39A4C5-EBA9-41FF-A19A-7C408CEED389.html)：具体器件文档中的输出码约定。不同端点、量程和转换模式应按具体资料处理。

本课DAC题使用明确给定的理想单极性关系Vout=Vref·D/2ⁿ。n=3、Vref=8V时，步长为1V，最大码111输出7V，不能自动改为8V。

ADC题使用**向下分箱的教学模型**：0≤Vin<8V，每一伏一个左闭右开区间。[5,6)V输出101，按区间下端重建时Vin−Vreconstructed∈[0,1)V。此处不是四舍五入量化，不能直接套用±0.5LSB。输入8V及以上不在给定模型定义域内。真实ADC的码跳变与饱和端点应查器件资料。

## 三、动画和仿真的证据边界

`scripts/diagrams.py`中的门限、毛刺、脉动计数、建立保持、施密特和脉冲波形，均为明确标注的教学示意。时间宽度及电压位置不代表真实器件参数。

D锁存器与D触发器使用Icarus Verilog实际仿真生成的VCD。完整记录在`build/simulation-data.json`与`build/sim/`；D触发器画面截取10～40ns，5ns已同步复位，15、25、35ns为三个正常上升采样边沿。RTL仿真没有包含物理器件的模拟延迟与亚稳行为。

工程附有23组正常RTL测试与3组预期失败，以及独立有限枚举和计算检查。只有锁存器、触发器两种实际VCD视图用于本课；其余RTL用于进一步动手验证，**不要求零基础学生先学习Verilog**。`latch_bad`是保留的源文件标识，在本课中作为有意构造的D锁存器展示，文件名并不表示锁存功能本身错误。

有限枚举检查覆盖本课明确给定的位宽、输入域和例子，不等于对所有物理实现与所有输入条件的证明。
