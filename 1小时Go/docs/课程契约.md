# Go 基础语法课程约定

- 面向零基础，以姓名与成绩为贯穿需求，先给具体例子再解释规则。
- 目标约一小时，本工程按实测配音控制在 55–65 分钟，优先 58–63 分钟。
- 十章覆盖程序结构、变量常量类型、运算符输入输出、分支循环、数组切片、映射字符串、函数延迟执行、指针结构体、方法接口、错误处理和文件实践。
- 1920×1080；30fps 时间网格上的事件驱动 VFR；H.264/AAC，包含实际章节标记。
- 首页全屏两列知识点总览。后续深蓝底，代码左侧，运行结果放代码下方并使用 30–32px 字号，右侧教学要点。
- 无底部字幕、无背景音乐。中文系统男声；百炼北京语音接口，qwen-audio-3.0-tts-plus / longanlufeng。
- 每章至少一道题，单独留四秒思考，答案下一页再出现。
- 每个讲解单元人工选择代码行组。依据最终音频的实测起音移动，持续到下一个单元，停顿与思考期不清除。
- 句号之间增加 0.1 秒，逗号不额外修改。先处理声音，再建立时间轴。
- 代码页不超过十二行主要代码，字号 34px；完整程序另存，可独立构建运行。
- 代码运行结果、故意的编译错误和运行时错误分别验证；文件示例只在独立测试目录执行。
- 交付包含 MP4、十章目录、完整讲稿、源码与答案、可编辑工程和验收说明。账号信息、原始服务缓存和私有辅助工具不入包。
- 公开版本按用户授权发布源码，账号信息及音视频不上传。
