### ca-01-04 等价替换：先整理乘除结构

1. 例题

$$\lim_{x\to0}\frac{\sin3x\,\ln(1+2x)}{x^2}$$

2. 分别识别完整小量

$$\sin3x\sim3x,\quad\ln(1+2x)\sim2x$$

3. 代入并约分

$$\lim_{x\to0}\frac{3x\cdot2x}{x^2}=6$$

4. 保留差的整体，不能先把指数项换成一

$$e^x-1\sim x$$

看第一道例题，分子是两个因子相乘，适合分别等价替换。正弦里面是三x，就替成三x；对数里面是一加二x，整个对数替成二x。不要看到三角函数就只写一个x，也不要把对数里面的系数二弄丢。两个内部小量都随x趋于零，条件满足。

持续高亮：[1, 2]；显示到第 2 行。

提示：把整个因子识别出来；内部系数必须保留

### ca-01-05 无穷小的比较：统一做比值

1. 条件

$$\alpha(x)\to0,\quad\beta(x)\to0$$

2. 高阶与等价

$$\frac{\alpha}{\beta}\to0:\ \alpha=o(\beta);\qquad\frac{\alpha}{\beta}\to1:\ \alpha\sim\beta$$

3. 同阶与低阶

比值趋于有限非零常数：同阶；比值绝对值趋于无穷：前者低阶

4. 例子

$$\frac{x^2}{x}\to0,\quad\frac{2x}{x}\to2,\quad\frac{\sin x}{x}\to1$$

比较两种无穷小，不要只凭名字或指数猜，最稳的统一办法是做前者除以后者的极限。比值为零，前者是后者的高阶无穷小，也就是更快靠近零；比值为一才叫等价。这里高阶不是数值更大，恰好是趋近零时相对更小，这个方向要记牢。

持续高亮：[1, 2]；显示到第 2 行。

提示：先确认两者都趋于零；比较顺序决定高阶或低阶

比值趋于有限非零常数叫同阶，常数不一定是一；比值绝对值趋于无穷，前者是低阶。例子中x平方除以x趋于零，所以x平方高阶；二x与x同阶但不等价；正弦x与x等价。如果比值振荡没有极限，不能硬塞进这些需要比值极限的分类。

持续高亮：[3, 4]；显示到第 4 行。

提示：同阶不一定等价；等价对应比值恰好趋于一

### ca-01-06 左右极限：分段题分别代入

1. 分段表达式

$$f(x)=x+1\ (x<0),\quad f(x)=2x+c\ (x>0)$$

2. 左边与右边

$$\lim_{x\to0^-}f(x)=1,\quad\lim_{x\to0^+}f(x)=c$$

3. 两侧一致才有双侧极限

$$1=c\quad\Longleftrightarrow\quad c=1$$

4. 点值可以不等于极限

$$f(0)=9,\quad\lim_{x\to0}f(x)=1$$

分段函数在分界点求极限，先判断从哪一边靠近。x从零左边来，用x加一，得到一；从右边来，用二x加c，得到c。不要因为题目在等号处规定了某个函数值，就把那个值同时拿来充当左右极限，附近表达式和点值是两件要分别检查的事。

持续高亮：[1, 2]；显示到第 2 行。

提示：左极限用左侧表达式；右极限用右侧表达式

双侧极限存在，要求左右极限都存在并且相等，所以这里c必须为一。即使把零处的函数值另设成九，只要左右表达式不变，极限仍然可以是一。下一章判断连续时，才要求这个极限再等于实际点值。分段题先写左右两行，通常就能清楚拿到参数条件。

持续高亮：[3, 4]；显示到第 4 行。

### ca-01-07 第二类重要极限：算指数乘小量

1. 通用模板

$$u\to0,\quad uv\to L,\quad1+u>0$$

2. 结论

$$(1+u)^v\to e^L$$

3. 例题

$$\lim_{x\to0}(1+2x)^{3/x}$$

4. 只算这个乘积

$$(2x)\frac{3}{x}=6\quad\Longrightarrow\quad e^6$$

第二类重要极限常出现底数趋于一、指数变得很大的形式。先把底数写成一加小量u，再算小量乘指数v的极限。如果这个乘积趋于有限数L，而且底数在附近为正，就得到e的L次方。不要只看到一的无穷次方就直接写e，指数最后还要经过这次计算。

## 连续与间断点

### ca-02-01 连续的三项检查

1. 连续要求

$$\lim_{x\to a}f(x)=f(a)$$

2. 先有定义，再比较左右极限与点值

$$\lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a)$$

3. 例题

$$f(x)=\frac{\sin x}{x}\ (x\ne0),\quad f(0)=k$$

4. 连续补点

$$\lim_{x\to0}\frac{\sin x}{x}=1\quad\Longrightarrow\quad k=1$$

连续定义在考试里可以拆成三项检查：点上有函数值，附近有有限的极限，而且这个极限等于点值。分段函数仍然先算左右，再检查与点值是否一致。若只证明左右极限相等，还没有证明函数一定连续，因为题目可能把点值故意填错，或者根本没定义点值。

持续高亮：[1, 2]；显示到第 2 行。

提示：有点值、有有限极限、两者相等；分段处先分别算左右

例题把非零时的函数设为正弦x除以x，零处填k。附近极限是一，所以要连续就取k等于一。这种题常叫补定义或求参数，作答直接写极限值，再令点值与它相等。闭区间端点的连续只检查从区间内部靠近的一侧，不必额外要求区间外也有表达式。

持续高亮：[3, 4]；显示到第 4 行。

提示：补点的值等于极限；区间端点检查相应单侧

### ca-02-02 间断点分类：先看两侧是否有限

1. 可去：有限极限相同，但点值不对或未定义

$$\lim_{x\to a^-}f=\lim_{x\to a^+}f=L\in\mathbb{R}$$

2. 跳跃间断

$$\lim_{x\to a^-}f=L_1,\quad\lim_{x\to a^+}f=L_2,\quad L_1\ne L_2$$

3. 第二类例子

$$\frac1x\ (x=0),\qquad\sin\frac1x\ (x=0)$$

4. 第一类间断点

可去间断点，或跳跃间断点

间断点分类先算左右极限。两侧都有限而且相等，只是没点值或点值不对，叫可去间断；两侧都有限但不相等，叫跳跃间断。这两种合称第一类。记忆时抓住“可去能补点、跳跃两边不同”，不要把任何没有定义的点都直接叫第二类。

持续高亮：[1, 2]；显示到第 2 行。

提示：可去：有限且左右相等；跳跃：有限但左右不同

如果至少一侧不能得到有限极限，就归入第二类。比如一除以x在零附近无界，是无穷间断；正弦一除以x不断振荡，是振荡间断。遇到含绝对值、分母为零或振荡项的题，先列可疑位置，再逐个算左右。分类依据是附近极限的表现，不是函数式看起来有多复杂。

持续高亮：[3, 4]；显示到第 4 行。

提示：可去与跳跃属于第一类；无穷或振荡属于第二类

### ca-02-03 闭区间连续：三类结论

1. 有界与最值

$$f\in C[a,b]\ \Longrightarrow\ m\le f(x)\le M$$

2. 介值性质

$$f(a)<k<f(b)\ \Longrightarrow\ \exists\xi\in(a,b):f(\xi)=k$$

3. 零点条件

$$f(a)f(b)<0\ \Longrightarrow\ \exists\xi\in(a,b):f(\xi)=0$$

4. 例题

$$f(x)=x^3+x-1,\quad f(0)=-1,\quad f(1)=1$$

题目出现闭区间连续，优先想到三组工具：一定有界且能取得最大最小值，能够取得端点值之间的中间值，以及端点异号时内部至少有一个零点。最值定理要求闭区间，若换成开区间，就不能不加检查地照搬。写定理题的过程，先交代连续范围，再写端点计算。

持续高亮：[1, 2, 3]；显示到第 3 行。

提示：先核对闭区间与连续；至少有一个不等于恰好一个

比如x立方加x减一，在零到一连续，两个端点分别为负一和一，因此中间至少有一个零点。到这里已经完成零点存在性的标准写法，不需要解出三次方程。若还问唯一性，可再证明导数三x平方加一恒正，从而严格递增；端点异号本身并不能保证唯一。

## 导数与复合函数求导

### ca-03-01 导数定义：看清增量除法

1. 定义

$$f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}h$$

2. 例题

$$f(x)=x^2,\quad a=1$$

3. 代入并展开

$$\frac{(1+h)^2-1}{h}=2+h$$

4. 取极限

$$f'(1)=2$$

导数定义先记成可操作的四步：把自变量从a换成a加h，减去原来的函数值，再除以h，最后令h趋于零。题目给的是这个差商极限时，优先识别它对应哪个函数在哪一点的导数。分子两个函数值的顺序、分母的增量，都需要一一对应。

持续高亮：[1, 2]；显示到第 2 行。

提示：先代a加h，再减f(a)；分母是自变量的增量h

例题函数是x平方，在一处求导。分子展开成二h加h平方，除以h得到二加h，再取极限就是二。若题目把分母写成二h，而分子仍是f的一加h减f的一，整个结果就要再除以二，不能看到相似形状就直接写导数值。

### ca-03-02 求导公式与四则运算

1. 幂、指数、对数

$$(x^a)'=ax^{a-1},\quad(e^x)'=e^x,\quad(\ln x)'=\frac1x$$

2. 三角函数

$$(\sin x)'=\cos x,\quad(\cos x)'=-\sin x$$

3. 乘法法则

$$(uv)'=u'v+uv'$$

4. 除法法则

$$\left(\frac{u}{v}\right)'=\frac{u'v-uv'}{v^2}\quad(v\ne0)$$

5. 反三角函数

$$(\arctan x)'=\frac1{1+x^2},\quad(\arcsin x)'=\frac1{\sqrt{1-x^2}}$$

常见求导先背这些公式。x的固定a次方，指数a乘下来，次数减一；e的x次方保持原样；自然对数导数是一除以x。正弦求导得余弦，余弦求导有负号。常数导数为零，和差可以分别求导。这里a是固定常数，若指数也含x，后面要换方法。

持续高亮：[1, 2]；显示到第 2 行。

提示：常数导数为零；余弦求导别漏负号

乘积不能只把两个导数相乘，要写前导后不导，加前不导后导。商的分母平方，分子按上导下不导，减上不导下导，顺序不能反。反正切和反正弦也常出现，注意反正弦的根号中是减号，反正切的分母是加号，并且原函数的实数定义域仍要满足。

## 不定积分与积分方法

### ca-07-01 原函数与不定积分：求导验答案

1. 原函数

$$F'(x)=f(x)$$

2. 不定积分

$$\int f(x)\,dx=F(x)+C$$

4. 验证

$$(x^2+C)'=2x$$

### ca-07-02 基本积分：幂、对数与指数

1. 幂函数

$$\int\frac{dx}{x}=\ln|x|+C\quad(x\ne0)$$

3. 指数

$$\int e^x\,dx=e^x+C$$

4. 一般指数底数

$$\int a^x\,dx=\frac{a^x}{\ln a}+C\quad(a>0,a\ne1)$$

### ca-07-03 基本积分：三角与反三角

### ca-08-07 反常积分：先找奇点再分开

1. 无限区间

$$\int_1^\infty f(x)dx=\lim_{b\to\infty}\int_1^b f(x)dx$$

2. 无界端点

$$\int_0^1 f(x)dx=\lim_{\varepsilon\to0^+}\int_\varepsilon^1 f(x)dx$$

3. 内部奇点必须分两边

$$\int_{-1}^1\frac{dx}{x}=\int_{-1}^0\frac{dx}{x}+\int_0^1\frac{dx}{x}$$

4. 右侧已经发散

$$\lim_{\varepsilon\to0^+}[-\ln\varepsilon]=+\infty$$

反常积分有两类明显特征：区间伸到无穷，或者被积函数在端点及内部某处无界。先用有限端点或避开奇点的小距离写成普通积分，再取单侧极限。只有需要的各个极限都有限，才能说收敛。若区间内有奇点，必须在那个点两侧分别计算，不能让两个发散部分互相抵消。

## 定积分的面积与体积应用

### ca-09-01 面积：先求交点，再写上减下

### ca-10-01 先识别阶数与方程类型

1. 一阶与二阶

$$y^{\prime}+y=x,\qquad y^{\prime\prime}-3y^{\prime}+2y=0$$

2. 阶数看最高阶导数

$$(y^{\prime\prime})^2+y=0:\quad n=2$$

3. 线性要求

$$a_n(x)y^{(n)}+\cdots+a_1(x)y^{\prime}+a_0(x)y=Q(x)$$

4. 初值用于确定常数

$$y(0)=1,\quad y^{\prime}(0)=0$$

微分方程的未知量是一整个函数。先看最高出现几阶导数，那就是阶数，不看这个导数有没有平方。含y两撇的平方仍然是二阶，但已经不是线性。线性方程要求未知函数及其导数都只以一次出现，彼此不相乘，系数可以是自变量x的函数。先分类型，再选择对应模板。

提示：阶数看导数阶数，不看幂次；线性不允许y与导数互相相乘

通解包含任意常数，给了初值以后再确定常数，得到符合该条件的特解。常见n阶线性方程的通解有n个独立常数，所以一阶题通常确定一个，二阶题通常要两条独立条件。别把右边等于零当成未知函数只能取零，齐次线性方程照样可以有许多非零解。

### ca-10-02 可分离变量：一侧留y，一侧留x

1. 识别模板

$$\frac{dy}{dx}=g(x)h(y)$$

2. 分离并积分

$$\int\frac{dy}{h(y)}=\int g(x)dx$$

3. 例题

$$y^{\prime}=xy,\quad\frac{dy}{y}=x\,dx\quad(y\ne0)$$

4. 积分结果

$$\ln|y|=\frac{x^2}{2}+C$$

5. 整理且补回零解

$$y=C e^{x^2/2},\quad C\in\mathbb R$$

可分离变量的识别标志，是右边能够拆成只含x的因子乘只含y的因子。把含y部分和dy放一边，含x部分和dx放另一边，再分别积分。例题y撇等于xy，除以y以后得到dy除以y等于x乘dx。这里除以y暂时要求y非零，所以要记住最后检查是否漏掉常数解。

持续高亮：[1, 2, 3]；显示到第 3 行。

### ca-10-03 一阶线性：标准式与积分因子

1. 标准式

$$y^{\prime}+P(x)y=Q(x)$$

2. 积分因子

$$\mu(x)=e^{\int P(x)dx}$$

3. 相乘后识别完整导数

$$(\mu y)^{\prime}=\mu Q$$

4. 通解

$$y=\frac1\mu\left(\int\mu Q\,dx+C\right)$$

一阶线性方程先整理成y撇系数为一，再读出P和Q。计算积分因子μ，等于e的P积分次方；这里选择一个方便的积分因子即可，不必把任意常数反复带进去。然后整条方程乘μ，左边就可以写成μ乘y这个乘积的导数，右边是μ乘Q。

持续高亮：[1, 2, 3]；显示到第 3 行。

提示：先把y撇系数化为一；P的正负号直接影响积分因子

两边积分后得到μ乘y等于右边的积分加C，最后除以μ。整套步骤是标准式、积分因子、完整导数、积分、解出y。模板看起来长，但每一步都固定。若一开始的方程是二倍y撇加其他项，必须先整体除以二，不能只把y撇前的二擦掉却不改右侧。
