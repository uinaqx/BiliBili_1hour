# 一小时学完高等数学（上）：制作约定

- 面向零基础大学生，服务于期末考试常见基础题与及格目标，不承诺个人分数。
- 严格覆盖用户列出的 39 组知识点，按常见理工类高数上课程组织为 10 章。
- 重点为识别题型、使用条件、固定步骤、例题与易错点，不展开证明或概念内涵。
- 目标 58～63 分钟，按最终配音实测安排，不靠长静音凑时长。
- 深色公式板，逐步显示解题过程，相关公式持续高亮，在实际语音开始时切换；无底部字幕、无音乐。
- 使用已授权百炼中文沉稳男声，句号间额外 0.1 秒，逗号不改。
- 定理必要条件仍需明确。凹凸采用凹向上/下和二阶导符号并列，单独凹/凸称呼以学生本校教材为准。
- 公式与例题实际符号计算核验；试片后自动继续制作，最终检查成片、章节及音轨。
- 交付视频、章节、讲稿、公式与题型速查、练习答案和可编辑工程；不自动上传 GitHub。
