# 渲染、验收与交付

## 接手与缓存

接手时识别最新认可版本及运行工作，冻结必要原文件哈希。复用已完成的可靠讲稿、音频、对应表与缓存，但不能把进度报告的“完整”当作验证。盘点各页初始状态、提示点和分幕，补齐未填表。

按页/章节缓存，缓存键覆盖真正输入：组件及导入依赖、该页时间轴、资源与字体、字幕变体；合成缓存还需包含实际 PNG 内容。文件存在不代表有效。小修只重渲染受影响范围；连续动画必须逐帧或充分采样，不能用两张静帧冒充插值动画。

有限 worker、工程锁、复用浏览器并在 finally 释放，失败后续跑。Remotion 参数按锁定版本核对：工作工程曾用 `puppeteerInstance`，误传无效属性可能导致额外浏览器不断启动。清理自己启动的进程，不杀用户浏览器。

## VFR 证据

静态页面可按事件合成 VFR，但事件须包含代码、图示、幕、输出、题目倒计时和字幕边界。30fps timebase 不等于真正恒定 30fps；平台要求 CFR 时需实际导出并测量。

VFR 用 `-ss t -frames:v 1` 可能取得未来画面。应按显示帧时间戳选 `max(PTS <= t)`，按解码显示序号取图；有 B 帧时不能直接拿包序号。`media_qa.py extract` 使用该方法。

严格 90 秒试片要核对实际时长，长停帧可能使简单裁切超时；必要时用 CFR、trim/atrim、明确帧数和采样数。

## 只去掉字幕

`-sn` 只去软字幕，不能去已经烧录的像素。有工程时关闭字幕层，用同批无字幕源帧和同时间轴重新合成，复制原音轨、章节元数据；另存新文件。不能裁底部、盖色块、重排画面或重新配音。

检查时长/章节相同、copy 的音轨比特流相同、高亮和非字幕区域保持、实际底部不再有字幕、全片可解码。没有字幕流不证明没有烧录字幕。只有成片而没有源素材时，不能承诺无损恢复字幕下的像素。

## 验收分层

| 检查 | 证明什么 | 不证明什么 |
| --- | --- | --- |
| 示例执行 | 输出和预期失败正确 | 画面同步 |
| 清单结构 | 时间、行号、分幕、初始状态合法 | 讲解选对对象 |
| 实际同步函数 | 保持、回跳、多行和幕隔离 | 编码后的画面正确 |
| 逐页语义复核 | 旁白与目标对应 | 编码完整性 |
| 成片检查 | 包时序、像素、音轨、章节、可播放 | 未听看的语义位置 |

检查切换前一帧、切换帧、短语结束后、静音、回跳、多行、思考期和换幕边界。直接运行渲染用的函数，不只测另写模型。独立转译 TypeScript 时使用 ES2020 等支持 Set 迭代的目标，避免 ES5 默认值导致假失败。

覆盖每个主题、例题与答案、已知问题点、每章开头/中段/末尾、拼接处和新切换点。预算允许时逐编码状态检查实际高亮像素和字幕边界。旧问题点只能回归，不代替全量覆盖。正则审计提示逐项复核，不能为报告变绿而改错期望。

`media_qa.py verify` 仅检查结构、时长、章节、音轨和完整解码；不会判断语义、字幕是否提前或烧录字幕是否消失。用户明确跳过验证时，注明未测，不生成通过记录；后来要求测试则恢复验收。

## 工程与安全交付

通常交付 MP4、需要时的 SRT、章节目录、完整讲稿、例子与答案、工程和说明。保留最终音频、时间信息、依赖锁文件、字体说明、组件和语义计划，让工程可离线复用配音。

密钥和业务空间标识只从未打包的环境/秘密存储读取；`.env.example` 留空或用明确占位符。扫描源文件、文档、元数据、日志、Git 待提交内容及最终 ZIP，命中只报告安全位置和类别，不回显值。

显式白名单打包，不把真实 `.env`、`.git`、依赖、浏览器缓存、临时日志、对话记录或旧版大视频收进去。GitHub 按已有用户授权发布，不新增公开上传授权，也不重复索取已有授权。

验收绑定本次视频和时间轴 SHA-256、字幕变体，必要时记录渲染输入指纹。文件变化后旧报告过期，不能只看历史 `allPassed`。包生成后核对 ZIP 完整性、安全路径和关键文件。

版本命名清楚，最终答复链接实际产物，说明检查范围，不让用户猜该看原版还是新变体。
