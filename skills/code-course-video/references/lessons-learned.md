# 制作总结与反思

这份反思来自语言入门、数据结构与计组系列的制作修复，保留可迁移的经验，不包含账户信息、密钥或特定机器路径。

| 现象 | 原因 | 改进 |
| --- | --- | --- |
| 零基础文案太难 | 围绕知识点写定义，忽略学习顺序 | 小需求贯穿，先变化与例子、再规则与术语 |
| 声音没完，字幕先换 | 粗分段、按字数估计，或音频后处理未重新对齐 | 最终音频上定位起止，检查长句和句尾 |
| 高亮闪现 | 把短语区间当高亮可见区间 | 高亮是持续状态，句末不清空 |
| 持续选中但选错 | 把机制修复当成语义修复，靠首行或关键词猜 | 逐页对应表覆盖后半段、回跳、题解 |
| 换代码后错位 | 行号与事件沿用上一幕 | 幕内初始状态、事件归属和边界检查 |
| 计组提前更新 | 通用 stage 同时驱动标题、强调与数据 | ALU、寄存器、主存分别按语音更新 |
| 换索引仍不对 | 小幕里根本没有当前概念 | 最小补齐对应素材，保留风格与声音并记录 |
| 测试绿但仍很多错 | 只查非空选中和旧时间点，未区分数据、语义与编码 | 分层验收，新提示点和逐页覆盖 |
| 截图误导诊断 | VFR seek 取了未来帧 | 按显示 PTS 提取当时实际保持的帧 |
| 字幕整句丢失 | VFR 没为字幕边界出帧，ASS 与网格取整不同 | 边界纳入事件，检查边界后一帧 |
| 修一点也很慢 | 全片重渲染、过量浏览器、缓存不可靠 | 有限并发、复用浏览器、锁与真实指纹、局部重做 |
| 报告对应旧版本 | 验收没绑定产物 | 文件哈希和变体绑定，通过记录不可直接继承 |
| 去字幕改变其他内容 | 裁切/覆盖，或重新走制作全流程 | 关闭字幕层，用相同源帧、原音轨和章节导出 |

## 工作方式

此前最重要的问题是把“脚本跑完”和“用户要求实现”混在一起。状态连续、语义准确和成片正确需要不同证据。不能用几个截图或很多测试用例暗示人工看完全部课程；未做的检查明确标注。

自动工具适合越界、缺失、连续性、帧时间、媒体完整性和敏感值；到底讲哪行代码则依赖上下文理解。两者结合比不断补正则可靠。

修复要维护范围：用户要改切换时间，就保留认可的持续高亮；只要审查，就不顺手修改；排除早期版，就保护其文件。接手续跑复用可靠成果，同时盘点空表和未验证状态。

更快来自统一清单、最终音频对齐、早期试片和局部缓存，而不是省略必要验证。一份通用函数不能代替整套逐页修复，去字幕也无需重新生成声音。

## 不固化成普遍偏好

字幕开关、零基础或已有 C/C++ 基础、时长容差、服务商/型号分别继承当前要求。“十章目录”是特定输出格式，不强制内部只有十章。模型、免费额度和权限按执行时核对，绝不复制历史秘密值。
