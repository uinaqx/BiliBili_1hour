# 教学与画面

## 契约与讲稿

课程清单统一关联章节、页面、讲稿、代码、实际输出、题目答案、配音、字幕和视觉事件。记录受众、已有基础、目标时长与容差、字幕开关、参考风格、声音服务和交付位置。目标可按约一小时准备，但明确的 58–63 分钟或其他范围优先；修复时保持原时长。

从日常小需求入手，如成绩或开销统计。按“看到什么 → 这一行做什么 → 结果怎样变 → 为什么 → 术语名称”讲解。零基础学生不默认理解变量、类型、语句、编译、引用和异常。单页少量新概念，不逐字符读完整代码，不靠定义堆砌撑时长。跨语言比较只用于确实学过对应语言的受众。

口吻像耐心、循序渐进的老师，使用清楚的小步骤。正式章节标题采用“变量与数据类型”“模块”“异常处理”，生活化问题可作副标题。不自动添加座右铭、口号、音乐和广告。

每主题设置“判断/预测/纠错 → 约四秒思考 → 答案与原因”。题目不提前显示答案。正常输出、编译错误、运行时异常/panic 和测试失败分别标记。

正常示例与修正版本要实际执行。错误示例既确认失败，也确认错误类别/原因，非零退出码本身不够。环境版本和真实输出写入制作记录。理论课验证题设与状态推导，包括位宽、编址单位、缓存初始值、数据方向和写入时刻，不把教学模型当成普遍硬件规则。

## 可读画面

已有认可参考优先复用；没有指定时参考 `CourseFrame.tsx`：

- 1920×1080、16:9，以 30fps 网格计时；真 CFR 或事件驱动 VFR 由交付约束决定。
- 深色底，左代码/图示、左下运行结果、右侧注解，底部字幕独立。
- 代码约 34px 或以上，结果约 30–32px；主要代码不超过 16 个逻辑行。软换行会增加真实高度，要做溢出检查。
- 高亮边框与浅底色持续可见，不能被透明度动画清空。
- 图示使用稳定对象标识；强调对象和实际数据更新分别控制。
- 字幕关闭时不重排画面，保留原位置。中文字体在渲染机器上实际核对并说明依赖。

模板不内置完整语法着色器、语音 API 或全部计算机图示，按当前语言和内容补充。用 `renderCodeLine` 接入已有语法着色组件，保持原语言配色；不要为套模板而重构已认可的工程。

## 声音与时长

先短测中文、术语、数字和标点，再批量配音。用户指定阿里云百炼等服务时使用环境配置，执行时核对模型、地域、权限、免费额度和费用保护，不复制历史密钥，不宣称所有调用免费。既有配音可用时不重复在线调用。

讲稿字数只用于估计，最终以实测配音、阅读和练习停顿编排。过长删重复，过短补有教学价值的分析，不用长静音凑数。指定句号间多停 0.1 秒时，仅修改该类停顿，保持逗号策略；所有音频处理完成后再对齐。

内部试片覆盖长代码、中文、输出、多行与回跳、图示状态、长字幕和思考期。已批准制作的任务检查试片后继续，无需新确认。
